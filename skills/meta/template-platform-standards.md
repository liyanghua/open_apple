# 模板片准入三强校验（Template Platform Standards）

> 适用：所有「复刻+模板」生产的成片（template_run_plan 驱动的 cinematic-fast）。
> 定位：**准入三件套**——语义一致（文案=口播=画面）、画面重复（同一镜头不得反复出现）、口播覆盖（每段有声文案有音频）。三者均为硬校验；任一失败，成片不得发布（build 阶段 fail-closed + 发布门复核）。

## 1. 语义一致：文案必须由绑定素材证明

**原则**：模板定**结构骨架**（镜头序列/节奏/起承转合/卖点顺序），素材定**证据**；每镜口播+花字 = 该镜绑定素材的**可见动作**描述。禁止「画面证明不了」的 claim（顾客满意/口碑/工厂/品牌史画面等）。

**判定器**：`lib.template_source_match.semantic_mismatches(script)` → 空列表 = 通过。
- 正判：文案/花字至少命中绑定动作的一个**证明词**（`PROOF_KEYWORDS`：检测/测/读数…、边角/圆角/边缘/贴合…、刮/划/耐磨…、擦/油/水/污…、铺…、家/桌/饭/质感/木纹…）；
- 反判：文案不得使用**其他动作的强证明词**（`STRONG_ACTION_TERMS`，如餐桌场景画面配「刮擦/检测/耐磨」= 跨 claim）；
- 豁免（必须遵守，与已批准 01/04/05 口径一致）：
  - **反问句**（口播以 ？ 结尾）：提问而非断言（“…行不行？”），豁免证明词；
  - **否定式安全表达**：不/无/没/别 + 证明词（「不翘边/毛刺不存在/不刮手」）豁免；
  - **事实引述**：`FACT_CITATION_WORDS`（价格/元/20年/SGS/报告/免费/定制/尺寸/直播间…）任何画面都允许——它们是事实/服务口径，不是对画面的描述。

**接线**：`build_script()`（剧本阶段文末）对 6 张已固化模板 fail-closed；`/overview/` 对全部成片实时展示；`tests/lib/test_template_invariants.py::test_semantic_validator…` 保护。

**写作规范（给文案作者/agent）**：
1. 先读该镜绑定素材（scene_plan.source_mapping → 素材动作 + 语义证据窗口），再写文案；
2. 文案只描述「画面里正在发生/可见」的证据动作 + 允许的事实引述；
3. 删掉任何需要「画面里没有的镜头」才能证明的句子（品牌/口碑/工厂/顾客满意/市场对比类）；
4. 长模板（20+ 镜）：把品牌/口碑类素材性 claim 改写为「家庭/生活语境可证」的表达（如「用得舒服，才是真的好」），或删除。

## 2. 画面重复：成片内不得“同一镜头用多次”

**标准（H 硬 + S 软）**：
| 项 | 标准 | 判定 |
|---|---|---|
| H1 | 相邻镜头不得使用同一素材 | 相邻同素材 = 0 |
| H2 | 单一素材占全片时长 ≤ 33% | 占比 ≤ 0.33 |
| H3 | 同一素材不得出现**完全相同**的 in-point 窗口 | 完全相同窗口 = 0 |
| H4 | 同素材相邻窗口起点差 ≥ 0.75s（微变化，允许部分重叠） | 起点差 ≥ 0.75 |
| S1 | 单素材复用次数 ≤ ceil(镜数/素材数) | 展示，超限警示 |
| S2 | 同素材两次使用间隔 ≥3 镜 | 展示，超限警示 |

**判定器**：`lib.template_source_match.material_reuse_report(scene_plan)`。
**分配器保证**：窗口分配（`build_source_mappings`）先语义窗口内去重；候选耗尽时回退取「与已用窗口起点距离最远」的差异化窗口——H3/H4 由构造保证（`.py` 已实现）；H1/H2 取决于**素材池容量与结构编排**（见 template-material-pool-design）。

**可行性判断（写结构前必算）**：N 镜 / M 素材 → 理论最大复用 = ceil(N/M)；若某动作域占位 > 上限或连续段 >1，此结构**数学上不可满足 H1/H2** → 必须：改结构（轮换/分段）或扩素材池，否则视为设计缺陷（overview 会标红）。

## 3. 口播覆盖：每段有声文案必须有音频

- 每个 narrated section 必须存在 `assets/audio/narration-{NNN}.mp3`（三位命名契约 `narration_filename()`）；
- `assets/audio/sample-mix.mp3` 必须存在（成品混音）；
- TTS 生成阶段 fail-closed：`overflow/error` 一律中断管线（`prep_template_media`）；
- 判定：`backlot.overview_state._audio_coverage()`；overview「口播覆盖」列 = ✅/⚠。

## 4. 准入流程（成片发布前）

```
build_script（语义硬门，已固化模板）→ prep（TTS 门 + 混音）→ render → QA/证书
  → material_reuse_report（H1-H4 必须 pass；S1/S2 记录）→ publish 门（证书 hash 校验）
  → /overview 总览三列展示（语义/重复/口播）→ 人工抽帧复核（每片≥4 帧：hinge/证明/边角/家庭）
```

反模式（已发生，写入历史）：① 显式动作表与文案文本打分不一致 → 用 `semantic_mismatches` 真值校验破自洽；② 素材窗口 fallback 回落同窗口 → H3 抓住（14 片 92 处完全重复）；③ 只抽 1 片帧而漏掉其余 → 每片至少 4 帧人工抽检成为流程项。

## 5. 严格档（S-Strict）与正式版准入（2026-08-28 评审定版）

**背景**：标准档（H1-H4）允许部分重叠窗口与 33% 占比，用户体感仍"重复度高"。
**严格档 = 正式版发布准入**（`release_designations.strict_required=true`，重发布=新准入；Goldset sheet-01 白名单豁免并记录理由）。

**严格规则（6 条全硬门）**：
| 规则 | 数值 |
|---|---|
| S1' | 单素材复用 ≤ ceil(镜数/素材数) |
| S2' | 单素材占片 ≤ 25% |
| S3' | 同素材窗口**完全不重叠** |
| S4' | 同素材相邻窗口起点差 ≥ 1.5s |
| S5' | 复用间隔 ≥ 4 镜（最终序列） |
| 通过 | strict_pass = 全部满足 |

**数学可行性（写片前必判）**：
- **S2' 25% ⇒ 该片必须 ≥4 个动作域**（k 域各 ≤D/4 ⇒ Σ ≤ kD/4，k<4 时恒 <D，矛盾）；域数不足 ⇒ 加域（换 beat/素材）而非调镜数；
- **S5' ≥4 + 原始顺序不可变**：重复域天然聚簇的模板纯子集无解（实测 15/19）⇒ 需**换序改写变体**（-c2 式：模式化 A B C D E ×2 交错重排 + 叙述弧校验）或放宽记录特例；
- **S3' 非重叠容量** ≠ 窗口容量（gap0.75 允许重叠）；非重叠容量 = 证据窗口内 span 步进的可容纳窗口数（如「自动铺开」3.7s 窗口 ⇒ 容量 1）——**按此容量规划复用**，别用 window_capacity 的 8/9 数字误导。

**压缩三态 SOP**：
1. **纯子集**（可）→ `rp.compression` 契约（kept ids/ordinals + base_section_refs + input_hash + 硬门标志）→ 同 run 重建/渲染/QA/严格门发布；
2. **换序改写**（子集不可 + 域数够）→ 新变体模板（09c2 流程）→ 同管线；
3. **不可达**（域数 <4 或 ≤15s 锁死）→ MARK_GAP + 缺口账单，等素材扩容。

**实测结论（归档，防重推）**：04c1 / 05c1（8镜/16.0s 严格✅）/ 09c2 达标；15/19 纯子集无解 ⇒ 换序改写待办；01 = Goldset 白名单（8 镜 S5' 极限）；严格化对 L3 影响可忽略（05: 8.31→8.27，15/22 预期微升）。
