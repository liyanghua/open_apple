# 模板素材池设计（Template Material Pool Design）

> 适用：为「复刻+模板」生产准备/扩充自有素材池。目的：在任何模板结构下都能同时满足
> `template-platform-standards` 的 H1（相邻不重复）与 H2（单素材 ≤33% 占片）。

## 1. 最小可证明集（动作域设计）

素材按**动作域**组织；每域 = 一类「可被镜头证明的产品动作」。当前池（透明桌垫）6 域：

| 动作域 | 素材可证明的可见动作 | 证据窗口（人工标定） |
|---|---|---|
| 防油易擦拭 | 倒油→油滴落→纸巾擦走 | 0.5–8.0s |
| 防刮 | 硬物刮擦/按压 | 1.9–7.6s |
| 无甲醛检测 | 手持检测仪读数 | 0.0–8.0s |
| 桌角对齐-挤压不变形 | 手铺桌角贴边 + 挤压复原 | 1.7–5.1s |
| 自动铺开对齐 | 桌垫自动铺开并对齐 | 0.2–3.9s |
| 餐桌场景 | 家庭餐桌生活（食物/茶具/木纹） | 0.0–7.5s |

**最小可证明集 = 每域 ≥2 镜**（不同机位/不同动作阶段），矩阵目标 **6 域 × 2 = 12 素材**。
扩池清单（按优先级）：
- 餐桌场景 ×2（近景食物/全景家庭入座）——H1/H2 最大压力域；
- 无甲醛检测 ×2（读数特写/边测边铺桌垫）；
- 桌角 ×2（桌面下缘贴合特写/挤压复原连拍）；
- 防刮 ×2（金属刮/硬刷擦拭视角）；
- 防油 ×2（大面积污染/单滴特写）；
- 自动铺开 ×2（俯拍铺开/侧视张力）。

## 2. 复用可行性数学（写模板结构前必算）

```
N = 模板镜数； M = 素材域数（当前 6）
单素材理论复用上限 = ceil(N / M)
H2 下限：占比_min = (N/M × 单镜时长) / 单片时长 ≈ 1/M
```

- N ≤ 12 且 M=6：可满足 H1/H2（每域 ≤2 次，交织编排相邻不重复）。
- N=21~30：M=6 时每域 ≥3~5 次 → H2 单素材占比 ≈ 1/6(16%)~可行但 **H1 邻镜冲突频繁**；若故事把多镜压在同一域（如 14 片餐桌场景 18 镜/59%）→ **必然违反 H1/H2**。
- 结论：**长模板（>12 镜）必须二选一**——① 扩池到 12+（每域 2 镜，仍受 N/M 上限约束但 H1 可交织） ② 结构轮换（每 6-8 镜一个卖点组，组内换域） ③ 分段成片（单段 ≤12 镜）。
- 模板本身若某域 > ceil(N/M)（如 30 镜中 13 镜「餐桌场景」）→ 视为**设计缺陷**：改结构（减少该域、换域表达或增加素材），不得硬排。

## 3. 入池流程（新增素材）

1. 拍摄/采购 **动作域 ×2** 素材（1080×1920 或更高，动作含证据窗口≥6s）；
2. 入池登记：`projects/table-mat-mix-v8/inputs/source/video/product/`（命名 `product_透明桌垫-<域>.<ext>`）+ `media_index.json`（时长/指纹）；
3. 审定：`source_media_review`（reviewed owned）+ `reference_source_matrix`（matrix row 桥接，evidence_frames 与 v8 代表帧对齐）；
4. 标定语义证据窗口（人工看帧，写入 `SEMANTIC_EVIDENCE_WINDOWS`）——窗口必须落在「证据实际发生」区间，禁止粗估整段素材；
5. 冒烟：用 `scripts.add_matrix_grounding.py` + `material_reuse_report` 验证新池下目标模板 H1/H2 通过。

## 4. 已知边界与升级路径

- 「画面相似度」目前以「同素材+窗口起点差」近似；VLM 帧 embedding 相似度（未来）可替代，作为 P2；
- VLM 语义匹配（未来）：自动产出动作域→素材映射，替代人工 `SLOT_ACTION_BY_TEMPLATE` 标定（当前 6/43 模板已标定）；
- 含「工厂/口碑/顾客满意」等高叙事域的模板：只有该域素材入池（叙事镜头 + 相应台词）才能回到「结构高保真」模式——否则以生活方式可证表达（见 platform-standards 写作规范）。
