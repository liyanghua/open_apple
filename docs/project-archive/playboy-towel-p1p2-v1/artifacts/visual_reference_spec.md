# P1/P2 双商品参考与品牌视觉约束

## 参考层级

- 商品目录：银离子目录绑定 P1，长绒棉素色毛巾目录绑定 P2。用于选择商品全貌、织纹微距、折叠/使用素材。
- 商品事实图：作为 Seedance 第二参考图，只提供商品页语境和事实上下文，不要求模型读取或生成图中文字。
- 品牌视觉系统：`~/Desktop/花花公子抖音增长/花花公子视觉识别系统2.0.pptx`。用于 Remotion 的版式、颜色、字体、字幕安全区、标识使用与片尾承接。

## Seedance 双参考规则

1. 第一参考图锁定商品外观、颜色、织纹和形态。
2. 第二参考图绑定商品事实图片，仅作上下文参考。
3. 提示词禁止生成商品页文字、参数表、Logo 或报告截图。
4. 事实文案仍由 P1/P2 事实卡驱动，在 Remotion 中逐字呈现。
5. 当前 `P1-S01-motion-02`、`P2-S01-motion-01` 只作为动作验证片，正式动作片需重新双参考生成。

## 视觉系统落地

- 竖屏 9:16，主体优先，字幕和事实卡固定在品牌安全区。
- 字体优先使用视觉系统中的中文字体映射，英文/数字使用 Arial 或等宽替代，避免小字。
- 颜色从品牌主题色中取深色文字、白底和单一强调色，商品本色只用于主体与局部强调。
- 画面保持平面、干净、克制；不把商品事实做成密集 UI 面板。
- 片尾统一保留商品 ID/规格以商品页为准的承接卡，动态价格不写死。
