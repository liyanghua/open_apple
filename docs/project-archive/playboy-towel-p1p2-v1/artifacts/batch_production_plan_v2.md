# P1/P2 毛巾批量视频生产规划 v2

版本：v2.0
状态：基于首轮样片和参考片分析整理，进入批量前规划审核
适用商品：P1 银离子毛巾、P2 长绒棉素色毛巾
主线架构：商品事实卡 → 主图卖点拆分 → Seedance 2.5 动作片 → Doubao TTS → Remotion 品牌合成 → BGM 混音 → 兼容性检查

## 一、已经验证的成片方向

本轮验证了两种节奏：

1. 单卖点 3–5 秒动作片：适合展示一个细节动作或做素材库存。
2. 高密度连续卖点成片：参考视频约 12 秒、6 个场景，平均每镜头约 2 秒，适合抖音商品短视频。

批量发布的主格式采用第二种：

- 单条成片建议 8–12 秒
- 4–6 个连续卖点镜头
- 每镜头约 1.5–2.2 秒
- 每镜头只表达一个卖点
- 一条连续口播贯穿全片
- 字幕按口播语义和镜头卖点同步切换
- 收尾使用品牌 Slogan，不使用泛化商品页核对语

3–5 秒动作片作为底层素材长度；成片阶段从动作片中裁出 1.5–2.2 秒卖点镜头。

## 二、已固化的硬规范

### 1. 商品事实边界

- P1 和 P2 必须使用各自的商品事实卡。
- 页面宣称只能用“页面标注”“商品页显示”等事实边界措辞。
- 不能把页面宣传语写成检测结论、性能保证或绝对承诺。
- 动态价格不写死。
- 商品图中的文字不能自动转成口播事实，必须经过商品映射审核。
- 银离子目录中出现“长绒棉”主图时，必须确认归属后才能用于 P1 文案。

### 2. 主图与卖点规则

- 一张主图对应一个主卖点。
- 优先使用不含模特的主图。
- 主图只负责锁定商品外观、颜色、织纹和结构。
- 有真人的详情图不得直接作为 Seedance 参考图。
- 主图比例、尺寸不符合接口限制时，先做等比例压缩和无人物裁切。
- 不同卖点必须使用不同动作：触摸、扫纹、提起、展开、回落、颜色展示等。

### 3. Seedance 动作片规则

- 模型：Seedance 2.5，当前 provider 为 Ark。
- 默认时长：4 秒，允许范围 3–5 秒。
- 生成音频关闭，口播统一由 Doubao TTS 生成。
- 禁止模型生成 Logo、字幕、参数表、商品页 UI 和报告文字。
- Prompt 必须明确：保持商品颜色、比例、织纹和真实形态。
- 动作片通过身份、构图、动作、材质、禁止项五类描述控制。
- 每条动作片生成后必须检查首帧、中段和尾帧，确认没有变色、变形、错 SKU 或人物隐私问题。

### 4. 品牌视觉规范

来源：`~/Desktop/花花公子抖音增长/花花公子视觉识别系统2.0.pptx`

- Logo：官方 Playboy 黑色组合标志。
- Logo 宽度：120px。
- Logo 位置：右 72px、顶 96px。
- 中文字体：微软雅黑或系统等价中文字体。
- 英文与数字：Arial。
- 卖点标题：64px，左 72px，最多两行。
- 卖点补充文字：38px。
- 口播字幕：30px。
- 字幕底部安全区：距底部约 210–240px。
- 左右安全边距：72px。
- 顶部安全区：180px。
- 底部安全区：240px。
- 主强调色：`#4874CB`。
- 辅助色：`#EE822F`，每个镜头最多使用一次。
- 禁止渐变字、描边字、弹跳、旋转、闪烁和重复叠字。
- Logo 和卖点标题只由 Remotion 叠加一次，底层动作片不得再次带同一层文字。

### 5. 口播与字幕规范

- Doubao Speech 2.0。
- 默认音色：`zh_female_vv_uranus_bigtts`。
- 语速优先自然，必要时使用 speech_rate 25 控制高密度口播长度。
- 先生成完整口播，再根据时间戳做字幕。
- 字幕按语义句切换，不能按固定字数切断词组。
- 口播必须完整播放，视频尾部至少预留 0.5–1 秒收尾余量。
- 字幕使用白色文字和低透明深色底，保证复杂商品画面上可读。
- 口播、字幕、镜头卖点必须一一对应。

### 6. BGM 与音频规范

- 使用 SUNO 生成无歌词、无主唱的背景音乐。
- BGM 只做节奏和氛围，不与口播争夺频段。
- 默认 BGM 音量约为人声的 10%–15%。
- BGM 在开头和结尾做短淡入淡出。
- 口播和 BGM 必须在同一最终音频轨中混音。
- 不把其他项目的音乐直接当作本项目热门 BGM。

### 7. 转场与兼容性规范

- 高密度卖点之间使用 4–6 帧、约 0.2–0.3 秒交叉淡化。
- 不使用花哨转场、旋转、闪白或强烈缩放。
- 所有片段统一为 1080×1920、30fps。
- 最终输出：H.264 High Profile、`yuv420p`、AAC-LC、MP4。
- 必须检查 QuickTime/系统播放器兼容性，避免 H.264 4:4:4、`yuvj444p` 等格式。
- 每次输出后使用 ffprobe 检查分辨率、时长、编码、像素格式和音频轨。

## 三、批量成片模板

### 目标时长：10–12 秒

| 时段 | 内容 | 规则 |
|---|---|---|
| 0.0–0.4s | Logo 进入 | 右上固定位置，淡入 |
| 0.0–2.0s | 卖点 1 | 主图动作 + 标题 + 第一段口播 |
| 2.0–3.8s | 卖点 2 | 织纹/边缘动作 + 第二段口播 |
| 3.8–5.6s | 卖点 3 | 材质/结构动作 + 第三段口播 |
| 5.6–7.4s | 卖点 4 | 使用/折叠/回落动作 + 第四段口播 |
| 7.4–9.5s | 卖点 5 | 颜色或场景动作 + 第五段口播 |
| 9.5–10.5s | 品牌收尾 | Logo + `PLAYBOY，让日常更有质感` |

镜头数量可以按商品素材量调整为 4–6 个，不能为了凑时长重复同一个动作。

## 四、P1/P2 卖点矩阵

### P1 银离子毛巾

- 织纹细节：高密织纹、柔软触感
- 材质表达：只使用 P1 事实卡已核验的纯棉/银离子表述
- 使用动作：触摸、扫过、提起边缘
- 颜色动作：只使用 P1 已确认颜色
- 风险：带“长绒棉”字样的主图必须先完成商品归属确认

### P2 长绒棉素色毛巾

- 素色外观：晴空蓝、柔胭粉多款可选
- 织纹细节：双面毛圈
- 材质表达：长绒棉材质，棉含量百分之百，必要时加“页面标注”边界
- 使用动作：提起、展开、柔软回落
- 品牌收尾：`PLAYBOY，让日常更有质感`

## 五、每条视频的生产流程

1. 从商品事实卡选择一个可用卖点。
2. 从主图目录选择对应无模特主图。
3. 写 3–5 秒动作 Prompt。
4. 调用 Seedance 生成动作片。
5. 检查身份、动作、材质和隐私风险。
6. 将动作片裁成 1.5–2.2 秒成片镜头。
7. 按高密度模板编排镜头顺序。
8. 生成连续 Doubao TTS。
9. 用时间戳驱动底部字幕。
10. 加入 SUNO 无歌词 BGM并压低音量。
11. 加 Logo、卖点标题、品牌 Slogan。
12. 以 0.2–0.3 秒淡化拼接。
13. 输出兼容 MP4。
14. 做画面、字幕、口播、BGM、编码五项 QA。

## 六、哪些内容已经固化，哪些由 Agent 决定

### 必须固化，不得临时改变

- 商品事实边界
- 主图一图一卖点
- 3–5 秒动作片长度
- 1.5–2.2 秒成片镜头长度
- Logo 资产、位置和尺寸
- 字体、字号、安全区和颜色
- 不生成 Logo/文字的 Seedance 规则
- Doubao 音色和字幕时间戳机制
- SUNO 无歌词 BGM 和人声优先混音
- 交叉淡化和 MP4 兼容编码
- 品牌 Slogan 的最终文案

### Agent 可以根据素材和内容调整

- 具体卖点顺序
- 触摸、扫纹、提起、展开、回落等动作选择
- 每个镜头的 1.5–2.2 秒具体长度
- Prompt 中的镜头角度、景别、光线和运动方向
- BGM 的节奏和乐器，只要不盖住口播
- 字幕底色透明度，只要满足可读性
- 4 镜头还是 5 镜头结构，只要不重复动作
- 哪些片段需要重生成，以及重生成原因

### 任何情况下都要重新记录的决定

- 更换商品主图
- 更换商品事实口径
- 更换 TTS 音色或语速
- 更换 BGM 供应商或音乐风格
- 更换成片时长范围
- 更换 Logo 版本或位置
- 更换 Remotion 合成方式

## 七、批量质量门

单条视频必须同时满足：

- 商品身份没有漂移
- 动作在 3–5 秒内完成
- 成片每个镜头只讲一个卖点
- 卖点字幕和口播一致
- 口播完整，没有尾句截断
- 字幕没有重叠、出界或压住商品主体
- Logo 只出现一次且位置统一
- BGM 不盖住口播
- 转场不闪烁、不黑帧、不残影
- 输出文件在目标播放器中可打开

批量通过条件：

- 首批至少 2 条成片通过人工审核
- P1/P2 各至少有一条完成“动作 + 口播 + 字幕 + BGM + Logo”闭环
- 同一批次不重复使用相同动作和相同卖点顺序
- 所有失败重做都记录原因和修正方式
