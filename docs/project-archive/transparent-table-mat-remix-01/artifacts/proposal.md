# Proposal：透明桌垫竖屏产品混剪

## 当前状态

本项目已完成参考解析、自有素材检查和逐镜映射，当前停在 `proposal` 人工审批点。没有生成补充素材、没有调用付费模型、没有制作样片、没有转码代理、没有渲染完整成片。

## 推荐方案 A：三连冲突，逐项实测

开头 0-2 秒用“酱汁落下 → 餐叉摩擦 → 擦拭结果”建立冲突；2-6 秒展示人工铺开和对齐；6-10.5 秒餐叉测试；10.5-15.8 秒酱汁污渍、停留、擦净；15.8-20.3 秒按压、弯折、回落贴合；20.3-23.5 秒谨慎呈现仪表读数；23.5-28.2 秒回到完整餐桌；28.2-30 秒放置待补品牌 CTA。

推荐理由：最符合“直接、有冲击力、真实测试感、卖点清晰”，也是现有实拍证据覆盖最完整的方向。没有 FAL 缺口。

## 运行与作者模式

- Pipeline：`cinematic`
- Renderer family：`product-reveal`
- Render runtime：`Remotion`，用户已指定且本机可用。
- HyperFrames：预检不可用，记录为 `runtime not available on this machine`，不静默替换。
- FFmpeg：用于旋转归一、代理、音频混合和最终技术检查，不承担主合成视觉。
- Authoring mode：推荐 `atelier`，因为这是单条英雄产品视频；会手写项目级 Remotion composition，不使用 stock cut 作为创意组件。

## 音频审批

六条自有素材音轨都为数字静音。当前 `music_library/` 为空。请在进入样片前确认：

1. 提供一条已获授权的音乐；或
2. 批准无音乐、只做自制/授权 SFX；或
3. 批准 TTS 旁白，并在样片中先审声音。

本轮没有调用音乐生成、TTS 或下载工具。

## 文案与合规边界

- 防刮：`餐具摩擦测试`、`日常刮蹭，先由桌垫扛`，不写“刮不花”。
- 防污：`酱汁污渍，一擦就净`、`防污易打理`，不把画面写成明确的油污实测。
- 形变：`弯折后回落贴合`，不写“永不变形”。
- 检测：`仪表实测画面，读数以画面为准`；没有报告前不写第三方无甲醛认证。
- 瓶身标签和 YESWOOD 标识必须裁切、遮罩或模糊。

## 批准后顺序

1. 根据你选择的 A/B/C（可混合）和 atelier/templated，锁定 proposal。
2. 补齐品牌名、Logo、店铺/购买方式和 CTA。
3. 仅用 source/ 生成 10-15 秒样片，覆盖前三连钩子和一组证明；样片再次审批。
4. 样片通过后才做完整剪辑、Remotion 合成和最终技术质检。
