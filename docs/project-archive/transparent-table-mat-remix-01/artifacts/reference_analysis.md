# 参考解析：透明桌垫产品短视频

## 结论

参考片长 14.791 秒，720x1280 竖屏，检测到 7 个镜头，平均镜头 2.11 秒，约 28.4 cuts/min。它的有效方法是“动作先于解释”：首秒直接放置产品，前三秒连续给出铺设、边角和摩擦，随后用液体、擦拭、弯折完成一串可见证明。

## 可借鉴的抽象方法

- 开场立即出现产品和动作，不做说明式铺垫。
- 每一个卖点都配一个可见的测试动作。
- 以动作发生点硬切，平均 1-3 秒一个信息单元。
- 使用 2-4 字短标签，把字幕当作动作的“证据索引”。
- 问题、测试、结果连续出现，减少观众推理成本。

## 必须重新创作

- 用自有酱汁、餐叉、擦拭、铺设、弯折、仪表和餐桌全景重新编排。
- 用“三连冲突”取代参考片的单次铺设开场。
- 采用原创粗黑体与炭黑/安全红证据标记，不复制白色毛笔字。
- 将 15 秒卖点串扩展到约 30 秒，给测试结果留可读停顿。
- 以完整家庭餐桌画面收束，CTA 留待品牌信息确认。
