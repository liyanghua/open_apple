# Table Mat C1 Sample Art Direction

Design read: a credible domestic product proof, not a generic feature reel.
Warm wood and real hand movement carry trust; charcoal typography keeps the
evidence precise; ice blue appears only as a brief transparent-edge sweep.

- Runtime: Remotion
- Authoring: atelier, project-local, no stock scene registry
- Format: 1080x1920, 30fps, 410 frames (13.667s)
- Palette: warm wood, warm white, charcoal, one ice-blue accent
- Type: compact bold sans, short evidence labels rather than verbatim captions
- Motion: source-led, hard evidence cuts, one restrained edge sweep
- Primary subjects: cleaning cloth/result; utensil contact; fingertip/rounded edge
- Anti-patterns: purple gradients, generic cards, repeated hero layout, unsupported claims

Distinctness: the transparent edge sweep is used only in the final rounded-edge
beat. Each beat has a different subject, crop, tonal emphasis, and motion register.
