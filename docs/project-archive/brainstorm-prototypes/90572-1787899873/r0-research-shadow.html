R0 Research Shadow

只读并行研究：验证覆盖率与吞吐，不改变 production checkpoint

输入与主控
OpenMontage facts

Project revision
research input hash + source media refs

Executive Producer
创建任务、设定边界、合并报告

Production state
现有 checkpoint / artifacts 保持不变

Shadow boundary

允许：读取已授权输入、调用只读分析工具、写临时报告

禁止：写 canonical artifact、付费生成、改 decision log、推进 stage

输出：schema-valid TaskReport + evidence refs

并行任务单元
A

Reference Analyst

视频结构、镜头节奏、caption / visual pattern；只产观察与时间码证据

B

Source Inspector

自有素材清单、时长、可用区间、质量与 provenance；不做创意选择

C

Evidence Researcher

事实、来源、时效性和受众问题；不改写 script 或 proposal

汇合与判定
TaskBoard → merge → existing research gate

1. SpawnGuard：并发上限 2-3、单任务超时、无嵌套 spawn

2. TaskReport validator：输入 revision、角色、结论、证据、置信度、warnings

3. EP synthesis：去重、冲突标记、覆盖率统计；只有主 Agent 能写 research artifacts

4. R0 decision：通过 → 进入原 research checkpoint；失败 → 关闭 shadow、单 Agent 继续

R0 成功信号

  • 研究覆盖提升 ≥20% 或 wall time 下降 ≥25%
  • 报告 schema 通过率 100%
  • 0 越权、0 重复付费、0 canonical 污染

不算成功

  • 只是产生更多文字
  • 主 Agent 仍需人工重做全部研究
  • 并发导致证据冲突却没有可追溯标记
