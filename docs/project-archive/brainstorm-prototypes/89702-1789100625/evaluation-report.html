逆向得到的复刻手法

1. 抽取原片镜头时间轴与字幕/口播槽位。
2. 保留镜头动作模板：手摸边、桌面展示、边缘特写、油污泼洒、擦拭、全景收尾。
3. 用产品图/事实重建同构画面，替换桌面颜色、产品边缘和文案。
4. 用统一暖色调、浅景深、竖屏构图和白字描边维持“同一条片”的感觉。
5. 用后期叠字幕完成卖点替换，但没有把每个 claim 编译成可验证的视觉证据。

要超过它，主线必须新增的硬门

F1 时间轴锁定： reference_fingerprint 保存逐镜区间、切点、速度和 drift 容差。
F2 口播锁定： transcript → word/phrase timecodes → TTS performance lock；逐词起止误差可测。
F3 卖点证据编译： 每个 claim 必须有 required_action/result/evidence_window；无证据就 omit 或人工确认。
F4 替换矩阵： reference_shot → product_fact → visual_route → asset hash → final shot，禁止按数组位置漂移。
F5 双重评分： reference fidelity（结构/节奏/镜头语法）与 product truth（身份/事实/证据）分开评分。
F6 失败只重做局部： 以 shot_id 为粒度回滚，不整片重跑；时长、字幕、TTS 变化触发受影响镜头重渲染。
