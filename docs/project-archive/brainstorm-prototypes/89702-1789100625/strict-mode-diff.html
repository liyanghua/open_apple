严格复刻模式 vs 当前主线

核心变化：参考片从“分析依据”升级为“时间轴与表现合同”，但最终素材仍必须来自你的产品与授权资产

当前主线 · reference_driven

参考片角色
提供结构、节奏、镜头语法和风格灵感

脚本
重新创作；不复制原台词和原字幕

镜头
按 scene plan 做语义映射，允许重新安排镜头表达

时长
目标时长和节奏相近，但没有逐拍锁定合同

验收
重点看机制、产品证据、语义对齐和原创边界

适合：借鉴一类爆款的叙事方法，做出有明显差异的新片
新增 · reference_fidelity

参考片角色
生成可执行的 beat/shot/audio/caption fingerprint

脚本
保留口播结构、停顿、强调点；逐句替换为产品事实

镜头
每个 reference shot 必须有对应 replacement shot 和证据

时长
锁定每拍区间、切点、速度和允许 drift 容差

验收
新增时间轴相似度、口播节拍、转场意图和逐镜替换闭环硬门

适合：同一条广告骨架换成你的 SKU，要求“看起来就是同一套节奏”

主线需要新增的 5 个合同

1 · Reference Timeline

每拍 start/end、beat_role、cut_type、speed、transition_intent

2 · Voice Performance

逐段文字槽位、pause、emphasis、WPM、音色与响度约束

3 · Replacement Matrix

reference_shot → product_claim → owned/generated asset → source window

4 · Fidelity Policy

锁定项、可变项、禁止复制项、duration drift 容差

5 · Fidelity Evaluation

输出 reference_alignment_report，失败时只重做受影响镜头

建议的执行流
research → reference_fingerprint → fidelity_policy_lock → script_rewrite → replacement_matrix → assets → sample → fidelity_eval → compose
✓

差异定义符合预期

继续细化严格复刻模式的 artifact、状态机和质量门

↺

需要调整锁定范围

例如只锁节奏，不锁口播；或允许更大的镜头重排
