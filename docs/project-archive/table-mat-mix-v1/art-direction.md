# Art Direction — table-mat-mix-v1

## Design read

不是通用家居广告，而是一条“透明桌垫证据冲刺”：暖木桌面提供生活可信度，透明材质的边缘高光和编号证据章把肉眼不易察觉的产品价值变得可读。参考片只提供 11 个镜头边界和快切节奏，不复用其像素、品牌、字幕或音乐。

## Taste profile

- visual_variance: 6 — 生活全景、材质近景、油污证据、耐热结果、CTA 五种构图轮换。
- motion_intensity: 8 — 1 秒级硬切、短促推拉和方向相反的平移；不做慢速幻灯片。
- information_density: 5 — 每镜只保留一个卖点，口播字幕与证据标题分层。
- palette_discipline: 暖木色 #C99259、奶油白 #FFF8EC、墨黑 #15130F，仅用安全绿 #0A8F70 和证据黄 #FFD84D 作强调。
- reference_strategy: 逐镜沿用参考时间槽，画面全部来自用户产品事实图。
- anti_patterns: AI 紫色渐变、通用科技卡片、悬浮玻璃面板堆叠、伪造实验数据、复用 stock scene components。
- quality_gates: 产品始终可辨；字幕在抖音安全区；价格促销信息不成为画面焦点；11 个切点与参考一致。

## Type personality

标题使用 PingFang SC / Noto Sans SC 的 800–900 字重，像商品检测章一样直接；字幕用 650 字重并保持短句。数字 960 和 2年 使用等宽数字特征，强调可核验感。

## Motion character

“快、准、落地”：镜头内以轻微推近和横移制造真实摄影感，切点使用 1–2 帧的透明高光扫过；卖点章先压缩后回弹，模拟桌垫落在桌面的重量。所有动画只由帧驱动，采用确定性 interpolate() / spring()。

## Layout and rhythm

主体保持中下区域；顶部 12% 放证据标签，中上区域放卖点标题，底部 16% 放词级口播字幕。长镜头承担完整卖点，0.2–0.7 秒的尾部镜头只承担 CTA 闪切，不塞入新的口播句。

## Signature device

“透明护盾刻度”：一条带折射感的透明弧形高光从桌面边缘扫过，在卖点成立时落成绿色证据章。只在开场、960 小时和最终 CTA 三处出现，避免成为每镜模板。

## Scene inventory

1. 服帖近景：桌垫边缘与揉面动作，主张“实厚不虚标”。
2. 餐桌生活中景：木纹透过桌垫，主张“纯净原料，透度高”。
3. 边缘压力近景：用动态裁切承接“防刮”。
4. 油污擦拭证据：橙色液体与抹布为主视觉。
5. 油污结果特写：数字 960 成为视觉峰值。
6. 热锅落桌结果：高温使用场景，强化耐用保护。
7. 生活餐桌回落：儿童与餐桌，落到无味安全。
8–10. 三个极短 CTA 闪切：产品全景、清洁证据、服帖动作，按参考尾部切点快速回顾。
11. 最终落版：餐桌全景加原创直播间 CTA。

任意两个连续场景不共享同一主视觉主体；签名装置只在 1、5、11 使用。
