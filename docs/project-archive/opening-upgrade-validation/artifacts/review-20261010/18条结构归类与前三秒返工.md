## 两条首件

- **P1-SELL-A / 防臭情境：**0–0.5 秒潮湿浴室和毛巾接触动作立即入画；0.5–1.8 秒手迅速提起、打开边缘；1.8–3 秒落在可辨织纹与包边。画面传达“用久怕有味”的日常顾虑，不呈现臭气消失、杀菌可视化或虚构测试。口播与文字只用已批准商家宣称。
- **P1-N01 / 选购细节：**0–0.5 秒整条毛巾进入画面；0.5–1.8 秒快速靠近毛圈；1.8–3 秒翻出边角形成第二观察点。以连续真实动作形成远近变化，不靠静态主图和花字撑满三秒。
