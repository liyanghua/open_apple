# A/B 样片两项放行障碍修复单

适用成片：`P1-SELL-A-v1.mp4`、`P1-SELL-B-v1.mp4`。本修复单只处理商品事实与口播核验；v1 保留原始检查结果，不把人工判断写成机器通过。两片是试点 SKU `yb-bb-03` 的样片，修复后仍需版本化复审，不能直接计入原 300 条商品配额。

**10 月 10 日事实放行更新：**用户明确确认“主图这样写是因为商品事实就支持，所以放行”。已将这次决定记录在[商品声明批准记录](../fact_claim_approval.20261010.v1.json)，并生成[已批准 P1 事实快照 v2](../../fact_snapshot_P1.v2.json)。下文“待批准”的描述是做决定之前的历史状态；现在 A/B 中与主图相符的银离子、10A 抗菌、防臭、吸水、纯棉及双面毛圈定性措辞已经获得商品事实放行。此批准不表示有独立检测报告，不允许新增抗菌率、吸水速度保证等量化结论，也不替代声音和成片质检。

## 障碍一：卖点文案超过当前商品事实的放行范围

当前 P1 事实卡 `fact_snapshot_P1.json` 为 `pending_confirmation`，且 `approved_by=null`。主图原件和 `merchant_fact_addendum.v1.json` 可证明商家在图片中写了“银离子”“10A 抗菌”“吸水”等字样，但附录状态是 `merchant_claims_only`，独立性能验证为 `not_run`。v1 口播把“银离子、10A 抗菌、防臭、吸水”直接作为商品效果陈述，因此不能凭主图或样片人工验收放行。

按**每一条声明**完成选择，不以整张主图或整段脚本一次性批准：

| 声明 | 当前证据 | 修复选择 | 放行记录 |
| --- | --- | --- | --- |
| “银离子”“10A 抗菌” | 商家主图声明 | 有可核对的商品页/检测材料且负责人批准时，使用批准的准确措辞；仅认可商家页面时，明确写成“商品页标注……”；未获批准则删去 | SKU、来源文件及哈希、证据版本、允许文案、批准人和时间 |
| “防臭”“吸水”效果 | 商家主图声明，暂无独立实测 | 需要效果证明才能作确定性口播；否则改为页面归因或换成画面可直接观察的织纹、毛圈、动作描述 | 与上项逐条记录，不能由 AI 擦拭动作代替实测 |
| “纯棉”、颜色等商品属性 | 待确认事实卡及商品图片 | 核对对应 SKU 的当前商品事实，批准后使用；颜色按已批准的商品版本 | 属性值、商品版本、来源和批准状态 |

为减少返工，推荐先出一版**不含未经批准效果承诺**的 v2 脚本。保留开头差异和视觉节奏，正文用已批准的材质、外观、可见动作；需要 10A/防臭等核心卖点时，先补证据并批准对应事实，再锁定最终文案。不能先合成后补事实卡。事实卡升级为新版本，脚本每句绑定其引用的事实 ID 和允许措辞。文案选择前，v2 不进入 TTS 或渲染。

## 障碍二：ASR 的口播、字幕和收尾核验失败

两片的 `narration_evidence.v1.json` 中 `narration_content`、`caption_alignment`、`slogan_tail` 均为 `fail`。ASR 把“银离子”识别为“银李子”，A 片的“10A 抗菌”识别异常，并把结尾“更有质感”识别为“够有质感”。16.1 秒片尾在 ASR 最后一个词后约有 0.54 秒，满足 0.4 秒的**时间余量**；文字内容是否完整仍待听辨。技术响度合格不能证明这些字可听清。

先听[阶段一核验记录](./阶段一核验记录_20261009.md)中的 A/B **干声与最终混音**、卖点句与结尾，共八段音频，然后按结果局部处理：

| 听辨结果 | 修复动作 |
| --- | --- |
| 干声字词正确、混音听不清 | 仅调整 BGM 压低/侧链、口播电平和混音，再导出；不重生动态镜头或 TTS |
| 干声已念错或吞尾字 | 在事实文案定稿后修正 TTS 读法/停顿，仅重生受影响句；重新测量实长、调整字幕和片尾时间 |
| 干声与混音都准确，只有 ASR 误识别 | 保留原始 ASR `fail`；由具名审核人在具体视频哈希上听辨并记录逐字结果、时间及证据，按允许的人工核验机制处理，不伪造机器通过 |

无论采用哪一路，字幕按**最终口播音频**重新对齐。重新跑 ASR、alignment、片尾字词/余量检查及最终技术 QA；如果 ASR 仍错，标记自动核验未通过，并附具名人工核验结论。完整重听 A/B 新版，尤其检查结尾“PLAYBOY，让日常更有质感。”是否读完、可辨认、留有至少 0.4 秒。

## 最小返工与放行顺序

1. 在声明清单中确定每个卖点的“批准原文 / 页面归因 / 删除”，完成事实卡版本与负责人记录。
2. 冻结 A/B v2 文案及字幕；保持两片前三秒的差异，不把未批准的效果词留在标题、字幕或口播任一层。
3. 听辨八段音频后确定修复分支。复用现有 Seedance 动态镜头、BGM 和 Remotion 版式；仅重新生成必要的 TTS 句子与最终合成。
4. 产出 `P1-SELL-A-v2`、`P1-SELL-B-v2`，记录各自文件哈希、事实卡/脚本/音频版本和实际费用；v1 保留，不覆盖。
5. 对 v2 跑完整核验并在审核台重新人工审批。只有事实范围、声音内容、字幕和最终版本审批全部闭环，才改变放行状态。

商品事实确认已完成。当前剩余的人工判断是对已截取干声/混音中真实读音的听辨；其余可以按上面的局部返工流程执行。
