## 参考镜头 × 我的素材

| 表达任务 | 现有素材 | 调整方式 |
|---|---|---|
| 开头提出选购问题 | 提起、翻角、织纹特写 | 第一画面直接有动作，语音尽早开始；具体时间对齐参考测量 |
| 连续展示依据 | 全貌、毛圈、包边 | 一句对应一个视觉证据；删掉动作前后停滞段，在动作落点和句意转折处切镜 |
| 表达触感 | 抚摸素材 | 截取有效接触动作；在不失真的前提下调整速度，不整体盲目倍速 |
| 品牌收尾 | 合格主体画面 | 完整读完 slogan，最后词后至少留 0.4 秒，音乐自然结束 |

现有素材无法表达参考的动作时先登记缺口，方案审核后再用 Seedance 2.5 补镜头。展示动作不能替代真实吸水/抗菌等实测证据。

## 三项改造

节奏：按句意和动作组织长短镜头；去掉空等和冗余停顿；快切段优先比较硬切与现有短转场，保留品牌文字连续性。并非所有片段一律缩到相同时长。

口播：改成短句连续推进，按“问题—可见依据—下一项—品牌收尾”组织；在核心词设置重音，句内少停顿、语义转折保留短停顿。继续用 Doubao TTS，先试听再按实际词时间排镜头，避免仅把音频整体加速。

BGM：分析节拍速度、鼓点密度、音色、进入位置、能量变化和人声间隙；优先选现有批准 SUNO 素材中匹配的部分，不合适再提出 SUNO 新生成方案。学习音乐功能与风格，不直接默认搬用原片音轨。人声为主，口播期间压低音乐；不把当前固定增益值冒充参考片实测响度。

## 可选方向与对照设计

先以 P1-N01 为试验对象，保留现有 V3 为基准：

| 版本 | 改动 | 用途 |
|---|---|---|
| A：连续讲解版 | 重写并重录更紧凑口播，按新口播重剪，保留现有音乐 | 验证整体口播与剪辑调整是否更自然有效；这是组合改动，不能归因为某一个变量 |
| B：音乐推进版 | 固定 A 的口播和画面，仅调整 BGM 选择、入点和混音 | 比较音乐方案带来的听感差异 |

本轮先交方案，不进行付费生成或重渲染。取得原片并补齐实测参数后，先交逐秒表与口播/BGM brief；批准后才制作两版完整对照。新文案、声音、音乐和时间轴改变时生成新版本，不继承旧片批准。
