## 1. 结论与研究检查结果

**优先调整连续讲解、动作与短句的对应关系，再比较音乐方案。当前样片的常见镜头长度已接近参考片，单纯把所有镜头继续缩短，解决不了口播停顿和画面信息不足。**

|---|---|---|

## 2. 分镜拆解：参考片的拍法和节奏

| 区间 | 观察到的结构 | 可以采用的方法 |
|---|---|---|
| 0–13.50 秒 | 悬挂商品、翻标签、水盆动作、独立包装；大字卖点随画面变化。ASR 未识别到连续讲解 | 第一帧就有商品与手部动作；用画面承载信息；不照搬长达 13 秒的前奏 |
| 13.50–18.77 秒 | 换一组画面与较小字幕，先提出日常使用问题，再转向商品 | 短句引出选购关注点，马上接上商品画面；不复制未经证明的卫生或使用寿命结论 |
| 18.77–30.10 秒 | 全貌、手臂触感、毛圈、包边交替出现，连续讲解覆盖多个短镜头 | 一句对应一个可见细节；下一句可以在切镜附近衔接，减少逐段重新起头的感觉 |
| 30.10–35.63 秒 | 回到选购判断、组合展示和交易承接 | 我们用已批准品牌 slogan 收束，不复制对方价格与优惠 |
| 35.63–46.33 秒 | 再次进入大字卖点展示，依次出现吊牌、材质画面、包边、包装 | 适合借鉴单项信息的画面支撑，避免把一个画面重复包装成多个卖点 |
| 46.33–63.20 秒 | 使用、揉捏、包边、浸水拧水、颜色展示；动作较连续 | 动作本身可以推进节奏；若制作真实性能验证，必须另有本商品真实取证 |

完整 30 段候选区间和观察见 `reference_shot_timeline.v1.csv`。这些是参考片结构观察，不是我方商品事实，也不是平台留存或成交效果的证明。

## 3. 口播改造：先连起来，再适度提速

试制目标是**品牌前约 5.2–5.8 个汉字/秒**，保留强调和呼吸位置；相比现有版本提高约 1.6–1.8 倍的内容密度。这个值是我方试制目标，不是直接套用参考的粗估 7 字/秒，也不是将旧音频整体加速 1.8 倍。

- 第一处有效发声争取在 0.1–0.2 秒出现；以实测词时间为准。
- 先写一段连贯文案，再用 Doubao TTS 生成自然衔接的讲解。开头与正文尽量同一次生成、同一声线和状态。
- 普通句间停顿先按约 0.08–0.18 秒设计；语义转折可稍长。超过 0.25 秒的空档进入复核，不作为一刀切失败规则。
- “全貌、毛圈、包边”通过重音和景别变化突出；上方标题只保留关键词，底部显示实际口播。
- 品牌句允许放缓，完整读完后至少保留 0.4 秒。字幕结束不等于尾音已结束，需独立 ASR／波形及试听核验。

### 首版文案建议

> 选毛巾，别光看颜色。提起来，先看整体；拉近一点，毛圈看仔细；翻个角，包边也别漏。再顺着纹理轻轻摸一遍，选之前，把这些细节看清楚。PLAYBOY，让日常更有质感。

品牌前为 53 个汉字；以目标语速估算讲解约 9.1–10.2 秒，再加品牌句、强调与尾音空间，预计成片约 14–15 秒。最终时长由实际 TTS 决定。

此稿强调可见的选购细节。当前 P1 事实快照仍为 `pending_confirmation`，抗菌、棉含量、吸水、防臭等字段仍是 `needs_evidence/page_claim`。本次不把参考片台词或我方待核实字段升级为直接性能承诺。需要更强功效卖点时，应先补对应事实依据。

## 4. 参考镜头 × 我的素材：14 秒左右的动作时间表

以下是编排草图，**不是已经冻结的 final_props**。TTS 生成后按词时间微调，使用半开区间及真实素材入出点，检查慢动作尾段、手部裁切和不同颜色的衔接。

| 预计成片区间 | 画面任务／现有素材 | 对应讲解 | 左上关键词 |
|---|---|---|---|
| 0–1.50 秒 | P1-lift 提起的有效动作立即开始 | 选毛巾，别光看颜色 | 看细节 |
| 1.50–3.00 秒 | P1-W1-full 展示整体构图 | 提起来，先看整体 | 看全貌 |
| 3.00–4.80 秒 | P1-macro 毛圈近景 | 拉近一点，毛圈看仔细 | 看毛圈 |
| 4.80–6.40 秒 | P1-corner 翻角，边缘进入视线 | 翻个角，包边也别漏 | 看包边 |
| 6.40–8.30 秒 | P1-touch 有效接触动作 | 再顺着纹理轻轻摸一遍 | 摸纹理 |
| 8.30–10.60 秒 | P1-edge／整体画面，完成选购判断 | 选之前，把这些细节看清楚 | 细看再选 |
| 10.60 秒至品牌读完 | 两段相容的已有动作承接品牌句，单段约 1.5–1.7 秒；不得超取源素材时长或重复冻结尾帧 | PLAYBOY，让日常更有质感 | 日常质感 |
| 最后发声结束后 ≥0.40 秒 | 保留有效画面和完整 LOGO；音乐自然收束 | 无新口播 | 延续 |

第一轮优先复用既有 Seedance 2.5 动态素材。素材不够长时改选或缩减表达，不用静态图或循环动作补时长。需要新镜头再列出缺口并按 Seedance 2.5 参数预检、预算与样片审批进入主线。

剪辑先沿用已批准的 5 帧 incoming-only 转场和连续品牌层；快切段以动作起落和句意转折确定剪切点。局部硬切作为后续可选调整，不与本轮所有变量一起更换。手部动作只在确有空等时尝试约 1.1–1.2 倍播放，逐段检查，不整片统一倍速。

## 5. BGM：明确推进感，同时保住讲解

### 已测结果与待核实项

参考片混合音轨的频谱变化自相关，在前段得到约 **156／78 BPM** 候选，后段得到约 **167／83 BPM** 候选；口播段的候选很不稳定。这可能来自倍频／半拍歧义、声音事件或段落变化，**不能据此确认原曲 BPM、统一节拍或换过几首歌**。

我方批准 SUNO 素材在前 15 秒的两种信号方法都给出约 **110 BPM** 的候选，后半还有节拍层级歧义。上述仅用于筛选节奏方向；曲名、乐器与“热门”身份均未确认。

### 两档可执行音乐方案

| 方案 | 做法 | 目的 |
|---|---|---|
| M1：现有音乐基线 | 复用已批准 SUNO 素材；A 版只根据新片长调整结尾，维持现有音乐性格 | 先看连续讲解与动作重剪能改善多少 |
| M2：更密的节拍推进 | 若试听 M1 推进不足，再由 SUNO 生成原创纯器乐；试制参数为约 152–160 BPM，也允许约 76–80 BPM 的半拍感；清晰短打击、短低音、稀疏旋律、无歌词、开头即进入节奏、无长铺垫 | 这是我方音乐设计 brief，不能写成原曲鉴定结果 |

SUNO 提示词草案：`Original instrumental background for a concise product demonstration, approximately 156 BPM with a relaxed half-time feel, crisp short percussion, tight restrained bass, sparse melodic phrases, immediate rhythmic entrance, continuous forward motion, clean ending, no vocals, no lyrics, no long intro, leave space for rapid Mandarin narration.`

混音沿用人声优先：从独立音轨测量音乐与口播的相对强弱，口播段可先以音乐低约 10–14 dB 的相对电平试配，再试听调整。不要把 `volume=0.08` 当成已经实测的人声／音乐响度差。两版成片共同瞄准约 -14 LUFS、真峰值不高于 -1.5 dBTP，比较时响度差控制在约 0.5 LU；口播间隙轻抬音乐，品牌句结束后自然收尾。

音乐拍点用于加强关键动作，不要求所有切镜对准鼓点。字音完整、动作连贯优先于机械卡点。

## 6. 可选方向与本轮对照设计

| 创意方向 | 开头和推进方式 | 素材需求 | 本轮建议 |
|---|---|---|---|
| C1：跟着动作看细节 | 选购提醒 → 全貌 → 毛圈 → 包边 → 触摸 → 品牌 | 现有动作素材优先 | **先做此方向**，最容易验证连续讲解改造 |
| C2：买前先看哪里 | 用“毛圈和包边，买之前看清了吗？”这一创作问题引出两项细节 | 可复用现有素材，但文案和排列另立版本 | 作为下一轮开头实验；不得标成已验证用户原话 |
| C3：一个生活动作带出细节 | 从挂起、取下、使用后收纳等情境进入讲解 | 可能需新增合格生活场景动作；性能表述需真实证据 | 待 C1 校准后再扩展，不为凑变化重复拼五段素材 |

首批只制作 C1 的两条完整对照：

1. **A：连续讲解版。** 新文案、新 TTS、按语义重剪，音乐使用 M1。与既有 V3 比较的是“讲解＋剪辑”的组合改进，不能单独归因于语速。
2. **B：音乐推进版。** 冻结 A 的画面、字幕、口播文件和时序，仅替换 M2 音乐方案及相应混音。它检验音乐方案的整体效果，不声称独立分离了曲速、音色、入点、增益的贡献。

若 M1 已达到目的，可以先保留 A，将 B 的新增音乐调用延后。每条仍走正式 pipeline 和审核台；文件、依赖或声音改变时生成新版本，原有通过记录只属于原版本。

## 7. 品牌规范和主线落地

继续使用 `playboy-production-noto-fullscreen-v3`：官方 LOGO 右 72、顶 96、宽 120；Noto Sans CJK SC 已批准替代字体；标题 64px、x=72/y=220、通常 2–4 字；蓝色下划线高 8px、间距 22px、宽度等于实际标题；底部字幕 38px、top=1550。上／下大面积遮罩保持关闭，字幕避免覆盖关键动作。

制作路径继续为 **Seedance 2.5 动态素材＋Doubao TTS＋Remotion＋批准 SUNO 音乐**。当前能力审计确认 Remotion 可用，HyperFrames 在本环境不可用；本轮不更换合成路径。

实施顺序：

1. 将本研究补充与用户选择的 C1/A/B 方案关联到单条 brief、文案及 creative lock。
2. Doubao TTS 生成连贯讲解；记录真实词时间和费用。先核验结尾、错读、密度，再安排镜头。
3. Agent 决定动作区间、强调词与句意衔接；写入 scene plan。不要由脚本按固定秒数自动轮换素材。
4. 将文案、caption、标题 cue、动作入出点、转场和音乐写入唯一 final_props；保留依赖哈希。
5. 【2026-10-08更正】A/B均通过 video_compose 的 ProductionBrand 完整渲染。原稿承诺的 mux-only 不适用于当前路径；两版通过共享画面与口播输入保持对照。实际记录：[A render receipt](../rhythm-ab-20261007/A/render_receipt.v1.json)、[B render receipt](../rhythm-ab-20261007/B/render_receipt.v1.json)，两者 render_mode 均为 full。
6. 运行技术、品牌、ASR／alignment、尾音、转场与 video_judge；失败、未运行、工具错误如实保留。人工核验不能改写机器结果。
7. 审核台并排查看 V3/A/B，先按正常速度、相近响度看完整片，再核对前三秒及接缝。

本轮分析没有发起 Seedance、TTS 或 SUNO 的付费生成。A 预计需要一段新 TTS 和一次完整渲染，优先不新增视频素材；B 若换音乐，需要一次批准的 SUNO 生成／选曲及重混音。实际调用预算在执行时按既有估算与账本记录，未知成本不填零。

## 8. 验收和后续批量固化

本轮重点检查：前三秒是否已经有有效动作和明确问题；开头接正文是否还空等；一句话是否对应正确商品细节；口播能否在手机正常音量下听清；音乐是否抢字；标题与字幕是否重复或重叠；品牌尾句是否完整。

可固化成检查项：真实口播起止、超长间隙提示、字速统计口径、标题安全区、尾音余量、依赖哈希、固定口播的音乐对照、源素材区间与实际成片差异记录。

继续留给 Agent：哪一句值得强调、何时切镜更自然、哪段动作成立、什么场景能表达事实、音乐是否适合本条内容。不能把“每镜 1.75 秒”“每条 7 字/秒”“156 BPM”变成 300 条的统一规则。

先用 A/B 得到制作层面的人工判断；发布后再用前三秒留存、完整观看、点击等同口径数据评估吸引力，并记录投放条件和内容差异。没有这些结果时，只能说完成了制作优化，不能承诺爆款或成交提升。
