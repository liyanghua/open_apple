## 三个选择

| 选择 | 收益 | 限制 |
| --- | --- | --- |
| A. 逐帧旧字/干净结构分离，复用现有候选（推荐先验证） | 不新增模型费用，尽量保住原本存在的亮边和木纹 | 无法保证真正被字覆盖的木纹变清晰；错误判定会把旧字带回来 |
| B. 新的受控重建候选 | 可尝试改善真正被遮住的纹理与结构 | 需单独批准模型、上传与预算；没有成功保证，不默认执行 |
| C. 保留 v3 不再修补 | 不增加开发和推理成本 | 接受当前补丁和亮边缺口，不称为无痕去字 |

## 推荐 A 的验证边界（方向已确认，先实现证据阶段）

仍是首镜 38 帧、同一候选、相同外层允许编辑区 `M`。不改脚本、口播、其余镜头或节奏。

- 在 `M` 内区分：明确旧字及其描边/阴影、明确干净原片结构、不确定区域。
- 只有经逐帧证据和审核确认的干净区域才能释放回原片；旧字和不确定区域继续使用生成重建。
- 不能只靠亮度阈值判断：白色旧字和桌垫高光都会很亮；也不能简单腐蚀掩码或把 v1 掩码直接拿回来。
- 实际修复区 `R[t]` 只能是 `M` 的子集。生成仍只用已有 d032 候选；先验证去字与结构，不叠加模糊条带。
- 这会有意修订 d034 的“完全不使用 M 内原片”规则：改为“只能使用经证明无字的 M 内原片子集”。
  旧版工具默认行为和历史契约不得静默改变，新增模式必须显式选择并保留证据。
- 第一份交付是 38 帧区域分类/保护区审核图，不直接提交一条所谓完成的 v4。审核证明不了干净，就不释放那部分原片。
- 通过后才在独立分支按先测试、后实现的顺序接入合成，输出首镜新旧对照、逐帧区外一致性报告及动态审核片。
- 若文本核心区域仍有模糊，明确报告 A 的上限，不继续用局部调色冒充解决，也不自动转 B。
