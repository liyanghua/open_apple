### 旧烧录字幕的前置阻塞

原片旧字约在 y=982–1028。去掉黑底并下移新字，不会移除这些旧字，可能暴露“2mm”等未采用声明。因此复用镜头暂不能直接套新字幕交付。

优先方案：使用与当前原片相同剪辑的无字母版；必须逐镜核验帧数、构图和动作映射，不能盲目替换路径。

若没有无字母版：另行确认只对旧字幕字形区域做局部时序修复的小样；先试 1 镜，检查文字残影、木纹拉伸、桌垫边沿与手部，不合格不批量。不默认整片 AI 重绘、不用大块模糊或黑条遮盖、不大幅裁切画面。局部擦字会改变字形所在像素，不再宣称逐像素完整保留。
