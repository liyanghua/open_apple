# s01 时序去字试验：不通过

日期：2026-09-25。范围：能力开发验收，不是制作素材放行。

## 结论

本地源像素借用工具可以安全输出诊断文件，但**当前配准算法不能完成这段实拍的去字**。旧字幕几乎完整保留。暂停后续付费生成、批量去字、混音与成片组装；此版本不需要用户作为合格样片审核。

## 为什么失败

共尝试 456 组 donor 配准：

- 309 组未形成足够的 RANSAC 一致匹配。
- 124 组没有足够的干净双向跟踪点。
- 17 组虽可配准，但字幕附近没有足够可信的局部像素证据。
- 1 组运动/空间支撑不可靠；只有 5 组实际复制了少量像素。

八组局部对照中旧字幕和黑色描边仍清楚可见，因此拒绝。未进入正常速度的人工作品验收；不把“可播放、区外不变”当成去字合格。

画面包含桌沿、桌体、地面等不同深度的区域。结合失配统计，当前单一局部近刚性运动假设和严格支撑条件不适用于这段画面。这是**现有算法没有找到可信对应**，不能据此断言原片中所有被遮背景都从未出现，也不能通过降低门槛就声称修好了。

## 已补齐与仍缺失

已补齐：工具注册、源帧/掩码校验、有界资源和子进程、同镜头约束、像素来源追溯、部分恢复标记、无损区外保护验证、失败诊断留档。

仍缺失：达到真实桌沿/木纹质量要求的时序背景重建。当前版本只能作为保守源像素借用和诊断能力，不能接入全片自动放行。

## 下一步决策，不自动执行

1. **继续纯源像素路线**：升级分区域/多平面的运动配准；不新增生成费用，但是否能补全全部字幕区域仍未验证。
2. **局部时序生成修复**：只重建字幕遮挡区，掩码外强制回贴原帧，再验证跨帧一致性和桌沿连续性。需要先确认用户是否接受该方式，再核验具体模型的商用许可、能力、费用与预算，单独批准后只做首镜试验。

建议评估第 2 条路线，不再把当前局部配准工具当作完整去字方案。没有调用任何新模型；没有默认使用非商用模型，也没有重复提交此前被服务商拒绝的参考输入。

只有首镜通过后，才恢复 s06 的长方形桌面/柔软桌垫重做，再处理其余片段、添加已批准的无黑底下移字幕、复用已确认的豆包口播并组装。
