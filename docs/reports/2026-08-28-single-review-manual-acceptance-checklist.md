## 走查步骤（每档宽度重复一遍）

准备：浏览器 DevTools 设置为 1180px、900px、390px。每档检查下面 1–8。

1. **首屏任务**：打开页面即可读到“现在需要你确认什么”（状态标题 + 说明），不需要先看项目进度。
2. **九步 rail**：横向轻量进度，只有“确认脚本 / 确认制作准备 / 查看样片”三个人审门高亮；等待门显示“现在需要你确认”。
3. **材料列表**：样片门出现 样片/镜头对照/字幕和口播/声音效果/系统检查/系统建议/制作依据 七项；点击可选中查看。
4. **视频与说明**：播放器可播放样片；下方有“画面和声音对照”时间线（点击片段可跳转）；“确认通过后 / 退回修改后”两张流程说明可见。
5. **五项确认**：创意方向/开头/证明/节奏/字幕，每项只能选 通过/需要修改/不通过；未全通过时“确认通过，继续制作”不可点，只能“退回修改”。
6. **审批动作**：通过 → 刷新后进入下一步（等待状态消失）；退回并写意见 → 提交后出现“调整意见已提交”，随后可重新拉取。
7. **异常恢复**：样片缺失/播放失败/报告不完整/权限变化时，先看到中文原因，再看到“重新拉取”入口；提交失败不会显示“已通过”。
8. **布局**：无横向滚动、长中文不截断；390px 下确认动作在内容之后且不遮挡最后一项确认；每档均无重叠。
