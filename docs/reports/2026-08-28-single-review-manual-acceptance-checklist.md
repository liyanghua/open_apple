## 走查步骤（每档宽度重复一遍）

准备：浏览器 DevTools 设置为 1180px、900px、390px。每档检查下面 1–8。

0. **阶段产物完整性**：在调整宽度前，逐个点击九个阶段，确认每阶段至少有一个业务材料且内容不重复、不含工程字段。按以下基线核对（契约见 spec §9.5）：
   - 了解任务：研究步骤、参考片重点（可播放）、参考片分镜、素材情况（可预览）、素材风险、镜头与素材匹配、检查结果；
   - 看创意方案：采用方向（目标人群/语气/画面做法/为什么有效/行动引导；未选择方向时必须显示“尚未选定方向”，不得默认取第一个方向）、备选方向（未选择时列出全部方向）、卖点（仅从已选方向派生）、导演总控单（五章摘要与规则）、预计成本；
   - 确认脚本：制作脚本按开场/正文/结尾呈现口播、字幕、段落目标、画面重点、节奏、证明要求；“口播/屏幕文字”卡只有数量和“打开制作脚本”入口，不重复正文；
   - 看分镜：镜头安排含镜头目的、参考依据（含描述与参考时间区间）、素材能证明什么、安排理由，且“成片时间轴”与“源素材区间”分开显示；“参考片段预览”与“自有素材预览”是两个独立媒体动作；动作和时长只显示成片时间轴；
   - 确认制作准备：生成清单（状态/原因/付费标记/预计费用）、画面素材、生成任务（真实任务状态：排队/生成中/需要确认/已完成/生成失败 + 任务质量 + 预览 + 实际费用 + 失败原因 + “已用于本镜头”标记；有方案无任务显示“尚未生成”）、口播和字幕覆盖、音乐和费用（预计费用与已用费用分开）；
   - 查看样片：样片可播放、镜头对照（只显示差异与素材身份）、字幕和口播（计划口播/实际口播/计划字幕/实际字幕分开显示；实际缺失显示“实际口播未提供”，不得显示成计划内容；字幕差异 + 导演规则差异）、声音三轨、系统检查、系统建议、制作依据；
   - 完成剪辑：剪辑结果（修改前样片可播放）、镜头顺序（字幕/口播/预览）、声音和字幕、成片检查就绪结论；
   - 检查成片：完整视频（播放 + 下载）、画面声音对照时间轴、质量结论（检查结论 + 观感维度）、版本变化、待处理问题；
   - 确认交付：交付视频（播放 + 下载）、文件信息、平台和下载（平台/状态/标题/导出下载）、交付文件（下载按钮）、QA 证据（下载按钮）。
   若任一项缺失、错位或工程字段（plan_id、control_rule_refs、模型名、路径）出现在正文，停止本轮验收并记录为代码整改项。

1. **首屏任务**：打开页面即可读到“现在需要你确认什么”（状态标题 + 说明），不需要先看项目进度。
2. **九步 rail**：横向轻量进度，只有“确认脚本 / 确认制作准备 / 查看样片”三个人审门高亮；等待门显示“现在需要你确认”。
3. **材料列表**：样片门出现 样片/镜头对照/字幕和口播/声音效果/系统检查/系统建议/制作依据 七项；点击可选中查看。
4. **视频与说明**：播放器可播放样片；下方有“画面和声音对照”时间线（点击片段可跳转）；“确认通过后 / 退回修改后”两张流程说明可见。
5. **五项确认**：创意方向/开头/证明/节奏/字幕，每项只能选 通过/需要修改/不通过；未全通过时“确认通过，继续制作”不可点，只能“退回修改”。
6. **审批动作**：通过 → 刷新后进入下一步（等待状态消失）；退回并写意见 → 提交后出现“调整意见已提交”，随后可重新拉取。
7. **异常恢复**：样片缺失/播放失败/报告不完整/权限变化时，先看到中文原因，再看到“重新拉取”入口；提交失败不会显示“已通过”。
8. **布局**：无横向滚动、长中文不截断；390px 下确认动作在内容之后且不遮挡最后一项确认；每档均无重叠。
