## 3. 原声如何转成可用开场

采用以下流程：

`原声记录 → 购买任务/阻力 → 本片可兑现承诺 → 开场候选 → 素材与证据检查 → 开场包 → 固定主体 → 审核与实验`

### 3.1 三种来源，分别标记

| 来源类别 | 保存内容 | 展示边界 |
| --- | --- | --- |
| 文档摘录 | 文档版本、段落/编号、原文、原评论对象、平台链接或缺口 | 来源仍未核验时明确标记，不称本品牌真实买家证言 |
| 问题改写 | 父原声 ID、提炼的购买问题、改写内容、增删及类比说明 | 可以用消费者语言提问，不冒充逐字引语 |
| 创意假设 | 创意依据、适用人群/场景、待验证事项 | 没有原声时留空引用，不补造来源 |

来源真实性状态与创意类别分别记录：即使确实引用了原手册，仍可能是“文档摘录、平台来源待核验”。评论去重后才能分析频次；原手册的估算提及数不作为需求占比或排产权重。

### 3.2 与两片有关的线索

| 原声编号 | 文档内可定位的短摘录 | 可以启发 | 不能证明 |
| --- | --- | --- | --- |
| XHS-01 | “买了好多种毛巾手感都不对” | 买前希望理解材质与细节，存在判断困难 | 看织纹就能判断真实触感；本品手感更好 |
| XHS-19 | “有没有其他颜色呢” | 颜色是某些用户关注的选项 | 用户普遍只看颜色；本品当前颜色与库存 |
| DY-38 | “都没这么细节” | 有人会注意细节与价值感 | 本品优于其提到的其他商品；价格比较成立 |

“买毛巾，还只看颜色？”等建议属于基于线索的创意改写。原声没有直接证明这个问题覆盖广泛人群，是否有效要由后续数据回答。

### 3.3 候选筛选

每个母片先形成 12 条纸面候选，共 24 条；先过事实与承接门，再按五个维度排序：

1. 购买相关：是否吸引本商品的潜在用户。
2. 首帧明确：无需等待，能看懂对象和动作。
3. 承诺明确：继续看能获得什么。
4. 后文兑现：存在对应画面或证据，而非只制造悬念。
5. 表达独立：与同组其他候选存在可感知的创意差别。

每片选择三个新候选进入分镜；保留未选候选及拒绝理由。排序是制作决策，不是预测爆款概率。下节保留八版工作稿；A01-H1、A03-H3 已先行制作动态预览，未完成其余候选、整组筛选材料或新版本审批。

A01-H1/H2 与 A03-H1/H2/H3 可以参考上述原声线索，但都属于改写或推演。A01-H3 主要来自可用动作与剪辑设计，标创意假设；B0 是已有制作表达，不强行挂原声 ID。

A01-H2 的“差不多”只表达同款远近观看的反差，不加入两品牌、两规格或性能对比暗示。如人工审核认为语义仍易误解，缩窄为“远看一眼，近看呢？”，保留修改记录。

口播工作稿经实际 TTS 后校准：超时先缩句，不靠异常加速挤进三秒。整组保持同一声音、语气基调及响度目标，语义所需的重音可随开场包变化。

采用新版 H1 动作后，A01-H1 与原 A01-H3“拎起看看”存在动作趋同风险。完成八版分镜前重审 H3 的观看目标、景别或动作设计，保留取舍理由，不能只换一句口播就宣称形成了三个有效新方向。

### 4.2 三秒的共同节拍

| 时间 | 信息任务 | 制作约束 |
| --- | --- | --- |
| 0–0.5 秒 | 识别商品与正在发生的动作 | 不用黑场、片头或缓慢出现的标题占用首帧；口播尽早进入 |
| 0.5–1.5 秒 | 建立一个具体问题或观察目标 | 一次只讲一个问题，避免健康恐惧、无关悬念 |
| 1.5–2.7 秒 | 提供第一处可见细节 | 画面响应口播，不让字幕独自承担内容 |
| 2.7–3.0 秒 | 结束开场发音并衔接主体 | 预留声音与转场空间，不在句中切开 |

时间段是信息节点，不是强制切镜节点。默认 1–2 个主要镜头；不将六个 0.5 秒格子机械渲染成六次切换。

新增 `hook` 节奏角色，与主体 `body` 分开校验。主体继续沿用 1.8–2.6 秒镜头规则；开场允许更短的动作截取，须在分镜中写出时间和目的。新规则不能反过来放宽全片主体节奏。

### 4.3 素材获取

1. 先审查现有 full、lift、macro、edge、touch 五段素材，标出可用源时间区间及构图。
2. 不通过放大裁切冒称获得更高真实细节；视觉不足时记录素材缺口。
3. 优先为动作开场和指向包边补缺；本轮两段新的 4 秒动作已生成。先审核和复用，不自动再次提交；是否存在新缺口由动作与成片检查决定。
4. 新动作继续使用绑定 SKU 的已核对参考图，保留原图、处理记录、参考哈希和生成任务 ID。
5. 模型只生成商品与动作，LOGO、标题、下划线和字幕由合成层加入。

新增实测承诺需要另立母版及真实取证，不通过 AI 生成湿度、掉毛、霉菌或吸水变化来补证。

### 4.4 动态镜头契约（B1/B2 已实现，实片审核待完成）

对被定义为动作开场的镜头，不能仅以“文件为 MP4”“来源是视频模型”或全画面有像素变化认定合格。画面必须完成声明的商品/手部动作，且动作在最终构图和三秒窗口内可见。

每个动作镜头保存以下计划字段，并在生成后绑定实际源片哈希和检查证据：

| 字段组 | 必需内容 | 核验方式 |
| --- | --- | --- |
| 来源与身份 | `source_kind`、模型/任务 ID、商品/事实版本、参考图哈希、素材哈希 | 代码校验引用与版本；商品一致性结合视觉核验 |
| 动作意图 | `motion_required`、`subject`、`action`、`start_state`、`end_state` | 明确是主体动作、镜头运动还是二者组合；不混为一项 |
| 节拍 | 计划动作开始/关键变化/完成区间，选取的源时间区间与播放速度 | 对最终预览逐段核对，TTS 时间轴独立绑定 |
| 可见结果 | 要露出的毛圈、织边或折角，以及允许遮挡范围 | 按最终输出而非只看原始方形源片判断 |
| 边界 | 不可改变的颜色、纹理、装饰织边、包边、手指数与物理接触要求 | 手部穿透、布料变款、关键动作缺失进入返工 |
| 检查 | 原始状态、方法、观测到的动作时间、证据区间、问题和审查者 | 机器未运行仍为 `not_run`，人工记录不改写机器结果 |

执行方法：

1. 生成前按起始状态→单一主要动作→结束状态写提示词；默认 4 秒源片，围绕三秒窗口设计，不要求模型同时完成多个复杂动作。
2. 以 0–0.5 秒内看见动作或商品状态变化为本轮创作目标；实际开始时间需要测量。这是待校准目标，不是已验证的通用留存阈值。
3. 先在无品牌遮罩的源片里判断主体运动，再在成片里判断动作是否被裁切、标题或字幕遮挡。抽帧辅助定位，关键动作还要连续播放或检查连续帧；采样不足时不能自动通过。
4. 运动分析先排除全局镜头推拉和背景变化，再辅助检查主体区域。运动量、光流或重复帧检测只能预警，不能单独证明手部自然、商品未变款或有吸引力；数值阈值用后续校准样本确定并版本化。
5. 仅静态图缩放、镜头缓移而主体不动、动作在截取区间外，均不能满足声明为 `motion_required=true` 的镜头。允许静物观察的其他类型须在分镜中明确标记用途，不滥用本条强制全片“都动”。
6. 缺少动作时先换合格源区间；动作本身失败才局部重生成。保持任务幂等和预算限制，不重复提交结果未知的远端任务。

本轮用户明确要求 Seedance 2.5 动态生成；不能静默降级为图片拼接或用另一模型补位。已有动态素材可复用，但必须实际满足本片动作，而不是因为素材池已有文件就认定无缺口。

### 4.5 竖屏构图与参考图适配（B3 已实现，构图需逐片审核）

生成前确定 `source_aspect_ratio`、`output_aspect_ratio`、`framing_mode`、主体安全区、手部/包边需要保留的区域，以及标题/LOGO/字幕禁遮区。检查必须覆盖动作关键区间，不能只验第一帧。

| 适配方式 | 使用条件 | 本轮状态 |
| --- | --- | --- |
| 原生竖屏生成 | 模型/参考输入组合兼容，商品身份与动作完整性通过首件验证 | 未在这两条新预览中验证；另行核对规格与费用 |
| 方形源片裁切铺满 | 整个动作区间中，商品关键部位和必要手部均在竖屏安全区内 | 本次直接放大会裁掉部分动作，不适用 |
| 完整动作保留＋动态背景填充 | 裁切会损失信息，且审核接受此构图 | 本次预览采用；主画面 1080×1080、y=350，同源模糊动态背景；仍待审 |

将适配能力接入共享合成组件的参数，不再每条复制、改写一份项目 TSX。品牌坐标继续来自同一 profile；改变商品展示区域属于候选版本变化，需新审核。容纳方形素材不能被描述成“原生竖屏生成”，画面放大也不等于新增真实纹理细节。

若改变参考图或生成比例，需要重新核对商品身份、输入兼容性及费用；不在失败后未经记录地切换。当前预览构图通过后，也只代表相应类型的可用布局，不自动成为 300 条唯一排版。

## 5. 实验基准、主体冻结与品牌声音

### 5.1 建立可比较的基准

- 两条原验收 MP4 和原审批保持不可变，标记为实验来源。
- 新建 A01-B0、A03-B0，修正口播边界并生成固定主体。它们是新实验基准，不声称与原成片逐帧相同。
- 30fps 下开场窗口定义为半开区间 `[0,90)`，固定主体为 `[90,end)`；其他帧率按三秒对应整数帧计算。
- A01 保留“再看织纹”及 slogan；A03 保留“再看包边，细节一眼可见”及 slogan。
- 优先维持 8／9 秒。若实际词时长与尾音条件不足，先修改共同基准并使同组四版等长，重新审核后再渲染变体。
- 基准通过后才冻结主体，不能一边生成变体一边修改共同后文。

### 5.2 冻结内容

| 允许在开场包内变化 | 同组必须保持一致 |
| --- | --- |
| 开场画面、镜头顺序、动作截取 | SKU、事实版本、商品身份与参考图边界 |
| 开场口播与同步字幕 | 第 3 秒后口播内容、声音片段和时间轴 |
| 开场关键词 | 第 3 秒后画面、标题、字幕、结尾、总时长 |
| 必要的开场声音细节 | 品牌 profile、BGM 曲目与时间位置、混音规则、承接路径 |

第一轮默认不新增变体专属音效，先减少声音上的无关差别。BGM 从全片同一时点播放，不随开场长度重新起算。开场口播的压低音乐包络不得延伸改变固定主体；边界处必要的包络统一写入基准。

5 帧接入转场在开场范围内完成；进入第 90 帧时已处于固定主体状态。若现有合成器不能做到，先实现并测试接入能力，不能把主体首五帧变化默认为允许。

冻结校验包含源素材区间、镜头参数、字幕/标题时轴、音轨与固定主体合成内容。合成前确定性画面和 PCM 可做一致性比较；压缩后 MP4 字节可能因编码上下文不同而变化，不直接拿文件字节比较主体。成片仍需解码检查接口与音画连续性。

### 5.3 品牌规范

以已批准生产基线及对应品牌 profile 为运行依据：

| 元素 | 固定约束 |
| --- | --- |
| LOGO | 官方资产；右侧 72px、顶部 96px、宽 120px |
| 左上标题 | 通常 2–4 字；64px；x=72、y=220；不重复整句口播 |
| 下划线 | 与实际标题宽度一致；高 8px；间距 22px；`#4874CB` |
| 口播字幕 | 38px；沿用左右 72px、顶部 1470px 及批准安全区 |
| 字体 | 绑定 VI 指定字体文件、家族、版本和哈希，禁止静默回退 |
| 转场 | 已批准的 5 帧实现；品牌层连续，不随每次切镜整体淡出 |
| 结尾 | “PLAYBOY，让日常更有质感。”完整读完，末词后至少 0.4 秒 |
| 输出 | 1080×1920、H.264、AAC；真实记录素材分辨率与裁切放大 |

不得恢复已被后续意见替代的中央事实横栏、无信息底栏、固定短横线和规格核对式结尾。

旧样片通过外观审核，不表示字体身份已认证。本轮正式交付继续执行严格字体与检查要求；缺失时在审核台展示具体阻塞。

2026-09-28 两条预览沿用用户允许的旧样片字体外观，字体身份仍为 `not_run`；这是本次预览范围的处理，不解除正式量产的严格字体要求。新增加的完整动作保留布局尚未获得用户审核。

### 5.4 从三秒预览接回完整片（B4 已实现，完整实片待验证）

- 三秒预览是审查开场的交付物，不作为整片拼接的唯一素材。保存原始 Seedance 视频、未混合口播、词时间戳和 BGM 引用，完整片从这些输入重新合成。
- 本次独立预览的音乐结尾有淡出；不能把预览末端淡出和压缩音轨直接拼入完整片，造成第 3 秒音乐下陷或重复压低。整片统一混音，BGM 同组同起点连续播放，尾部淡出只发生在全片结尾。
- 先生成并审核两个共同基准的固定主体，再输出开场变体。接合检查至少覆盖 2.5–3.5 秒及完整口播，检查动作方向、构图、曝光、重复帧/黑帧、文字层连续、音频断裂和词尾。
- 转场在 `[85,90)` 内结束，第 90 帧开始共同主体状态一致；需要改变该约定时修改共同基准和全部相关版本，不能让某一变体越界。
- 开场预览无需完整片 slogan；最终全片必须完整读出“PLAYBOY，让日常更有质感。”并留至少 0.4 秒。前者不因缺少 slogan 失败，后者不能继承预览的豁免。
- 对最终解码画面与音轨进行完整检查；固定主体的源文件相同，不代表跨边界混音和合成结果必然相同。

## 6. 与 300 条内容布局的关系

### 6.1 数量不扩张

继续保留同一批 300 条的不同维度：三 SKU 为 S01/S08/S04＝100/120/80；四周各 75；实验 240＋支持 60；六方向为 90/75/60/45/15/15。

本轮八版登记为试点，不抵扣原 SKU 配额。八个测试版本包含两个基准与六个开场变体，不自动等于八条新增独立作品，更不等于八次成功复验。

W1 本身就是 15 母版×4 开场＝60 条实验内容，再加 15 条支持内容。开场优化进入这 60 个原槽位，不把 300 条再乘四。

### 6.2 不同周次分别使用

| 周次 | 开场在实验中的角色 | 约束 |
| --- | --- | --- |
| W1 | 同母版四个开场包探索 | 同组后文固定；四版不算四次独立复验 |
| W2 | 新场景、关系、空间和轻玩趣表达 | 可以联动内容变化，标记组合探索，不声称只测开场 |
| W3 | 根据结果预登记一个待优化变量 | 可选开场、证据或承接；只改已登记模块 |
| W4 | 人工／AI 制作路径比较 | 同简报、同钩子和同事实要求，避免把不同创意混入路线比较 |

不同类型的开场从母题出发：实测型提出可验证问题；微仪式型给出具体生活触发；关系型建立人物处境；空间型给出空间限制；轻喜剧给出生活反差；FAQ 回答真实问题。原 18–35 秒主体和各自节奏仍保留，不把全批压成 8／9 秒。

首轮八版完成后，方法进入 W1 原有校准安排。此前规划的 W1 首 30 条和每批 5–10 条节奏继续保留，具体释放受原 SKU、素材、预算与类型首件条件约束。

主要扩展 `lib/hook_plan.py`、`lib/differentiation.py`、`lib/candidate_diversity.py` 和品牌合成校验；相关 schemas 同步版本化。审核展示接入现有 production reviews/campaign 页面，使用 `backlot/operator_reviews.py` 中的 ReviewService 与 `backlot/delivery_versions.py` 中的交付验证。按第 11 节拆成契约、渲染、质量、工作台四个可验证部分。

原声清洗、候选筛选、开场与后文匹配、局部返工写入现有 research/proposal/script/scene/compose 阶段 skills；代码不替 Agent 决定具体创意。开发在独立研发分支完成并通过测试后，再开启真实生产。

### 7.4 谁决定什么

| 代码固化 | skills 固化 | Agent 创作与判断 |
| --- | --- | --- |
| 版本、区间、字体、字幕、尾音、素材身份、预算、冻结项、审批失效、结果口径 | 原声改写方法、候选比较、三秒节拍、承接检查、素材缺口与最小返工流程 | 具体问题、句子、首镜、动作、重音和剪点 |

Agent 每次选择应能解释“为什么适合这个母版”和“后文在哪里回答”，而不是只给一句“更有爆款感”。

本次临场经验的处理方式：

| 本次处理 | 应固化内容 | 继续由 Agent 决定 |
| --- | --- | --- |
| 用户指出旧素材过于静态后重新生成 | 动作必需标记、来源/生成意图、主体运动证据和禁止静态替代 | 最适合钩子的具体动作与提示词 |
| 提起/翻角的动作设计 | 起止状态、动作节拍和身份限制的 skill 方法 | 提起、翻折、铺开或其他合理动作，不固定成每条套路 |
| 截取源片约 0.25–3.25 秒 | 源区间合法性、字幕/语音绑定与不截尾检查 | 根据实际素材选起点，不把 0.25 秒写成全局常量 |
| 为防裁掉手部调整 TSX | 共享构图模式、动作安全区检查、统一品牌组件 | 在通过的模式中选择构图；新模式先过首件 |
| 沿用旧字体外观完成预览 | 预览范围、字体状态、正式交付门禁 | 不能自行解除 strict 字体约束 |
| judge 非法 JSON 后重试一次 | 限次修复、原始错误、成本、具名人工核验入口 | 解释错误之外的内容问题，不能补造分数 |

## 8. 审核台与质量验收

每个母版显示 B0/H1/H2/H3 四张卡，默认先看前三秒；支持静音循环、带声预览、完整成片、版本差异和来源展开。成片审核仍绑定逐条具体版本。

必须展示：开场文案、关键词、来源类别与核验状态、承诺及兑现位置、变化内容、固定主体是否一致、质量原始状态、费用和实验状态。

人工先回答六个问题：

1. 第一眼能否看懂商品及动作？
2. 这个问题是否与潜在购买者有关？
3. 继续观看能获得什么是否明确？
4. 静音是否仍能理解主要信息？
5. 后文是否兑现，而非只重复提问？
6. 三秒接口是否断字、闪烁、跳动作或声音突变？

内部评分可以辅助排序，但不显示“预测爆款概率”。按钮与状态分开：制作通过、待流量测试、测试中、候选、复验通过、样本不足、停止；不把内部批准自动变成经营胜出。

机器与内容检查继续保留 `pass/fail/not_run/error`。具名人工替代仅用于既有规则允许的内容项，不能覆盖字体缺失、事实缺口或解码失败。旧样片历史缺失项如实保留，新版本不能继承为自动通过。

### 8.1 预览、完整片与批量放行分开

| 范围 | 可以确认什么 | 必须保留的边界 |
| --- | --- | --- |
| 开场预览反馈 | 动作、首帧、问题表达、三秒节拍及品牌可读性 | 文件必须可播放；缺失检查公开；不写完整片批准，不占交付数 |
| 完整实验版本审核 | 开场兑现、接口连续、冻结主体、全片语音与结尾、全部必要检查 | 绑定具体成片和依赖版本；只读源片和抽帧不替代完整检查 |
| 批量生产放行 | 对应 SKU、类型首件、事实、素材、预算、检查与人工审批均就绪 | 试点预览通过不释放其他类型/SKU，不证明留存效果 |

检查范围须预先声明。没有价格/参数声明的三秒开场，其对应核对项可以在适用性表中记录“不适用及理由”，但原始检查仍保留真实状态，不把 `skip/not_run` 改为 `pass`；存在商品事实主张时不能借此豁免。新范围规则必须经契约测试验证，不能在看到低覆盖率后为单片临时降低阈值。

字体与文本布局使用实际渲染浏览器的字体加载及 DOM/像素证据，口播使用独立 ASR/词边界检查；TTS 返回的文本和时间戳不能证明最终音轨完整。主体动作、商品自然度等语义检查允许按既有政策由具名人工核验，但必须保留原自动结果。

自动视觉评估非法结果最多一次格式修复重试；再失败标 `error`，进入待人工核验。Agent 抽帧观察不能冒充具名人工批准。当前两条可供创意反馈，但正式样片门禁仍未完成。

## 9. 小流量实验与结果解释

### 9.1 启动前实验卡

须记录：母版/四个候选及版本、发布或投放平台、账号、受众/流量分配方式、商品承接、预算上限、读取窗口、主要指标、护栏指标、有效样本要求、停止条件和负责人。

平台与实际预算尚未确定，当前保持待补。默认先通过人工导入平台原始导出数据接入系统，不开发自动投放器，也不使用浏览器直接开启广告。

### 9.2 指标

| 指标 | 用途 | 解释限制 |
| --- | --- | --- |
| 三秒留存/平台对应指标 | 开场主要比较项 | 先核对分子、分母、计数单位及平台定义；不把曝光与播放起始混用 |
| 五秒留存 | 检查开场到主体是否接住 | 不能仅靠前三秒刺激抬高数据 |
| 整体完播与观看时长 | 检查全片表达 | A01 与 A03 分组；不跨 8／9 秒与 18–35 秒直接排名 |
| 商品点击 | 观察是否吸引到合适用户 | 明确按曝光、播放还是其他口径计算 |
| 制作与媒体费用 | 判断获得有效结论的成本 | 费用全留账，包括被淘汰候选 |

三秒指标若平台不提供，先记录不可用，不用另一项指标静默代替。联合方案的 55% 仅保留为来源文件中的待测参考，不作为统一通过线。

先用同组基准可读数据及希望辨别的最小改善幅度确定样本量；把计算依据与多候选比较方法登记后再作统计结论。金额不足以获得样本时，应缩小后续测试规模或保留未定，不事后降低门槛宣布赢家。

### 9.3 测试和复验

- A01 与 A03 分开比较，每组四版尽量保持账号、受众、商品承接、预算分配及窗口一致。
- 默认 24／72 小时记录快照，不把这两个时点自动视为有效样本已经足够。
- 第一轮筛选候选；再以候选与基准在新窗口独立复验，复验前不标稳定赢家。
- 如平台无法给出可比流量，标探索性观察并记录时间/人群差异，不能宣称随机对照的因果效果。
- 达到事前预算上限即停止；样本不足、字段缺失或分配失衡分别记录，不补造结果。

结果回写对应模块：三秒弱而后段好，继续改开场；三秒强而后段掉，优先修承接与承诺；完播好而商品意图弱，重审购买理由；点击好而成交差，检查同款与交易承接。改变主体后开启新实验版本，不混入原冻结组。

## 10. 成本、复用与作品计数

首轮费用拆为：共同基准整理、六个新开场增量、必要新增素材、TTS/语音核验、合成/检查、人工审核与流量测试。研发成本另列。

共同主体和已有素材池只计一次，并保留复用关系；不能将同一笔历史成本完整重复分给八版。每版另报增量成本与分摊后的完整成本。预算、预占、目录估算、实付继续分开，未知实付为 null。

新增动作最多两段是素材需求上限，不是价格或付费调用次数保证。创意返工继续受既有最多追加两次及批准预算限制；若预算不足先停止，成功但淘汰的素材仍计费用。

2026-09-28 已使用这两个新增动作名额。每段回执 87,300 token、目录估算 6.111 元，共 174,600 token／12.222 元；引用当前生产记录的估算，不声明已结算或今后价格不变。新增 TTS、评估、渲染、Agent 工作和人工成本分别列账，不能把这 12.222 元当成两条完整视频的全部成本。

当前五段旧素材加两段新动作不足以证明可支撑 300 条。每个母题重新评估缺口；优先复用合格主体、声音和匹配的素材，对缺失的动作、场景或证据补充生产。共享准备成本只计一次，所有被淘汰但已成功生成的素材继续计费。

W1 校准报告按 SKU/类型/动作难度分别统计：

- 镜头首次合格率、最终合格率、每个合格镜头的付费尝试数及失败原因；技术成功率与创意合格率分开。
- 每条合格成片的新增生成成本、直接增量成本及含人工/摊销成本；同时保留未结算金额和估算来源。
- 排队、远端生成、下载、TTS、渲染、自动检查、Agent 主动工作、人工等待与返工耗时；耗时中位数/分位数标明样本量。
- 同组开场的实际差异、素材重合度、待审积压与人均审核耗时，不以“每天提交多少任务”代替有效产能。

现有并发上限 2、任务幂等和预算机制继续复用。吞吐量需由本机渲染、远端配额和人工审核的实际瓶颈共同测算；这两个样本不能直接外推 300 条交付日期。扩大预算、并发或生成规格前更新对应测算和放行范围。

同时展示四种计数：母版数、实验候选版本数、实际合格作品数、独立复验通过的配方数。不同导出文件、字体颜色变化和重复发布不能增加独立作品数。受控开场实验有实质变化时可按原槽位验收，但仍不增加独立母题/复验数。

## 12. 必须覆盖的验收场景

| 场景 | 预期结果 |
| --- | --- |
| MP4 仅有静态图缩放或相机缓移，声明要求布料动作 | 动作检查不通过；不能以视频格式或运动像素替代主体动作 |
| 源片有动作，但选取的三秒是等待或静止段 | 候选返工；优先调整合法源区间并重新校验语音/字幕 |
| 原片手部完整，竖屏裁掉捏角或包边 | 成片构图检查失败；调整合格构图模式或重新取材 |
| 手部穿透、增指、毛巾织边或颜色被改款 | 身份/动作自然度检查失败；局部返工不能改成新商品事实 |
| 只有抽帧/光流预警，没有完整动作的语义证据 | 不显示主体动作自动通过；保留待核验 |
| 未登记开场实验，却只更换前三秒申请普通独立候选 | 原普通差异门禁仍生效；不能滥用实验例外 |
| 口播跨越 3000ms，直接切会断字 | 阻止组装；检查音轨词边界并更新共同基准 |
| 开场口播过长 | 先缩句或重配，不能侵入固定主体或截断尾音 |
| 转场、标题动画或 BGM 压低延伸到主体 | 冻结检查失败；只允许共同基准内的固定行为 |
| 前三秒换动作和口播，主体一致 | 按 opening_package 合法实验处理，不受跨母题三轴规则误杀 |
| 以换开场名义改 SKU、主体文案或 CTA | 拒绝同组比较，要求新版本/新实验 |
| 原声只有文档摘录 | 显示来源待核验；禁止改成自有买家证言 |
| AI 织纹或抚摸画面被拿来证明吸水/触感 | 承诺与证据检查不通过 |
| 字体缺失、标题溢出、字幕重叠、slogan 截断 | 对应检查失败，不沿用旧样片批准 |
| 三秒预览没有结尾 slogan | 按预览范围处理；完整成片仍须验收 slogan 及至少 0.4 秒尾部空间 |
| 将独立预览的 BGM 末端淡出直接拼入完整片 | 接合检查失败；用原音轨按全片统一混音 |
| 渲染计划声明有声音，最终文件缺音轨或重复叠音 | 技术/声音检查失败，不以配置存在视为完成 |
| judge 返回无效 JSON | 保留 error；最多一次格式重试后转具名人工内容核验，不能伪造自动分数 |
| 独立 ASR 或字体身份检查未运行 | 保留 not_run；正式放行前补齐对应实际检查，不能套用 judge 的人工替代路径 |
| 无价格的预览触发覆盖率不足 | 按预登记的检查适用范围处理，不补造价格，不将 skip 改为 pass |
| 预览批准被拿来交付完整片 | 拒绝；完整片哈希、依赖及必要检查重新绑定审核 |
| 成片、字体、事实或固定主体版本改变 | 旧批准失效；相关候选需重新检查/审核 |
| MP4 编码差异但共同合成内容未变 | 不因文件字节不同误报主体变化，仍做实际解码检查 |
| 指标分母不同、样本不足或分配不平衡 | 不合并为赢家排名；记录具体数据限制 |
| 两组各四版、重复导出和重复发布 | 候选/母版/合格作品/复验四类计数正确且不抵扣原 300 条试点外配额 |
| 基准素材或成本被多个变体复用 | 共享成本仅计一次，增量成本独立可追溯 |
| 任务提交超时或已成功后中断恢复 | 使用既有幂等键/任务 ID 查询，不再次创建付费任务 |
| 成功生成但创意淘汰，或实际账单未知 | 前者仍计成本；后者保留估算和 null 实付，不能填零 |

验收材料分为工程回归结果、真实成片检查、用户审核、经营实验四类；任何一类不能代替其他三类。截至 2026-09-30，B1–B7 与 D 的结果导入工程已完成研发验收。后续仍需接入主干、完成新预览的动作/构图审核、两组新基准及八条完整实验片，再进行流量验证、W1 首 30 条校准和逐类型扩量。工程完成不代表这些生产或经营步骤已经完成。
