# 两条成片复盘与 300 条生产升级实施说明

实施分支：`codex/towel-production-scaleup`。生产路线继续使用 Seedance 2.5、Remotion、Doubao TTS 和已批准 SUNO 素材。此次实施没有启动新的付费生成。

## 已落地的主干

| 环节 | 已实现 | 使用方式与边界 |
|---|---|---|
| 单条审核 | ReviewService 的 final_review 绑定视频、生产记录与全部审核依赖的真实哈希 | 审核留言和正式批准分开；同批逐条审批；不补历史阶段 |
| 交付 | certify、editorial promote、restore 共用必要证据和最终批准验证 | 改成片或依赖后旧批准不能交付新版；旧交付历史仍可读 |
| 质量 | production_audit / production_quality / production_evidence | 原始检查状态保留，重新读取来源报告；缺语音、字体、DOM等不能显示全通过 |
| 品牌 | 参数化 ProductionBrand Remotion composition、严格 brand_profile 与字体预检 | operation=render 正式主入口支持，保留proposal/runtime/素材/音频/QA约束；目前该组件仅支持full渲染 |
| 费用与恢复 | 成功回执usage结算、原子预算预占、持久任务幂等、未知状态查询 | 不猜汇率，不把预占或估算当实付；未知POST结果不盲重提 |
| 批量 | 原排期转为300槽位campaign_plan，服务器从单条记录生成全景 | 周、SKU、方向、结构、状态筛选；试点单列；以唯一合格作品计数 |
| 差异 | 三轴规则、预登记单变量例外、真实解码媒体指纹 | 首3秒、关键帧、素材复用预警；高相似仍需人工判断 |

“人工验收通过”和“完整生产认证”分别展示。旧alignment、旧judge报告保留历史标签；A01三次无效JSON保留error，不生成分数。本轮已对两条原片重新执行当前哈希绑定的本地技术复检，但仍没有独立ASR与严格字体/全片DOM证据；事实卡原状态为待确认，不能把展示样片验收推导为所有SKU事实都已批准。

五个成功动作任务各87300生成token，合计436500。当前登记目录估算30.555元（2026-09-24价格口径），原4.2美元预占释放为待结算预算承诺；实际账单金额保持null，5笔待核实。两笔生成前失败的退款记录保留。没有将共享动作池30.555元分别全额重复分给两条成片。

## 从排期到单条的执行

1. 从300排期选择槽位：商品、方向、结构、实验家族、周次和制作路径分别保留。P1/P2试点不抵扣S01/S08/S04配额。
2. 绑定已批准事实版本、参考图及证据、品牌与字体版本；检查素材缺口。真实实测必须提供真实取证素材。
3. Agent用阶段skills生成脚本与镜头计划；跨母题做实质差异，实验组仅改预登记变量。先审计划再生成缺镜头。
4. 预占预算，持久化任务身份，调用SeedanceArk；超时先查询。动作不合格最多追加两次，不合格镜头费用仍留账。
5. TTS后以实际词时间安排镜头/字幕/尾音；Remotion正式主入口合成，沿用5帧转场和持续品牌层。
6. 采集实际媒体、解码、音轨、字体、逐帧布局、独立语音、事实/画面等证据；差异比较同时看计划和成片。
7. 审核台逐条验收。只有必要检查和对应最终版本批准都成立，才认证交付并计入独立作品数。
8. 每5–10条复盘成本/耗时/返工；W1先30条校准，新结构在所属周首件通过后扩量。质量达标与销售效果分别统计。

原配额：商品100/120/80；方向90/75/60/45/15/15；4周×75；240实验+60支持。W4确实包含30条人工路径，不能将Agent辅助自动标成人工对照。

## 成本与效率口径

视频API情景仍用270条AI辅助×平均新增1/2/3段合格动作÷80%通过率：338/675/1013次，估算2065.52/4124.93/6190.44元。仅是当前规格的视频生成预算情景，不含图片、TTS、ASR、judge、Agent、渲染、音乐、存储、拍摄、审核、人工剪辑及系统研发，也不是生产预算授权。

每个槽位费用和耗时未知时显示“待核实/未测量”。W4账目分共同准备、人工路径增量、AI路径增量，共同成本项目内只计一次；路线比较各分摊50%。单条增量现金成本与含人工摊销成本分别报告。

五段模型执行149–245秒只代表小样本；675次、并发2、70%利用率约20–33小时只代表生成窗口。首轮审核按3–5分钟/条规划15–25人时；W4人工剪辑另需15–30人时，不含筹备。四周是目标，不以重复内容填数。
