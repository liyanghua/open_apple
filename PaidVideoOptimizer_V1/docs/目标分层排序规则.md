# 三个目标 × 最近7天曝光分层（V1.3.0）

在“候选 TOP3”或“全量素材”的“排序目标”选择最大化曝光、最大化成单、最大化ROI；切换后自动计算并保存新快照。候选页可展开三个目标的全分层总览。历史综合评分保留作为兼容选项，旧快照不改写。

## 计算规则

- 曝光：平滑后的曝光数 / 100元。
- 成单：平滑后的净订单数 / 100元。
- ROI：平滑后的净成交额 / 消耗。
- 平滑效率 = (实际产出 + s0 × 参考效率) / (实际消耗 + s0)，s0沿用策略设置，默认100元；内部金额统一为分，展示时换算为元。
- 每个目标的参考效率分别从本次7天报表中，排除聚合行、错误行、缺失或负产出及非正消耗后，按合计产出 / 合计消耗计算。缺失产出不计入该目标参考的分子或分母。参考不随曝光分层改变，也不使用30天参考ROI覆盖。
- 无有效自身观测的素材使用参考效率，自身权重0，并标记待验证。无可用参考则效率缺失，不填0。实际零订单保留零订单，即使平滑后有正参考效率。
- 自身权重 = 消耗 / (消耗 + s0)。这是平滑权重，不是统计置信度。
- 按目标效率降序、自身权重降序、素材ID升序排序；不可计算的效率置后。每层取前三，不足三条按实际展示；不按追投队列预筛素材。
- 曝光层：<500、500–999、1000–1999、2000–4999、≥5000、缺失/待核。
- 三个目标不混入原综合评分的30天、趋势或稳定性权重。原指标仍供诊断；详情明确区分目标平滑ROI与历史综合评分使用的ROI。

## 使用边界

数据应限定同计划、同路径、同周期、同净额口径；系统仅能依据已导入范围比较，部分报表不能代表完整计划。只有30天数据时，三个7天目标显示无可用参考；可选择历史综合评分。

榜单表示历史单位预算效率，不是未来增量承诺。零订单或缺失数据素材入榜仍需补测。共享计划预算不能按素材重复追加；原有独立任务追投流程仍仅适用于确有独立任务及授权的场景。

## 验证（2026-09-13）

63项后端测试通过、TypeScript编译通过。新增覆盖目标切换、公式和金额换算、分层不改变参考和效率、缺失不当零、无7天参考、非法目标、API快照与CSV导出。

浏览器曾用本地私有历史报表验证500–999曝光层：曝光、成单与ROI目标可以得到不同的TOP1；刷新后保持所选目标和同一快照，全分层总览显示6层。实际报表日期、素材名称与人员标识已从公开文档删去；复验应使用合成或受控数据。
