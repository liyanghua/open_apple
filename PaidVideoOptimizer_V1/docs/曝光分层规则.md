# 最近7天曝光分层（1.2.0）

根据用户要求，将7天曝光按互斥区间分为：不足500、500–999、1000–1999、2000–4999、5000及以上；缺失或无效曝光独立列为“曝光缺失／待核”。边界500、1000、2000、5000均进入新一档。不用30天曝光或平滑值代替7天实绩曝光。

所有独立素材仍按已有全量评分规则计算，原始ROI与平滑算法保持不变。每层按综合分排序并取最多3条。页面默认查看5000次及以上，可在分层按钮或下拉框切换；每个层显示素材数量。选择“全部曝光”可查看跨层总览。没有任何素材时显示空层提示，不从低曝光层补足。

分层不会重新计算参考ROI，因此同一素材在不同视图里的综合分不变。曝光分层及选中层随排名快照保存，生成提案时只使用该快照选中层的TOP3。全量素材表支持相同层级查看；CSV仍导出整个排名快照，并附每条素材的曝光、层级、层内排名和本次选中层。

低于500次时显示低样本提示。更高曝光只表示样本规模更大，不是统计置信度或盈利保证；仍需同时看净订单、消耗、归因及退款成熟度。只有曝光量不足以估算可靠的ROI置信区间，界面不展示虚构的置信概率。

原始ROI在低曝光或缺失曝光时仍保留以便核对，但低曝光与缺失层不混进默认的5000+榜单。曝光分层不改变实际追投审批、预算或任务检查。
