# 计划与素材两级投流优化设计

**版本：** V1.5 评审稿
**更新日期：** 2026-09-16
**状态：** 仅更新设计文档，待用户审核；以下新增能力尚未实施
**适用：** 毛巾、浴巾、沙发垫等品类；单计划多素材赛马；视频到直播、视频到商品分别分析

## 评审说明与现状

本版主线为“计划加预算＋素材复验”，采用每日计划数据、每周素材明细；新品零历史时先生成限额试投方案。独立素材追投仅保留为独立场景，不作为乘方主流程的必填配置。

已有实现包含报表解析、历史素材排名、曝光分层、独立追投任务规则，以及乘方上下文、诊断接口、标签和冻结快照。不能据此认定本版计划级预算闭环已完成。当前乘方诊断仍有严格对账、曝光必需、两期判断和页面入口等限制；本版验收需逐项验证，不能沿用上一版测试通过结论。

下方 V1.4 原文仅作历史设计档案。与本版冲突时，以 V1.5 为待实施规范；这不表示运行中的系统已采用新规则。

## 1. 角色分工与运行流程

平台在计划内分配流量；运营负责计划设置、经营条件和内容上新；本地系统负责证据整理、复验排序、限额试验建议及复核。平台内部算法不作为本系统已知规则，也不声称本地排序能够控制赛马分配。

工作流：品类建档 → 计划关联 → 导入／录入 → 数据可用性检查 → 计划诊断＋素材诊断 → 人工确认建议 → 后台执行 → 本地记录 → 到期复核。

系统不直接登录投放后台或执行调整。每条建议必须展示证据周期、数据截止日、使用口径、触发理由、缺失项、下一步动作及复核条件。

### 1.1 对象与预算层级

| 对象 | 定义与用途 |
|---|---|
| 品类 | 毛巾、浴巾、沙发垫分别建档，效果基准默认不跨品类 |
| 计划 | 平台计划 ID；未取得时可创建明确标记的本地编号，之后关联真实 ID |
| 路径 | 视频到直播／视频到商品；同一素材在不同路径分别计算 |
| 素材 | 以素材 ID 识别，名称仅作展示；同一素材不同计划分别记账 |
| 内容方向 | 由人工标签组合形成，不从文件名猜测内容 |
| 后台预算 | 记录日预算／总预算、额度、生效时间和历史变更 |
| 本地授权池 | 明确覆盖计划、授权周期、总额、其他占用、已预留与已结算金额 |
| 单次追加上限 | 本次计划预算试验可承担的新增支出上限 |

同计划赛马素材无需分别填写预算、出价或独立任务 ID。不得把计划预算重复分配给每条素材。授权池是本地额度管理，不等同于后台钱包余额；一个授权范围不得在多个工作区重复登记为可用额度。

### 1.2 四种 ROI 不混用

- 后台目标 ROI：平台设置，保留字段定义与生效时间。
- 本地最低净 ROI：用户确认的经营筛选线，必须注明净额和成本口径。
- 计划实际 ROI：计划净成交金额／同范围成本，不平均各素材 ROI。
- 素材比较基准：同品类、同计划、同路径、同口径可比素材的汇总效率。

实际 ROI 不自动成为筛选线，后台目标也不自动等于本地净 ROI 底线。现有默认 ROI 5 属于演示参数；新建真实计划的经营底线默认“待确认”。净成交 ROI 不是利润率，没有完整商品成本时不声明盈利。

## 2. 数据口径与整体／明细关系

### 2.1 净成交与成本

保留三类净额标签：报表净额、扣一小时退款净额、用户核实的成熟净额。必须记录实际字段、退款窗口、归因说明、导出／更新时间及观察成熟状态；选择标签不会自动补扣退款。

“净成交金额”与“用户实际支付净成交金额”独立保存，不互换。成本分别记录整体消耗、综合成本、佣金及其包含关系。截图中的佣金“—”表示未报告，不是零，也不证明营销能力关闭。能力未知时保持未知，不能默认仅基础投放。

字段范围不一致时，只展示原始数据和差异；不能拼接不同口径形成 ROI。相同周期的历史重导报表保存版本与导出时间，不覆盖既有诊断输入。

### 2.2 两个独立维度

必须区分“投放阶段／数据分区”（乘方期间、全域期间、跨阶段）与“覆盖范围”（整体、视频子集、其他已知子集、范围待确认）。页面“数据维度：整体”不自动等于跨阶段数据分区。

同范围明细与总表才进行一致性对账。视频子集与整体比较时显示消耗、净成交、订单的覆盖率和未解释差额，不要求两者相等，不按比例将差额摊给素材。

同范围成本对账继续使用 max(¥1, 总成本×1%) 的默认容差；超差时阻断依赖完整归属的结论，保留可确认的原始指标。同范围成交、订单也展示差异及更新时间。只有子集范围差异不能被误报为解析失败或成本归属错误。

用户确认的单计划范围与原表“关联计划数量”分别留存。人工确认不抹除原字段；若以后有明确逐行计划 ID 冲突，应显示冲突并重新核实。

AIGC 动态创意集合不作为单素材参与排名；原记录保留，覆盖率同时展示包含集合与排除集合的结果。

### 2.3 私有历史样本的验收方法（数值已删去）

原验收基线来自本地私有历史导出与运营截图。账户、日期、素材数量、消耗、成交、订单及 ROI 的具体值不随仓库分发；受控资料保留来源和哈希，供授权人员复核。

验收时分别记录同周期、同计划范围的商品整体、含 AIGC 集合的视频明细、排除集合的视频明细。整体与子集允许有差额，必须展示并标为待解释，不能按比例摊给素材；截图中的实际支付净成交与报表净成交也必须分开，不得替换分子。商品侧缺曝光／点击时保持未知；直播侧按自己的路径对账，不借用商品整体截图。

这些历史数据只支持历史分析，不能独自支持今天的计划追加金额，也不能直接作为新商品的效果基准。

## 3. 计划级优化与追加预算建议

### 3.1 指标与诊断

每日记录计划消耗／综合成本、净成交、净订单、当日有效预算及设置变更。计算计划净 ROI、净订单成本、预算使用率、最近完整七天表现；具备前一非重叠七天时增加周变化。

一份周汇总可以做周诊断，但不得均摊为每日数据或据此判断哪些日子预算受限。缺数据时输出局部诊断及补充清单。

| 建议状态 | 触发与处理 |
|---|---|
| 数据待补 | 明确缺失项及其阻断功能，不让整个工作区空白 |
| 保持观察 | 归因未成熟、经营条件刚变化或有未复核试验 |
| 优先排查 | 低于经营底线、库存／价格／承接异常，说明排查方向 |
| 可做预算试探 | 全部数值动作条件满足后，给出金额、期限、授权与复核条件 |
| 停止继续追加／复核 | 试验未通过，提示人工检查是否恢复原设置，不自动回退 |

预算未花完不能自动推断出价低；计划 ROI 高不能自动推断加预算后仍能维持。诊断不输出预测增量成交或成功概率。

### 3.2 首版日预算试探条件

以下条件同时通过才输出追加金额：

1. 最近完整七天计划数据，默认截止日距运行日不超过两天。
2. 净额与成本口径一致；用户确认最低净 ROI、归因观察期；数据达到该观察条件。
3. 七天原始净 ROI 不低于底线，净订单默认至少五单。
4. 当前日预算及生效历史明确；最近三个完整预算日使用率均达到 90%，运营确认存在预算限制。
5. 商品可售、库存及承接有效；重大经营或投放条件变化后达到用户约定观察期。
6. 无未复核预算试验，当前设置已核实，授权余额、单次上限、试验日数与复核时间完整。

5 单、90%、两天新鲜度是可修改管理参数，不是统计置信度或行业最佳实践。没有可适用的真实参数时不自动确认。

总预算类型首版支持效果诊断，但不套日预算公式。ROI 目标变更只作观察建议，不给机械上调／下调数值；一次预算试验不同时建议改变目标 ROI。

### 3.3 金额、授权和复核

设当前日预算为 B，试验覆盖完整预算日数为 D，比例 p 默认 5%，用户确认的本次新增总额上限为 C，授权池剩余额度为 F：

- 新增日预算 ΔB = 向下按平台预算步长取整[min(B×p, C/D, F/D)]。
- 建议日预算 = B＋ΔB；试验预留 = ΔB×D。
- D、预算步长、C 和复核规则必须有用户输入／确认；ΔB 不足一个步长时不给数值动作。
- 首版从下一个完整预算日开始，不将部分日简单按完整日追加。
- F 按授权期内其他消耗、其他承诺、本应用预留及结算扣除，禁止同一支出重复扣减或重复授权。
- 此预留表示新增预算上限，不是对实际增量消耗或成交的预测。

生命周期：草案 → 本地确认与预留 → 人工后台执行并登记真实设置 → 观察 → 到期复核 → 结算／释放。重复提交幂等；尚未执行可取消并释放，执行后的变更必须留痕。

试验期限结束时提示运营核对／恢复预算；系统不会自动恢复。尚未确认试验结束及额度关闭时，不自动释放授权或允许连续追加。超出试验日数的持续支出需人工核查。

复核对比匹配周期与口径的数据，记录归因成熟度、商品及投放变更。未过线、样本不足或受经营变化影响时，不进入下一次追加。用户记录新增额度的结算依据，不能由计划总支出自动推断增量效果。

## 4. 素材级诊断、排序与内容决策

### 4.1 不先筛掉素材

普通素材全部可见；AIGC 集合独立展示。按同计划同路径计算三个历史效率视角：

| 目标 | 排序指标 | 必须同时展示 |
|---|---|---|
| 最大化曝光 | 单位成本曝光效率的平滑值 | 原始曝光、消耗、订单及 ROI |
| 最大化成单 | 单位成本净订单效率的平滑值 | 净订单规模、消耗及 ROI |
| 最大化 ROI | 同口径净 ROI 平滑值 | 原始 ROI、净订单及消耗 |

金额内部以分存储，界面效率统一换算为每元／每百元并明确单位。排序表示历史效率，不能等同于未来增量或平台流量指令。

保留六个曝光层：不足 500、500–999、1000–1999、2000–4999、5000 及以上、缺失。每层每目标真正按指标取 TOP3，不足三条按实际展示；全量列表仍可查。同分按自身数据权重、素材 ID 稳定排序。

曝光缺失时仍计算有依据的订单效率和 ROI，进入“曝光未知”组；曝光目标不可计算。零消耗不计算效率，零订单保留为零；缺失值不伪装为零。无可计算值的素材保留在待补列表，不占效率 TOP3 名次。

### 4.2 平滑与可比性

同品类、同计划、同路径、同口径、同周期的有效素材形成固定参考范围，不因切换曝光层或搜索而改变基准。

设消耗 S、净成交 V、曝光 I、订单 Q、参考效率 R、平滑消耗 S0：

- ROI：(V＋S0×参考ROI)/(S＋S0)。
- 曝光效率：(I＋S0×参考曝光效率)/(S＋S0)。
- 订单效率：(Q＋S0×参考订单效率)/(S＋S0)。
- 自身数据权重：S/(S＋S0)。

默认 S0 为 100 元，可调整并随快照冻结；各指标参考值按有效样本的分子合计／成本合计计算。无可比基准时展示原始值和“基准待积累”，不得跨品类补值。缺失原始指标不通过平滑生成伪实绩。

### 4.3 分级结论

- 一期即可生成：优先复验、保留观察、低样本补测、数据待补。
- 曝光和消耗阈值用于样本提示，不等于统计显著性，也不作为所有分析统一的入口条件。
- 缺曝光不阻断 ROI 展示，但不足以认定曝光样本可靠；本版自动方向扩产／停产仍需完整样本证据。
- 两期比较：同计划、路径、口径，周期不重叠；相邻周变化要求日期连续。
- 三期以上：支持连续周稳定性，不能把任意两个周期描述为长期稳定。
- 扩产／停止复制：至少两个可比周期，每期至少三个不同素材、样本要求均达标，且逐期满足用户确认的方向规则；操作变化无法排除时仅观察。
- 内容标签缺失时只输出数据诊断；缺视频或人工内容描述时不猜测开场、口播、画面为什么有效。

方向规则按主目标、ROI 底线和订单底线分别确认。每期方向效率相对该期计划可比素材参考计算，不能只验证本期过线、前期仅存在就认定“持续有效”。

内容建议写明：保留要素、仅改变一个变量、对照方向、产出数量、观察周期。数量受用户填写的内容产能约束；未填写时不自动编造配额。停止生产表示停止继续复制内容方向，不自动下线在投素材。

## 5. 新品类最小数据与渐进运行

| 档位 | 最小输入 | 可以输出 | 尚不能输出 |
|---|---|---|---|
| A 零历史试投 | 品类、路径、计划标识、目标、试投总额、周期、每日上限、复核时间、可用素材清单、可售状态；ROI 底线填值或标记待确认 | 限额试投安排、素材覆盖和采集清单 | 效果排名、盈利判断、基于实绩的追加 |
| B 单期素材诊断 | 素材 ID／名称、周期、归属范围、消耗、净成交、净订单及口径 | 历史 ROI／成单效率、样本提示、复验优先级 | 未提供曝光时的曝光榜；持续有效结论 |
| C 周复验 | B＋第二期非重叠可比数据；方向判断另需标签及样本条件 | 周变化、内容方向复验 | 因果增量、跨品类效果承诺 |
| D 数值预算建议 | 最近七天每日计划数据、有效日预算记录、已确认 ROI 底线、成熟度、经营条件、追加授权和试验期限 | 计划追加金额、预留和复核 | 自动执行、保证收益 |

没有计划汇总也能做 B 档的单素材原始效果分析；没有曝光仍能做商品侧 ROI／订单分析。没有真实平台 ID 时用“本地计划编号”建档，不伪造平台关联。

未满七天标记为部分周期，仅作探索观察，不折算为完整七天排名或套用预算追加条件。30 天数据为可选参考，不是新品启动必填项。

### 5.1 毛巾新品示例

用户输入毛巾、视频到商品、六条素材、七天试投总额 700 元、每日上限 100 元和复核时间。系统给出计划层面的限额试投安排，不将 700 元强行均分给六条赛马素材。这些金额仅是填表示例。

ROI 底线未确认时可以在用户授权的初始试投额度内采集数据，但不宣布盈利或建议追加。每天记录计划实绩；满七天导入素材表，按可用字段形成复验建议；下一周再验证方向。

毛巾、浴巾、沙发垫分别建立自己的参考值和经营底线。桌垫历史数据只能复用字段模板、操作流程和待验证内容假设，不移植 ROI、转化率或预算效果。

### 5.2 三类输入模板

| 模板 | 必填或阶段必填 | 可选增强字段 |
|---|---|---|
| 计划档案 | 品类、计划 ID／本地编号、路径、预算类型、当前预算及生效时间、后台目标口径、本地底线状态、成本和净额口径；数值建议前确认能力与经营状态 | SKU／商品标识、单价、成本构成、责任人 |
| 每日计划记录 | 日期、消耗／综合成本、净成交、净订单、有效预算、导出时间、成熟度 | 实际支付净成交、佣金、曝光、点击、变更说明 |
| 每周素材明细 | 周期、计划范围、路径、素材 ID、名称、消耗、净成交、净订单及口径 | 曝光、点击、上线时间、标签、视频链接 |

截图可人工转录为整体汇总，保留来源、周期和未核字段；一张七天截图不能生成七条日记录。毛巾新品尚无报表时先填写 A 档资料即可。

### 5.3 日常操作

每日：更新计划实绩与设置 → 查看缺失／观察／预算状态 → 如有建议人工核对执行 → 记录操作。

每周：导入同周期素材明细 → 核对路径和范围 → 查看目标×曝光层 TOP3 及全量诊断 → 维护标签 → 确定下一批变体 → 下周期复验。

历史回放：选择历史时间，不伪装成当前数据；展示当期条件下的诊断。今天的金额建议必须重新检查当前预算、授权、新鲜度和执行状态。

## 6. 实施和验收索引

按 P0 数据与兼容、P1 素材诊断、P2 计划预算闭环、P3 新品向导实施；详见升级计划的 V1.5 章节。数据模板与真实案例验收见《本地DEMO与真实数据验收》的 V1.5 章节。

审核重点：业务层级是否符合实际操作；新品最小字段是否可获得；预算试探默认参数是否接受；部分数据可运行与数值动作限制是否清楚。本次文档更新不代表参数已经被用户确认用于真实投放。

# V1.4 历史设计档案（以下不作为 V1.5 新功能的验收规范）


**版本：** V1.4 草案
**状态：** 待评审，尚未实施
**适用范围：** 巨量千川乘方计划中的推直播、推商品素材运营

## 1. 定位与边界

乘方后台负责计划级的实时调优：综合营销 ROI 目标、计划预算、系统建议出价，以及素材、达人、权益之间的流量分配。本地工作台负责素材经营：识别值得保留、继续测试、停止生产和扩产的内容方向。

```text
乘方素材明细 + 计划级综合营销数据
                    ↓
本地工作台：数据校验 → 样本分层 → 素材／素材组诊断 → 内容决策
                    ↓
运营人员：在乘方后台维持计划设置、上新素材、配置营销能力
                    ↓
下一周期回收同口径数据，验证本次内容决策
```

系统不登录千川、不改变计划预算、ROI 目标、出价、营销能力或素材状态。所有建议是本地的内容运营建议，必须由运营人员在乘方后台人工执行。

### 不再适用的旧能力

当前的“独立追投”工作流假设每条素材有独立任务、成本出价和可分配预算。它与同一乘方计划的系统赛马不匹配。因此，乘方工作区不应再生成以下动作：

- 按素材分别增加预算；
- 按素材试调成本出价；
- 为每条素材预留共享预算；
- 由本地系统认定某一素材应在平台被暂停。

旧工作区和旧排名快照继续可读、可复核；只有明确选择“独立追投”模式的工作区保留原有流程。

## 2. 数据口径

### 2.1 两类周期不能合并计算 ROI

| 数据分区 | 主指标 | 使用方式 |
|---|---|---|
| 乘方期间 | 综合营销 ROI = 净成交金额 ÷ 整体消耗 | 评价当前乘方计划和素材方向 |
| 全域期间 | 原支付 ROI／净成交 ROI | 仅作历史背景与迁移前参考 |
| 整体期间（跨两阶段） | 成交、消耗、订单等规模指标 | 不计算或展示合并 ROI |

“整体消耗”必须与当前营销能力一致；启用达人佣金等能力时，需包含相应营销成本。若只导入基础投放数据，系统必须明确标为“基础投放成本口径”，不能伪称综合营销 ROI。

### 2.2 最小输入合同

每次素材诊断以一个已确认的 7 天素材明细快照为基础，并补充计划上下文。

| 类别 | 必填 | 说明 |
|---|---|---|
| 范围 | 计划 ID、推直播／推商品、数据分区、起止日期、时区 | 同一诊断只比较同计划、同路径、同分区、同时间窗口数据 |
| 素材明细 | 素材 ID、素材名称、素材可归属整体消耗、净成交金额、净订单、曝光 | 素材 ID 仍以字符串保存；集合行只参与对账 |
| 成本归属 | `material_attributable`、报告期计划整体消耗及对账状态 | 只有可归属到单素材的成本才能做素材 ROI；计划总成本逐行重复或归属不明时，禁止素材 ROI 结论 |
| 计划状态 | 当前综合营销 ROI 目标、计划状态、乘方起始日 | 用于说明背景，不从本地推导系统建议出价 |
| 营销能力 | 基础投放、星选、达人营销、含达人佣金出价是否开启 | 决定成本口径和可比较范围 |
| 内容标签 | 至少内容类型、首屏钩子、核心卖点；可选人物／场景／价格表达／时长 | 标签由人工维护，不能由文件名猜测 |
| 操作日志 | ROI 目标、预算、能力开关、商品／承接变化的时间和说明 | 避免把人为或经营变化误判为素材效果 |

### 2.3 缺失处理

- 缺少整体消耗、净成交、数据分区或成本归属时，原始数据保留，但不计算综合营销 ROI。
- `overall` 分区只显示成交、消耗和订单等规模汇总，不能进入素材或素材组 ROI 诊断。
- 素材可归属成本之和与同周期计划整体消耗的差额不超过 `max(¥1, 计划整体消耗 × 1%)` 才视为已对账；超出时保留原始数据，阻断 ROI 和内容方向结论，并显示未归属成本差额。
- 缺少内容标签时，素材可在单素材榜中出现，但不进入素材组结论。
- 低曝光、低消耗或只有一个周期只输出“继续观察／补测”，不输出“停止生产”或“扩产”。
- 综合营销 ROI 的平台展示值可保存用于对账；排名及诊断使用可追溯的净成交金额 ÷ 同口径整体消耗重新计算。

## 3. 诊断对象与决策

### 3.1 两层对象

1. **素材**：回答该素材应保留在赛马、继续观察，还是不再围绕它复制生产。
2. **素材组／内容方向**：按人工标签组合聚合，例如“口播｜痛点首屏｜价格锚点”。它回答下一批要生产什么，而不是替平台分配当下流量。

### 3.2 样本状态

沿用最近 7 天曝光层：不足 500、500–999、1000–1999、2000–4999、5000 及以上、缺失／待核。曝光层只描述样本规模，不等于统计置信度。

| 状态 | 最低证据 | 允许的结论 |
|---|---|---|
| 待核 | 缺关键字段、范围不一致、曝光缺失或成本未对账 | 补数据，不参与内容方向结论 |
| 探索 | 少于 500 曝光、低于最低可比较消耗，或只有一个有效观察周期 | 继续观察／补测 |
| 可比较 | 至少 500 曝光且有正消耗 | 与同计划同分区参考效率比较 |
| 可复验 | 两个非重叠周期均可比较 | 判断方向是否持续；仍不宣称因果 |

阈值必须在工作区配置中可见、可修改，并随诊断快照冻结。V1.4 的默认值为 500 曝光、¥100 最低可比较消耗和两个非重叠周期。更严格的“停止生产／扩产”只能在业务负责人确认以下完整规则后启用：主目标（曝光／成单／ROI）、最少不同素材数、扩产的主目标相对计划参考下限、扩产的 ROI／成单底线，以及停止生产的主目标、ROI、成单相对计划参考上限。未确认时系统只给保留、观察或补测。

### 3.3 诊断输出

| 建议 | 适用情形 | 本地系统输出 | 人工在乘方后台的动作 |
|---|---|---|---|
| 保留赛马 | 素材可比较，且目标效率不低于计划参考 | 保留理由、证据期、内容标签 | 保持素材参与；不因单条建议频繁改计划 |
| 继续观察 | 样本不足、近期才上线，或数据未成熟 | 待观察指标与下一次复核时间 | 保持或补充同方向变体 |
| 补测变体 | 有流量信号但成交／ROI不足，或有成交信号但曝光不足 | 要改变的一个变量和保留的变量 | 新建有限数量变体，不同时改变多个核心变量 |
| 停止生产 | 同内容方向已有足够、重复的负向证据 | 停止复制该方向的理由 | 停止新增生产；是否下线在投素材由运营决定 |
| 扩产方向 | 一个内容方向在足够样本和多个素材中持续优于计划参考 | 下一批素材配额、结构和对照方向 | 组织制作与上新，仍由乘方自动分配流量 |

“最大化曝光、最大化成单、最大化 ROI”保留为**诊断视角**，不是预算命令。每张建议必须同时显示另两个目标的底线，防止用廉价曝光替代有效成交，或用极小样本的高 ROI 误导扩产。

## 4. 内容决策卡

每条素材和每个素材组输出一张可追溯的决策卡：

- 诊断周期、数据分区、计划 ID、营销能力和综合营销 ROI 口径；
- 内容标签与同组素材数；
- 7 天原始曝光、整体消耗、净订单、净成交额、综合营销 ROI；
- 目标效率的平滑值、自身数据权重、计划参考值和曝光层；
- 上一非重叠周期变化，以及当期操作／经营变化提示；
- 建议类型、理由码、证据充分度和下一次复核条件；
- 若为补测／扩产：明确“保留什么、只改变什么、生产几条、与哪一方向比较”。

示例：

> “口播｜痛点首屏｜价格锚点”方向已有 4 条素材、两个可比较周期；成单效率连续高于同计划参考，ROI 未低于底线。建议：下一批生产 3 条变体，保留痛点首屏与价格锚点，只改变人物和讲述顺序。该建议不要求平台给这 3 条素材指定预算。

## 5. 页面与工作流

| 页面 | 升级后职责 |
|---|---|
| 策略与预算 | 分为“独立追投”与“乘方协同”模式；乘方模式录入计划上下文、ROI 口径、观察阈值和营销能力，不录入单素材预算／出价 |
| 导入与对账 | 确认数据分区、计划 ID、整体消耗口径；阻止混合分区诊断 |
| 候选 TOP3 | 改为“素材诊断概览”；支持三种目标视角与曝光层，不显示“生成追投建议” |
| 全量素材 | 维护标签，查看素材和素材组诊断、来源与操作日志 |
| 新增：内容决策 | 展示保留、观察、补测、停止生产、扩产五个清单；可导出生产 brief |
| 追投与复核 | 独立追投模式保留；乘方模式替换为“诊断回收与复盘”，记录人工执行的内容上新和计划级操作 |
| 快照与回放 | 保存输入分区、计划上下文、标签版本、阈值、诊断和操作日志版本 |

## 6. 非目标与风险控制

- 不推断千川的内部竞价、预估转化或具体流量分配公式。
- 不把素材相关性称为增量因果；需要增量结论时，另行设计小范围对照实验。
- 不根据跨全域／乘方周期的累计 ROI 判断优劣。
- 不把达人佣金、服务费或商品成本缺失时的 ROI 称为利润率。
- 不自动关闭素材、调 ROI、改预算或开启乘方能力。

## 7. 验收标准

1. 乘方工作区不再生成独立素材预算／出价提案。
2. 含达人佣金的素材数据必须使用综合成本口径；缺口径时显式阻断 ROI 诊断。
3. 全域期间与乘方期间可分别回放；跨分区的整体数据不生成 ROI。
4. 低样本素材只能得到观察／补测结论。
5. “停止生产”和“扩产方向”必须展示标签组、样本量、周期和相对计划参考的证据。
6. 所有结论可回到原始导入行、计划上下文、标签和操作日志；历史快照不因后续修改而改变。
