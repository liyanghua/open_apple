# 全量评分 TOP3（1.1.0-score-first）

2026-09-13，按用户“先不筛选，先打分，小数据和缺失做平滑”的要求更新。

## 排名

所有可识别的独立素材都计算分数并排序，取前3名。ROI低、订单少、零消耗、缺近期数据或数据待核都不再被排名门槛剔除；集合行仍只参与原始对账，不作为独立素材。不同成交路径仍分别计算。

原有“探索、观察、数据待核、无近期消耗”等队列保留为状态标签，不决定入榜。TOP3表示分数前三，不表示已经验证适合放量。

## 平滑与缺失

- ROI实绩：净成交金额÷消耗。原始缺失仍为缺失，零消耗不生成实绩ROI。
- 有效ROI平滑：（净成交金额＋s0×参考ROI）÷（消耗＋s0）。默认s0=100元；消耗越少，越接近参考ROI。不额外叠加订单乘数。
- 默认参考ROI：所选30天同路径、无解析错误、非集合且有消耗的素材净成交总额÷消耗总额。没有30天时取所选7天；也可在策略中指定固定参考ROI。
- 缺失、零消耗、解析错误对应的ROI评分输入使用参考ROI，标记为补值。参考ROI也缺失时使用保守值0并提示。
- 趋势无可比基线时使用中性50分。滚动模式下缺稳定性时同样使用中性50分。这些补值仅用于评分，不是已观测事实。
- 待核数据可以出现在TOP3中，必须先核对；缺失数据的中性补值也可能排在已观测低表现素材之前。

## 分数组合

ROI子分=100×min(max(平滑ROI÷(2×ROI标尺),0),1)。当前ROI标尺为5，子分在平滑ROI达到10时封顶100。

趋势子分比较平滑后的最近7天ROI与前23天ROI；持平50分、翻倍100分、减半或更差0分，中间用对数插值。只有窗口与范围一致且差额有效时才计算。

- 仅30天：只使用30天ROI子分。
- 30天＋7天冷启动：默认30／40／20归一化为33.33%／44.44%／22.22%。即使素材缺某一项，也通过补值使用同一套权重。
- 滚动周：默认30%／40%／20%／10%；有连续至少3个有效非重叠周时使用实际稳定性，否则用中性补值。已具备周基线时趋势比较最近两周。
- 权重可在策略中修改。得分相同时比较7天净订单、7天实绩平滑ROI，最后按素材ID稳定排序。

## 追投仍单独判断

本次只取消排名筛选。具体预算／出价提案仍检查数据新鲜度、ROI与订单状态、独立任务结果、授权、冷却期和共享预算。不满足时展示原因，不因进入TOP3自动生成加价动作。

旧排名快照保留原规则与分数；点击“重新计算”生成新版本，不改写历史证据。
