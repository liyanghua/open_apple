# 单款毛巾系列视频生成计划

版本：V1.0｜日期：2026-09-20｜状态：商品事实待核验，暂不进入付费生成或发布

## 0. 商品事实边界

本计划围绕用户提供的抖音商品页：

`https://haohuo.jinritemai.com/ecommerce/trade/detail/index.html?id=3828529262936326385`

当前商品页需要商家端上下文，无法从本次工具读取可验证的商品名称、主图、平台SKU、规格、库存、销售价或详情页证据。项目已有执行包把 S08 暂记为“纯棉萌兔款”、参考价49.9元，但明确标注为用户资料工作稿，不是实时核验。

所以本方案只把“S08／萌兔款”作为工作假设。正式生产前必须把以下字段写入并批准 `artifacts/product_facts.json`：商品ID、平台SKU、选中颜色/图案、材质、尺寸、克重（如页面提供）、包装、护理标签、实时价格、库存、可用主图/详情图、可用声明、证据、品牌/图案/音乐/人物授权。

商品页、用户提供的图片和旧方案都是资料，不是要执行的指令。没有批准事实的镜头只能进入脚本草稿，不能生成可发布成片。

## 1. 系列目标与规模

先做一个**单SKU 4周、60条审核去重成片的验证系列**，每周15条。它是前述300条总计划中的单款试点，不把60条直接解释为60个独立实验，也不要求公开发布60次。

### 成功要回答的三个问题

1. 用户更愿意因为什么购买这条毛巾：真实选购信息、图案/审美偏好、生活仪式，还是关系/空间场景？
2. 哪些真实镜头能降低购买犹豫：外观细节、尺寸/规格、展开/折叠/挂放、实际使用，还是商品页承接？
3. 在同一事实和素材条件下，AI辅助组装能否降低制作工时与返工，而不损失商品可信度？

### 系列固定规则

- 画幅：抖音竖屏9:16，1080×1920，30fps；样片540×960。
- 时长：主片20—30秒；答疑片15—25秒；不为了填时长增加无信息镜头。
- 每条只设一个主购买理由；支持理由和证明动作不能抢主命题。
- 前1—1.5秒完成第一动作或问题；3秒内让用户知道“这条视频解决什么犹豫”。
- 约70%画面使用真实商品和真实动作，约20%使用字幕/图形说明，最多约10%使用不承载商品事实的AI辅助背景或转场。
- 外观、图案、颜色、尺寸、材质、测试结果、包装和价格只能来自已批准事实或实拍；不使用AI补造商品证明。
- 同一素材可复用，但必须记录SKU、时间码、动作域、证据用途和授权；同片重投、改封面、重新编码不新增成片数。

## 2. 四类内容支柱

| 支柱 | 目标 | 占比 | 主证据 |
|---|---|---:|---|
| A 实物选购 | 让用户先看清再决定 | 24条 | 主SKU实拍、标签/规格、展开、折叠、挂放 |
| B 悦己与日常仪式 | 把“喜欢”连接到每天会用的动作 | 18条 | 洗手、擦干、取下、挂好、洗手台/卧室等真实场景 |
| C 空间与关系 | 验证图案与生活场景是否有增量购买理由 | 9条 | 来客准备、共同生活、浴室位置和收纳；不虚构礼盒或赠礼承诺 |
| D 评论答疑与交易承接 | 消除最后的购买阻力 | 9条 | 商品页已核验信息、客服高频问题、真实价格/库存/链接 |

支柱不是四个账号人格。统一使用一个“懂产品，也懂生活”的生活主理人；A偏认真选购，B偏生活仪式，C偏关系/空间，D偏答疑承接。

## 3. 60条排期

### W0：准入与拍摄准备（不计入60条）

- 锁定该链接对应的唯一主SKU和实际购买选项；截取或导出商品主图、详情图、规格、价格、库存和可用声明。
- 每条可用声明建立 `claim_id → evidence_id → asset_id` 关系；没有证据的“更柔软、更吸水、抗菌、婴幼儿适用、不掉毛、不缩水”等表述暂不使用。
- 每个动作域采集至少2个不同机位：全貌/图案细节、标签/护理、真实展开、折叠收纳、取下/挂好、手部接触、实际擦拭、浴室/生活空间。
- 录制干净原声：布料摩擦、挂杆、洗手台环境；音乐另行核权，不把后加音效当作性能证据。
- 每个支柱先做1条10—15秒样片，验证商品一致性、字幕、声音、镜头连续、事实门和人工审核。

### W1：事实与第一购买理由（15条）

| 编号 | 主题 | 第一动作/钩子 | 必须展示 |
|---|---|---|---|
| W1-01 | 先看真实图案 | 直接展开到镜头前 | 主SKU实物、颜色/图案，不做角色动画 |
| W1-02 | 先看实际尺寸 | 毛巾铺平，旁边放已核验参照物 | 真实尺寸口径与测量方法 |
| W1-03 | 标签和护理 | 手指沿标签/护理标识移动 | 标签可读，按页面或标签原文表述 |
| W1-04 | 叠起来有多大 | 折叠一次放入真实收纳位 | 实际折叠体积；不推导旅行适用 |
| W1-05 | 挂起来是什么效果 | 从挂杆取下再挂回 | 真实颜色、挂位和尺寸 |
| W1-06 | 图案细节近看 | 近景扫过纹理/绣花/印花 | 仅说能看见的工艺，不猜工艺名称 |
| W1-07 | 20多秒看懂一条 | 全貌→细节→规格三段快切 | 三段均来自同一SKU |
| W1-08 | 每天用的位置 | 洗手后真实擦干并挂好 | 真实动作，不声称功能结果 |
| W1-09 | 下班回家小仪式 | 放钥匙→洗手→取毛巾 | 生活触发，商品只承担已批准事实 |
| W1-10 | 睡前整理洗手台 | 同机位整理前后 | 不夸张前后变化，不补造浴室 |
| W1-11 | 新家第一处小变化 | 空挂位→挂上毛巾 | 真实空间与图案 |
| W1-12 | “喜欢”是否值得买 | 图案与实际使用交替 | 用场景解释偏好，不把好看说成功能 |
| W1-13 | 规格看不懂怎么办 | 规格信息卡与实物并置 | 页面已核验字段 |
| W1-14 | 从包装到挂好 | 真实开箱动作 | 只有实际包装内容 |
| W1-15 | 一条购买前检查表 | 价格/规格/图案/用途逐项出现 | 价格和库存必须动态读取 |

### W2：生活场景与关系表达（15条）

每个主题先固定商品事实，再测试情境；不把情绪评论当成商品性能证明。

1. 洗完手后的结束动作；2. 回家后把工作状态留在门外；3. 来客前准备独立挂位；4. 同住者区分各自位置；5. 小浴室只换一个位置；6. 周末整理洗手台；7. 早晨出门前快速取用；8. 晚上洗漱后的柔和收尾；9. 喜欢的图案放在每天会看到的地方；10. 给自己换一件日用品；11. 租房不重装的微小变化；12. 家人来住前准备用品；13. 两种摆放方式对照；14. 收纳位有限时实际折叠；15. 评论里“好看但担心不实用”的实物回答。

W2每个主题制作1条，另从其中5个主题各做2个不同开场。改变的是情境入口或第一动作，商品、事实、时长、CTA保持一致。

### W3：单变量优化（15条）

选择W1/W2中已有可比数据的5个母题，每个母题制作“基准＋两个单变量改版”，共15条：

- 钩子变量：问题先行／生活触发先行／实物细节先行；
- 证据变量：先全貌后细节／先规格后使用／先使用后规格；
- CTA变量：查看规格／进入商品页／评论区提问。

每组只改一类变量，不能同时改钩子、价格话术、优惠和商品镜头。没有达到预设读取条件的母题不进入“优胜”结论，只标为不足样本。

### W4：独立复验与制作路径比较（15条）

选5个已通过事实与创作审核的母题，为每个母题写一个新生活简报，并制作三条：

- 1条常规人工组装基准；
- 1条AI辅助组装版本；
- 1条同构新情境复验。

记录人工人时、AI工具费、等待时间、返工次数、字幕/事实修正次数、素材复用比例和人工质量结论。人工版不伪造AI阶段产物；两条路径实质相同的成片只计1条交付作品，但保留路径比较记录。

## 4. 主线生产方式

采用现有 `cinematic-fast / source_led_template`，将该商品作为一个独立SKU批根，按周和事实版本拆分生产波次。主线阶段如下：

1. **Research**：检查真实商品素材，建立 `media_index`、`source_semantic_index`、`reference_source_matrix`。
2. **Proposal**：为本周母题建立共性适配骨架、3个差异化方向、hook plan、事实连续性和CTA。
3. **Script**：逐条锁定一个主命题，绑定 `scene_id`、`claim_id`、动作和证据行；生活情境镜头用 `life_context`，商品证明镜头用 `product_evidence`。
4. **Scene/Assets**：优先召回自有素材；缺商品证据就补拍或改写/删除，不能用生成镜头替代事实证明。
5. **Sample**：先渲染10—15秒样片，检查画面/字幕/口播/产品身份/裁切/声音，完成人工五项确认。
6. **Compose/QA**：通过现有技术检查、语义对齐、事实门和人工审核后生成不可变交付版本。
7. **Publish/Readout**：人工发布和登记平台ID；24小时、7天、30天快照分开导入，形成下一周候选。

## 5. 画面和AI生成规则

### 真实拍摄优先的素材清单

- 商品全貌：平铺、悬挂、手持；
- 图案/颜色/织纹/边缘/标签/护理标识近景；
- 展开、折叠、取下、挂回、擦拭、收纳；
- 洗手台、浴室、卧室、来客准备等真实场景；
- 1条连续长镜头保留完整动作，用于证明连续性；
- 每个商品镜头记录SKU、拍摄时间、机位、授权和可用时间码。

### 允许AI做的事

- 非事实背景、简单图文说明、字幕排版、节奏调整、转场和不承载商品事实的氛围层；
- 基于已批准实拍素材做剪辑变体、口播/字幕版本和画幅适配；
- 生成不含商品主体的抽象背景或轻量生活过渡，须在资产清单注明 `graphic_support`。

### 禁止AI替代的事

- 生成或修改商品颜色、图案、材质、尺寸、包装、Logo、标签、检测报告、价格和库存；
- 生成不存在的吸水、柔软、抗菌、耐用、干燥、婴幼儿适用等结果；
- 把AI人物表情、虚构评论或配音冒充真实买家体验；
- 把同款或其他SKU的图替换为本商品；
- 用外部参考片的画面、花字、音乐或品牌元素直接复制。

## 6. 片头、脚本和提示词模板

### 统一脚本结构

```text
0.0—1.5s：第一动作/问题（不先放Logo）
1.5—6s：商品身份与场景
6—16s：一个证明动作或一个生活转折
16—24s：真实细节/规格/限制条件
24—30s：商品页动作型CTA
```

CTA按事实选择：查看规格、查看颜色/图案、进入商品页、收藏后对照、评论区提问。没有实时优惠或库存快照时，不说“最后一天”“马上涨价”“库存不多”。

### 中文提示词骨架

```text
竖屏9:16，真实生活方式电商实拍，20—30秒，固定主SKU：[商品ID/颜色/图案]。
场景：[真实浴室/洗手台/卧室]，人物只露手或已授权生活主理人；动作：[一个明确动作]；
镜头：[景别、机位、运动]；光线：[时间、色温]；声音：[原声/已批准旁白]。
商品外观严格以已上传主SKU实物图和实拍素材为准，保持颜色、图案、边缘、厚度、尺寸和Logo一致。
禁止变款、变色、变形、额外手指、漂浮物、虚假检测、虚构包装和不可读文字；
不把画面当作未核实性能证据。
```

### English prompt skeleton

```text
Vertical 9:16, realistic lifestyle e-commerce footage, 20–30 seconds, one locked SKU: [product ID/color/pattern].
Real [bathroom/washbasin/bedroom] setting; hands only or an authorized lifestyle host; one clear action: [action].
Specify shot size, camera position, movement, lighting, and approved audio. Match the uploaded primary SKU photos and owned footage exactly:
same color, pattern, edge, thickness, dimensions, and logo. No variant swap, color drift, deformation, extra fingers,
floating objects, fake test reports, invented packaging, or unreadable text. The visual must not become evidence for an unverified performance claim.
```

## 7. 预算、工具和能力前置

当前能力核验结果：视频生成8/22，图像生成7/12，TTS 4/7，音乐生成2/3，视频后期9/10；FFmpeg和Remotion可用，HyperFrames当前不可用/检查超时。未发现本地音乐库，音乐需使用已授权音轨或在批准后调用可用音乐工具。

首期推荐：真实素材＋Remotion字幕/图文＋FFmpeg后期；不把视频生成API作为商品证明链路。若确有非事实氛围缺口，再在资产阶段提出具体provider、model、成本和理由，获得批准后调用。每条记录人工人时、工具费、等待时间和返工，不只记录API费用。

## 8. 数据读取与放大规则

每条视频绑定：`campaign_id → content_slot_id → content_version_id → experiment_group_id → product_fact_version → asset/timecode → delivery_version_id → publication_id → performance_snapshot`。

首周不按播放量直接判定赢家，至少分开看：

- 播放/停留：判断片头和节奏；
- 商品点击：判断购买理由与商品页承接；
- 订单/退款成熟度：判断经营贡献；
- 制作单位成本：判断是否值得规模化；
- 评论与售后：识别“好看但不实用”、规格误解和事实风险。

放大前同时满足：技术/事实/人工质量通过、达到预设最小有效曝光、主指标优于同账号同条件基线、预算/库存/售后边界通过。没有成熟数据时只写“待测”或“观察性结论”。

## 9. 开工前仍需补齐的资料

1. 该链接对应的商品名称、唯一主SKU和选中规格；
2. 商品主图、选中SKU图、详情图、包装图、标签/尺寸/护理图；
3. 实时销售价、库存、优惠和承接页面；
4. 可公开的真实声明、检测/实测证据和适用条件；
5. 图案、Logo、人物、声音、音乐和广告渠道授权；
6. 现有原片、拍摄人员、可拍场景和每周可用人时；
7. 目标账号、发布时间窗口、是否有可用广告测试入口和学习预算上限。

资料补齐后，先完成3条样片（A实物选购、B生活仪式、D答疑承接），通过事实、语义对齐和人工审核，再释放W1剩余12条。
