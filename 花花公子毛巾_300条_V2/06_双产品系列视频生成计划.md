W0必须分别建立两张商品事实卡：

`商品链接 → 商品ID → 主SKU → 颜色/图案 → 材质 → 尺寸/克重 → 包装 → 价格/库存 → 声明 → 证据 → 权利`

## 1. 规模和目标

先做双产品 **4周60条审核去重成片**：P1 30条、P2 30条，每周15条。60条属于双SKU试点，不等于60个独立实验，也不要求公开发布60次。

### 要回答的问题

1. P1和P2分别对应什么购买场景和购买阻力？
2. 每款商品的真实证据镜头是什么？哪些卖点不能说？
3. 在同一生产流程下，两款商品各自的素材补拍量、制作工时、返工率和经营数据如何？
4. 是否存在可以迁移的“选购方法”和“生活场景结构”，而不是未经证实的商品优劣结论？

## 2. 内容架构

每款30条采用相同的结构配额，但具体卖点由各自事实卡决定。

| 内容组 | 每款数量 | 目的 | 生产要求 |
|---|---:|---|---|
| A 实物与选购 | 12 | 让用户看清商品后再决定 | 全貌、细节、标签、规格、展开、折叠、挂放；只用该SKU证据 |
| B 生活场景 | 8 | 连接使用动作和生活触发 | 洗手、擦干、挂好、收纳、浴室/卧室/来客等真实场景 |
| C 疑问与承接 | 6 | 回答购买前最后阻力 | 仅回答页面、客服或真实评论中有来源的问题 |
| D 复验与路径比较 | 4 | 验证可复用性和生产效率 | 新情境复验；保留人工/AI制作记录 |

### 两款商品的关系

- P1、P2各自有独立的主命题、事实、证据矩阵、素材池、生产批根和经营数据。
- 只有在两款商品的规格、价格口径、使用条件和样本条件都可比时，才做“如何选择”的对照片。
- 对照片只回答“什么场景选哪款”，不直接说“P1比P2更好”“P2更柔软/更吸水”等未经同条件实测的结论。
- 同一浴室或同一人物可以作为表达框架复用，但商品画面、字幕、声明和SKU绑定必须分开。

## 3. 四周排期

### W0：双商品准入（不计入60条）

1. 分别从两个详情页导出标题、主图、选中SKU图、详情图、规格、价格、库存、优惠、包装和护理信息。
2. 分别采集真实商品：平铺、手持、图案/颜色、织纹、边缘、标签、尺寸参照、折叠、挂放、擦拭、收纳。
3. 建立 `P1_fact_v1`、`P2_fact_v1`，每个声明绑定 `claim_id/evidence_id/asset_id`。
4. 记录品牌、图案、Logo、人物、声音、音乐和广告渠道授权；未确认的图案不能动画化，未确认的包装不能出现在画面中。
5. 为P1、P2各做1条10—15秒样片，确认商品身份、画面连续、字幕、声音、裁切和事实门。
6. 只有两款都通过准入，才开启同周双SKU生产；一款被阻断时，另一款可以独立推进，但不能把总目标宣称为完成。

### W1：事实与真实使用（15条）

| 编号 | P1 | P2 | 变量 |
|---|---|---|---|
| 1—2 | 商品全貌/细节 | 商品全貌/细节 | 相同镜头结构，不比较优劣 |
| 3—4 | 规格/标签 | 规格/标签 | 页面字段与实物对应 |
| 5—6 | 展开/折叠 | 展开/折叠 | 真实尺寸和收纳结果 |
| 7—8 | 挂放/擦拭 | 挂放/擦拭 | 只展示发生的动作 |
| 9—10 | 购买前检查表 | 购买前检查表 | 各自价格/库存动态读取 |
| 11—12 | 细节先行开场 | 细节先行开场 | 只改变前1.5秒 |
| 13—15 | 3条支持内容 | 3条支持内容 | 评论/答疑/商品页承接 |

实际排产为P1 8条、P2 7条；下一周反向排产，保持四周各30条。

### W2：生活场景（15条）

每款选择4个场景，各做基准和一个开场变体：

- 洗手后擦干并挂回；
- 下班回家后的整理动作；
- 睡前整理洗手台；
- 浴室空间只换一个位置；
- 来客准备独立挂位；
- 同住者区分用品和位置；
- 旅行/收纳，仅在尺寸和体积已核验时使用；
- “好看但担心不实用”的真实问题回答。

场景可以相似，画面不能把P1素材套给P2。含商品的镜头必须标明SKU；纯生活过渡镜头也要记录是否含商品。

### W3：单变量优化（15条）

从W1/W2中各选2—3个已有初步数据的母题，每款制作：

- 基准片；
- 只改变片头问题；
- 只改变第一动作；
- 只改变证据排列；
- 只改变CTA。

一组不能同时改商品画面、优惠、旁白和片头。没有达到预设曝光/点击/订单窗口的素材标记“未成熟”，不产生赢家结论。

### W4：新情境复验与制作路径比较（15条）

为每款选择2个新情境，每个情境制作三种记录：人工组装、AI辅助组装、同构新情境复验。共8条核心内容，余下7条用于评论答疑和交易承接。

记录两款商品各自的人工人时、工具费、等待时间、返工次数、素材复用比例、事实修正次数和质量结论。人工路径不伪造AI阶段产物；两条路径输出实质相同作品只计一条成片。

## 4. 单条视频模板

默认20—30秒、9:16竖屏、6—8个镜头：

```text
0.0—1.5s：问题或第一动作
1.5—6s：明确P1或P2身份与使用场景
6—16s：一个真实动作/证据
16—24s：规格、限制或生活价值
24—30s：动作型CTA
```

每条只保留一个主购买理由，例如“先看实际尺寸”“先看挂放效果”“小空间如何收纳”“页面这个规格适不适合我”。不要把材质、吸水、柔软、抗菌、快干等多个卖点同时塞进一条片。

CTA只使用已核验动作：查看规格、查看颜色/图案、进入商品页、收藏对照、评论区提问。没有实时优惠或库存快照时，不使用“最后一天”“库存告急”等话术。

## 5. OpenMontage生产路线

### 批次组织

使用现有 `cinematic-fast / source_led_template`：

- P1、P2各自建立独立batch root和`product_facts`；
- 每周按`week + product_id + fact_snapshot_hash + production_wave`拆批；
- 每条内容有独立`content_slot_id`和`content_version_id`；
- 两款商品不能共享商品事实、证据矩阵或素材时间码；
- 共用模板只共享结构，不共享商品画面和声明。

### 阶段流程

1. **Research**：建立两套素材语义索引和证据矩阵。
2. **Proposal**：分别锁定P1/P2的主命题、开场、CTA和事实边界。
3. **Script**：每镜绑定`scene_id`、`claim_id`、动作、证据行和`content_role`。
4. **Scene/Assets**：优先召回自有素材；缺商品证据就补拍、改写或删除。
5. **Sample**：每个SKU先通过一条10—15秒样片和人工五项确认。
6. **Compose/QA**：完成技术检查、产品身份检查、字幕/口播对齐和不可变交付版本。
7. **Publish/Readout**：人工发布、登记平台ID，分开导入P1/P2的24小时、7天和30天数据。

真实商品素材和FFmpeg/Remotion主线优先。AI只用于字幕/图文、剪辑变体和不承载商品事实的辅助背景；商品颜色、图案、包装、规格、测试结果和Logo不能由模型补造。

## 6. 双商品素材与拍摄清单

每款至少准备：

- 2条全貌素材（平铺/悬挂）；
- 2条细节素材（图案/颜色/织纹/边缘）；
- 2条身份素材（标签、护理、包装）；
- 2条规格素材（展开与实际参照物）；
- 2条使用动作（取下、擦拭、挂回）；
- 2条收纳动作（折叠、放入真实收纳位）；
- 2条生活场景（浴室/洗手台/卧室或来客准备）；
- 1条连续长镜头，保留完整动作因果；
- 1条干净环境原声。

这是一款商品的最低入池目标；复杂动作可保留多个机位，但不能把同一镜头切成多个无信息片段来凑数量。

## 7. 质量与经营判断

### 发布前四道门

1. **商品事实门**：P1/P2身份、SKU、价格、规格和声明来源清晰。
2. **素材权利门**：商品、图案、人物、声音、音乐和场景可用于目标渠道。
3. **成片质量门**：画面连续、字幕可读、口播与画面一致、商品身份不漂移。
4. **人工交付门**：交付版本、审核记录、发布映射和去重结果完整。

任何一款商品事实变更或授权撤回，只让受影响的商品版本失效，不修改另一款的历史记录。

### 数据读取

每条记录：

`product_id → content_slot_id → content_version_id → fact_version → asset/timecode → delivery_version → publication_id → performance_snapshot`

分别查看P1/P2的播放留存、商品点击、订单、退款、制作成本、评论疑问和售后风险。只有同条件、同口径、达到预设窗口后，才做两款商品的场景级比较；不以单条播放量直接宣布产品赢家。

## 8. 开工前必须补齐

1. 两个链接各自对应的商品标题和唯一主SKU；
2. 选中颜色/图案、材质、尺寸、克重、包装和护理信息；
3. 实时价格、优惠、库存和商品页承接方式；
4. 商品页面可公开使用的声明和对应证据；
5. 两款商品的实物图、详情图和可拍样品；
6. 图案、Logo、人物、配音和音乐授权；
7. 目标账号、首周可用人时、广告测试入口和预算上限。

补齐后先做P1、P2各1条样片，再释放W1首批15条。未补齐资料前，本计划只能用于排产和拍摄准备，不能据此生成可发布广告。
