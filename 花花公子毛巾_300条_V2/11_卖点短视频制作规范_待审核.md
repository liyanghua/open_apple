# 卖点短视频制作规范

版本：v1.0｜日期：2026-10-08｜状态：**候选规范，待审核**。

适用：P1卖点展示类的参考驱动动态短片；本轮实例见[样片方案](10_P1卖点强化与多场景AB样片方案_待审核.md)。本稿不修改当前生效品牌profile，不替换300条规划中的故事、仪式、轻喜剧、真实实测等其他类型规则。

## 1. 规范分层及生效方式

| 层级 | 本轮内容 | 生效与变更 |
|---|---|---|
| 已批准约束 | Seedance 2.5动态素材路径；Remotion；Doubao；官方LOGO；Noto替代字体；固定文字位置；无上下蒙版；完整品牌句 | 延续历史用户批准，按真实文件版本绑定 |
| 本次候选规范 | 卖点与画面对应、多场景层次、参考图角色、前三秒A/B控制、生成次数上限 | 本稿审核后用于本轮；不能提前写成系统已实现或新片已通过 |
| Agent创作空间 | 在已批准卖点与场景内，选择自然手势、镜头起止、光线、运镜幅度和短句停顿 | 记录理由；不能自行改SKU、功效、共同正文或模型 |

文档确认只批准对应的制作方案与措辞，不把商家宣称升级为检测事实，不代替最终人工验收。后续样片反馈形成新修订号，旧版本与审批保留。

## 2. 卖点与证据规范

**SP-01：一项卖点一条依据。** 每项至少记录SKU、claim ID、准确措辞、原文件/页面快照、文件哈希、资料类别、措辞审核状态。10A、银离子抗菌、防臭、吸水分别建映射，不能自动互相证明。

**SP-02：三类证据不得混用。** 品牌主图/商品页属于 `merchant_claim`；真实且可核对条件的取证属于实测证据；Seedance生成视频属于 `generated_visual_expression`。本轮新增10A只补品牌资料来源，不改旧事实卡的待确认状态。

**SP-03：卖点表达必须具体。** 口播讲购买理由；左上标题讲核心关键词；画面给出相符的商品/使用语境。“提起来、拉近看、看包边”可以描述动作，不能替代整条视频的价值表达。

**SP-04：功能画面与证明分开。** 擦手可表达吸水用途，挂放可提供防臭话题的生活语境，但这些画面不证明吸水速度或除臭持续时间。拧水不等于吸水测试。AI不得生成证书、测量数字、虚构实验或检测标签作为依据。

**SP-05：本轮文案不外推。** 不出现永不发臭、抗菌率、秒吸、快干倍数、使用年限、医疗或特殊皮肤适用保证；P1卖点不搬给P2。发布前的正式事实审核另行保留，不能仅靠“AI演绎”字样替代证据要求。

## 3. 镜头层次与动作规范

| 编号 | 候选制作要求 | 如何核对 |
|---|---|---|
| SH-01 | 完整片至少包含环境中景、完整商品、手部使用近景、织纹超近景四类 | 在scene plan标注景别与用途，检查实际帧 |
| SH-02 | 相邻镜头至少改变景别、机位或主体动作之一 | 不把仅换字幕、换裁切或换文件名当成层次变化 |
| SH-03 | 每个主卖点有专属画面；同一微距不连续承担三个不同卖点 | 检查claim→scene对应表 |
| SH-04 | 前1秒内出现可见商品动作，前3秒识别商品与一个主要卖点 | 逐帧查看，不能只有背景/摄影机运动 |
| SH-05 | 每段动作写清“起始状态→动作→可见结束状态” | 模型任务成功不等于动作完成；看实际视频 |
| SH-06 | 主体镜头优先1.8–2.6秒；开头3秒；品牌尾段由配音和余量决定 | 不将全部片型硬压成8–9秒，不为了提速切掉动作结果 |
| SH-07 | 空间中前景、中景、背景服务商品，不靠蒙版制造层次 | 商品与接触部位清楚，装饰不抢主体 |
| SH-08 | 手部出镜为主，延续此前去模特要求 | 不从参考片迁移人物身份；不临时增加完整模特露脸 |

不得用“镜头更多”代替信息推进。两个相邻镜头如果都只是同一堆毛巾的轻微推近，应退回分镜；增加镜头速度也不能补足画面内容缺失。

## 4. 参考图和Seedance规范

**REF-01：输入角色分离。** `product_identity` 为自有商品全貌/细节图；`motion_composition_reference` 为本次用户明确允许使用的参考片关键帧；`brand_overlay` 为后期LOGO、字体和标题。只有商品图承担SKU外观约束。

**REF-02：参考帧不进最终时间轴。** 可作为本轮生成输入的构图/动作参考，但不得伪装成自有商品素材入池。原视频、水印、竞品商标、人物身份、字幕、黑边都不得出现在最终画面。保留参考来源及生成输入角色，不改写原素材所有权。

**REF-03：商品一致性优先。** 锁定实际商品的颜色、毛圈密度、边条、比例、标签位置。不能一张主图用完所有机位，也不能为生成某种动作而换成参考片中的毛巾。

**GEN-01：固定模型参数。** 使用 `seedance_ark`，Ark，`doubao-seedance-2-5-260628`，variant `2.5`，`reference_to_video`，4秒，720p，9:16，`generate_audio=false`。执行前通过工具dry-run验证；不得仅写variant而允许环境变量选到其他模型。

**GEN-02：一段一个主要动作。** 提示词必须包括Subject、Subject Motion、Scene、Spatial Framing、Camera五项，另外列商品保持项、禁止变化、标题/字幕安全区及参考图角色。广告字、LOGO和10A文字后期叠加，不交给视频模型生成。

**GEN-03：按真实输出入池。** 记录task ID、模型、输入哈希、真实分辨率/帧率/时长、选取区间、转场余量、生成成本和动作评审。4秒请求可能返回额外帧；720p放大输出不能称原生1080p。

**GEN-04：重试有上限。** 本轮6段首轮＋整轮最多2次追加。先定位身份漂移、手部错误、动作不完整或服务错误，再只返工失败段。超时先查询已知task；提交状态不明不重新POST；失败和淘汰素材仍记成本。

**GEN-05：参考能力不能静默降级。** 多参考校验失败时先修正参数与资产绑定；不能默默改成纯文本、静态图推拉、其他模型或参考片直接剪辑。对最终产品外观和动作的检查不能只读提示词。

## 5. 品牌与文字规范

以下继承当前 `playboy-production-noto-fullscreen-v3`，以1080×1920成片坐标计。

| 元素 | 固定值 | 内容要求 |
|---|---|---|
| LOGO | 官方资产；右72px、顶96px、宽120px、净空16px | 不由模型重画，不被手/产品关键部位挤压 |
| 字体 | 已批准Noto Sans CJK SC；400/700两份字体文件及哈希 | 预检实际加载，不允许静默系统回退 |
| 左上标题 | x=72、y=220；64px、700字重、行高1.15；2–4字符 | 防臭、吸水、10A、纯棉、多色、日常质感；不重复整句口播 |
| 下划线 | `#4874CB`，高8px，距标题22px，宽等于实际标题宽 | 用真实字体测量，不用固定短横线 |
| 下方字幕 | top=1550；左右72px；38px、400字重、行高1.25 | 展示实际口播；按语义和词时间断句，不缩到不可读 |
| 背景遮罩 | `overlay_background=none` | 无上下宽框、中央事实栏或整画面灰罩 |
| 收尾 | “PLAYBOY，让日常更有质感。” | 完整读完；最后一词之后至少0.4秒 |

**BR-01：10A的字符规则。** “10A抗菌”为5字符，不能绕过当前2–4字符检查。左上写“10A”，完整词组放在口播与底部字幕。修改字体大小或放宽全局标题规则不在本次范围。

**BR-02：可读性检查覆盖深浅背景。** 按实际DOM测量标题、下划线、字幕与安全区，再看最终画面。若纹理背景使黑字难读，优先调整机位、留白和素材选取；需要改变文字颜色/描边时单独记录品牌方案修订，不偷偷加回蒙版。

**BR-03：检查转场重叠区。** 字幕不仅与当前镜头的手部区域比较，也要覆盖前后镜头的5帧转场重叠区。允许依实际词时间拆短句；拆分边界不能切掉前一个词的显示区间。

## 6. A/B、配音、音乐与剪辑规范

**AB-01：预登记比较对象。** 本轮变量是“完整开头方案”，包括前三秒的语言与画面组合；不声称只验证一个词。正文、声线、品牌版式、音乐、时长和输出规格固定。

**AB-02：正文共享。** 共同正文仅采用一条TTS音频；A/B钩子独立生成。第90帧为共同正文起点，85–89帧内完成开头转场，不能让旧开头在第3秒之后仍然可见。两版完整导出后检查共同正文帧与音轨，而不只比较JSON。

**AU-01：先语音后排时。** 以实际词时间建立字幕和镜头线；检查“10A”“银离子”和PLAYBOY读法，快而清楚优先。只删除确认为静音的空档，不砍辅音、尾音或呼吸；不用统一加速整条音频解决时长。

**AU-02：接缝自然。** 开头与正文保持同一声线、语气、采样与混音规格；开头先测长，再微调允许范围内的语速。明显空等或语气断裂必须修正，不因分段TTS而接受机械拼接。

**AU-03：本轮不再测试音乐。** 复用上一轮B的SUNO文件，两版共同选择适合新片长的片段。人声优先，音乐相对口播约低10–14dB仅作为初始试配；必须测量与试听，不把轨道volume参数当响度证据。

**AU-04：公平响度。** 目标约-14LUFS、真峰值≤-1.5dBTP、两版整体差≤0.5LU。锁定正文stem、BGM增益包络和混音参数，不能分别整片归一化而改变正文音频。AAC边界的量化差异与实际内容差异分别记录。

**ED-01：5帧转场＋连续品牌层。** 使用现有实现，先核对源片段的入出余量。转场检查覆盖闪白、闪黑、亮度突变、手部跳位、字幕重叠和全层淡出。不得为了复制参考节奏重复使用同一个动作片段。

**ED-02：走正式渲染出口。** `video_compose`＋Remotion ProductionBrand完整渲染。当前该路径不承诺mux-only；最终文件验证H.264/AAC、yuv420p、尺寸、帧率、解码、音轨和正常播放。

## 7. 主线记录、质量状态与批量复用

| 环节 | 必须保留 | 归属 |
|---|---|---|
| 事实与脚本 | SKU、事实版本、claim ID、文案审核、证据类别 | 确定性校验＋人工事实判断 |
| 分镜 | claim→shot、镜头用途、景别、动作、参考角色、正文控制关系 | Agent设计，代码校验引用与区间 |
| 素材生成 | 参数dry-run、幂等任务、输入/输出哈希、费用、实际动作结果 | 工具执行，Agent解释失败与最小返工 |
| 合成 | 字体/LOGO、字幕词时间、安全区、转场、完整混音 | 参数化组件与实测检查 |
| 自动检查 | `pass / fail / not_run / error`及对应视频哈希 | 代码保留原始状态，不能补造分数 |
| 人工审核 | 检查项、具体视频版本、意见、通过/退回 | 与机器结果分开保存 |
| 交付 | 完整片、3秒预览、生产记录、费用与差异报告 | 审核台读取同源记录 |

`alignment` 的同音字/时间差异保留，不能替换原始ASR使它看起来正确。`video_judge`若只接收画面帧，不能宣称听过BGM或认证声音；没有通过阈值策略的评分只能作为建议。格式错误最多一次修复重试。

审核台应展示本次实际检查；旧稿的审批不会因为文件名相似而迁移。内部认可、完整生产认证、独立作品计数与经营效果分别记录。

本次新方案先沿用现有主线，不在生产中开发基础设施。参数检查、哈希、预算、字体、字幕布局与正文比对适合代码固化；提示词方法、景别切换、动作评审与最小返工适合阶段skills；具体钩子、动作细节、运镜与剪切点继续由Agent决定并留理由。候选规范须经过样片验收后才推广。

## 8. 审核与后续验收场景

| 场景 | 应有结果 |
|---|---|
| 主图写10A但无检测报告 | 记录品牌宣称和原图，不补造认证/检测结论 |
| 用抗菌宣称解释“永不发臭” | 退回文案；两项主张分开核验 |
| AI水效被标为秒吸实测 | 阻止采用该结果表述，生成片不作实测证据 |
| 六个镜头只是同一台面近景 | 退回分镜，补场景、动作和景别变化 |
| 只有摄影机移动，毛巾未执行计划动作 | 动作未完成，不能按生成成功入合格池 |
| 参考字幕、竞品字样进入生成画面 | 退回该素材，不靠遮罩掩盖后直接放行 |
| “10A抗菌”放入左上标题 | 当前字符检查应拒绝，改用“10A” |
| 5帧交叠时字幕盖住手部 | 按词时间拆句或调整画面区间，重新检查 |
| B只改了开头，却连正文TTS/BGM都变了 | 对照失效；重建共享正文，不作为有效A/B |
| Slogan未读完或余量不足0.4秒 | 延长共同尾段/修复配音；两版同时更新 |
| 远端超时但任务可能已提交 | 先查询，不重复付费提交 |
| 审核后改了素材、文案或混音 | 生成新版本，原审批不能直接放行新版 |

以上是待执行的验收场景，不表示本轮已经完成自动化实现或测试。
