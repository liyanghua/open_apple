# 花花公子毛巾内容经营布局与周度AI实验方案

**版本：V2.0 · 300条版｜编制日期：2026年9月13日｜适用范围：花花公子家居毛巾品类的抖音内容试点**

> 品牌经营主张：把每天会用到的家居用品，变成更舒服、更有趣、也更能表达心意的生活选择。
>
> 内容经营方式：需求与情绪 × 内容结构 × 品牌与IP人格 × 商品与证据；以周度实验决定资源配置，以真实素材和经营反馈积累可复用资产。

## 0. 本轮决策摘要与使用边界

### 0.1 五项建议先固定

| 决策 | 本方案的默认设计 | 何时允许改变 |
|---|---|---|
| 品牌方向 | 沿用既有总纲的“玩趣生活家居”，毛巾是首个验证品类 | 有稳定的用户反馈与经营反证，再调整，不因一条爆款改品牌 |
| 账号与人设 | 一个主账号、一个“懂产品，也懂生活”的生活主理人；实测、治愈、关系是同一人的不同侧面 | 单号验证、放量复验后，有增量证据才评估扩号 |
| 首批商品 | 棉＋莱赛尔20.9元、萌兔49.9元为主实验对象；运动系列选定一个真实规格为场景验证对象 | 依据事实完备度、库存、贡献和可判定数据替换；不是按售价推断优劣 |
| 内容产能 | 完整4周周期预留300个去重成片槽位：240个实验版本＋60个信任/评论/承接内容；每周75个 | 预算或证据不足时缩减在测组合，不强行凑300条公开发布 |
| 评价方式 | 退款调整后的内容贡献利润为结果；有效实验成本、独立复验通过率、合格消耗容量为核心过程指标 | 不因播放量高而跳过商品与利润验证 |


### V2更新：300条的四本数量账

| 数量口径 | 初始分配 | 校验 |
|---|---|---|
| 按周 | W1/W2/W3/W4各75条；每周60实验＋15支持 | 4×75＝300 |
| 按任务 | 240条实验；30条信任、15条真实评论/FAQ、15条交易承接 | 240＋60＝300 |
| 按主方向 | 实测选购90、治愈75、关系60、空间/玩趣45、评论答疑15、交易承接15 | 90＋75＋60＋45＋15＋15＝300 |
| 按主商品 | 棉＋莱赛尔100、萌兔120、运动固定规格80 | 100＋120＋80＝300 |

这四种口径描述同一批内容，**不能相加**。其中实测选购90条已经包含30条信任支持。每条记录只有一个主方向、一个主SKU和一个内容ID。

300是审核后去重成片的**计划交付量**，不是已完成视频数量。重复发布、重复追投、复用同期基准、只换封面或文件名不新增计数。实质不同的开场可记一个内容版本，但不会因此变成独立统计实验。W4人工/AI若导出同一个实质作品，只算一条，缺额按新内容补位或明示未完成。

本版沿用原方案的完整4周周期。3款SKU不机械扩成15款，也不自动扩5倍媒体预算。100/120/80只是待校准的供给分配，不是投放预算比例或销售承诺。W2—W4的SKU与方向由成熟结果批准，JSON中的工作稿是待选候选，不是已经确认的赢家。

### 0.2 和原有经营规划的关系

既有《花花公子家居饰品_智能化经营总纲_v5_爆款短视频流水线》提出“玩趣生活家居”、品类作战小组和“需求—商品—内容—成交/退货—经验回写”的闭环。本方案是其毛巾内容执行层，不另建一套品牌定位。[S1]

既有《爆款视频打造_9月作战规划_V5建议稿》区分了9月毛巾5万元验证目标与后续全项目100万元挑战，保留3款SKU、60+内容，并要求按利润、容量与承接证据晋级。V1沿用60条规模；本次按要求把内容交付计划提升到300条，原经营目标和历史记录不随数量被改写。本方案承接该边界，但**不把新的4周排期自动压缩到9月剩余时间，不重置原经营日历，不声称已具备5万元或100万元的实现概率**。既有费比≤20%、利润率5%基准/10%进阶属于规划约束，不是已实现数据。[S2]

### 0.3 信息分成四种，不混写

| 标识 | 含义 | 本文例子 |
|---|---|---|
| 用户提供 | 本次对话中给出的商品名称和参考价格 | 萌兔款49.9元；不是实时成交价或已核实成分 |
| 既有规划 | 已查阅方案中提出的战略与阶段目标 | 玩趣生活家居、3款SKU、60+内容 |
| 本轮建议 | 需要团队批准并通过实验校准的设计 | 栏目名、SKU优先级、75条/周、实验顺序 |
| 待核验 | 没有实物/报告/授权合同/财务台账支持的内容 | 具体纤维比例、干燥性能、授权形象延展、真实贡献利润 |

没有接入实时商品后台、投放账户、库存、授权合同或检测报告；本文没有虚构这些数据。所有栏目名、账号名和角色描述均为创意工作稿，并非品牌方已批准的官方设定。

## 1. 四层布局：把“一个选题”改成“一个可验证的购买理由”

### 1.1 四层各负责什么

| 层次 | 必须回答的问题 | 形成的对象 | 主要失误 |
|---|---|---|---|
| ①需求与情绪 | 谁，在什么时刻，想完成什么事情、从什么感受变成什么感受？ | 需求单元D：场景＋任务＋阻力＋情绪变化＋购买触发 | 只有“年轻女性”“治愈”这种大标签 |
| ②内容结构 | 用什么叙事让用户看懂需求、相信商品，并知道下一步？ | 内容配方P：开场＋事件/问题＋商品动作＋证据＋结尾 | 同一段卖点文案换音乐、换滤镜 |
| ③品牌与IP人格 | 为什么这句话由花花公子家居的这个角色来说？用户记住什么？ | 品牌/IP设定I：态度＋人格＋场景＋表达＋识别元素 | 泛情感故事加片尾Logo，或把品牌变成毫无差异的可爱号 |
| ④商品与证据 | 为什么此时选这款，而不是任意一条毛巾？ | 商品单元S：真实SKU＋规格/价格＋声明＋证据＋库存＋经济性 | 价格高等于品质高，名称等于功效，故事好看等于会成交 |

每条成片使用同一张“内容经营卡”：

**需求D → 结构P → 品牌/IP I → 商品S → 证据E → 交易承接L → 实验X → 结果R。**

这是业务记录链，不要求先建设复杂知识图谱。第一版用五张表和一个共享文件夹即可落地。

### 1.2 一个完整示例

**不是：**“做一条萌兔毛巾治愈视频。”

**而是：**“针对下班回家、想把私人时间和工作状态分开的人，以生活微仪式结构，由同一位生活主理人展示洗手、擦干、挂好毛巾的完整动作；用萌兔款的真实图案、实际尺寸与真实使用镜头承接‘给自己换一件喜欢的日用品’，验证情绪入口能否带来合格的商品点击与订单贡献。”

本轮可以改变开场“今天没做完的事，先放一放”与“回家后，我先换回自己的节奏”；不能同时改变SKU、价格优惠、商品页面、投放人群和主体证据，却把差异全部归到开场上。

### 1.3 不做四层全排列

10个需求×6种结构×多个人格×全部商品，会迅速制造大量没有意义的组合。先用四道条件筛掉不成立的组合：商品确能参与该动作、已有真实证据、品牌表达适配、具备库存与基本经济性。每周最多围绕2—3个主要经营问题展开，未得到答案的问题可跨周延续。

## 2. 账号定位与花花公子品牌×IP人格

### 2.1 账号定位

| 项目 | 建议 |
|---|---|
| 经营定位 | 花花公子玩趣生活家居的毛巾品类验证账号 |
| 消费者主张 | 把洗脸、洗澡、回家的几分钟，过得舒服一点、有趣一点 |
| 用户获得的价值 | 看得见的商品细节、可以照着做的生活小动作、轻松而不空泛的关系表达 |
| 人格定位 | 懂产品、会选购、有审美，也愿意认真照顾自己和身边人的生活主理人 |
| 起始人群 | 用生活任务界定：日用换新者、独居/同住生活布置者、运动使用者、来客准备者；不先假定年龄性别分布 |
| 账号名称工作稿 | “花花公子家居·玩趣生活局”或在现有合规账号名称下使用同名栏目体系；最终以授权与平台审核为准 |
| 简介工作稿 | “认真选日用品，也认真过自己的小日子。毛巾实测｜玩趣浴室｜给你留个位置。” |
| 不做什么 | 泛科普百科、廉价悲情号、恋爱导师、纯卡通娱乐号、只靠低价促销的货架播报号 |

以上是针对该家居业务的品牌表达提案，不是对花花公子全球品牌官方价值观的转述。

### 2.2 品牌和IP的分工

**品牌回答“我们代表怎样的生活选择”，IP回答“谁用怎样的方式持续表达这种选择”，商品回答“购买后能拿到什么”。**

| 品牌表达方向 | IP的日常表现 | 商品必须兑现的部分 |
|---|---|---|
| 玩趣，而非幼稚 | 具体的小幽默、图案惊喜、生活反差 | 实物图案与颜色确实存在，不通过生成模型改款 |
| 悦己，而非空泛鸡汤 | 做一个照顾自己的动作，而非讲一段励志道理 | 真实使用、实际尺寸、符合事实的材质/洗护信息 |
| 会表达关系，而非煽情 | 给来客准备毛巾、留挂位、尊重对方的使用习惯 | 有可购买的规格，包装与组合不虚构 |
| 有审美，而非奢侈炫耀 | 普通家庭也能复现的小范围布置 | 同机位前后对比，不把灯光/滤镜功劳算给商品 |
| 可信，而非假权威 | 说清观察条件、承认不确定、报告对应样品 | 声明—证据—SKU—批次之间能追溯 |

### 2.3 一个主IP，三种人格侧面

首期不创建三个人设账号，也不同时建设三套角色世界观。使用同一个可识别的人物、声音或授权出镜团队代表：

| 侧面 | 说话方式 | 典型动作 | 对应栏目 |
|---|---|---|---|
| 认真选购的一面 | “先看实际尺寸，再看这个细节。” | 量、洗、称、展示标签和真实使用 | 《毛巾认真测》 |
| 照顾自己的一面 | “今天，先到这里。” | 回家、洗手、擦干、整理和挂好 | 《下班后的三分钟》 |
| 会照顾人的一面 | “给你留好了，不用像做客。” | 准备独立用品、留位置、记住偏好 | 《给你留个位置》 |

“实测”和“治愈”不是互斥人格：同一个人既认真买东西，也认真过日子。运动、浴室改造、轻喜剧是表达场景，不新增一套人格。

### 2.4 IP设定卡

| 字段 | 初始约定 |
|---|---|
| 工作称呼 | 生活主理人；真实姓名/昵称及是否使用“花花”由品牌授权负责人批准 |
| 稳定主张 | 日用品值得认真选，小日子也值得认真过 |
| 身份边界 | 普通生活使用者与选购分享者，不虚构检测资质、医护背景、工厂身份或独立第三方评测身份 |
| 语气 | 平等、具体、轻松；少形容词，多动作与事实 |
| 幽默 | 来自生活小反差，不嘲笑身体、收入、关系状态和家庭角色 |
| 情绪 | 松弛、有分寸的温暖、轻巧的玩趣；不靠制造卫生恐惧和情感缺失推动购买 |
| 视觉 | 同一实际居家空间与道具语言；中性底色搭配实物色彩，不把所有内容做成相同的粉色治愈滤镜 |
| 品牌识别 | 在授权允许的条件下使用实物商标、合规字幕或栏目识别；前两周保持稳定，不同时试Logo与剧情 |
| 固定表达 | 栏目各保留一个可识别的句式；每集剧情与商品动作必须有实质变化 |
| 人物/声音一致性 | 使用获授权的真人或明确标识的虚拟角色；不擅自克隆他人声音或伪装消费者证言 |

### 2.5 四种IP路径的投入顺序

| 路径 | 首期安排 | 晋级条件 |
|---|---|---|
| 栏目IP | 立即使用，经名称与授权审核后发布 | 不需要先有动画角色，先验证需求与商品承接 |
| 原创轻角色 | 暂存设定，不把它设为首月制作依赖 | 至少有可复验的母题；品牌审批角色权属、形象延展和使用范围 |
| 外部治愈/情感创作者 | 第5周后作为可选迁移实验，不与首轮主实验混算 | 同一SKU、已知贡献边界、可使用原片及广告的明确授权 |
| 成熟IP联名 | 后置独立商业项目 | 商品授权、改编权、投放权、授权成本、库存风险与销量假设完整 |

萌兔商品图案不自动等于可开发的原创角色；兔头标识也不自动等于可以改造成动画人物的授权。执行前由合同与品牌方确认，不以“已经有品牌授权”替代逐项核验。

## 3. 第一层：需求与情绪地图

下面的用户原话均为**创意假设**，不是实际调研引语。上线后必须由真实评论、客服、搜索词和订单/退款原因支持、修订或删除。

| 编号 | 生活触发与任务 | 阻力/不满意 | 希望发生的情绪变化 | 商品参与动作 | 候选商品与证据 | 购买触发工作稿 |
|---|---|---|---|---|---|---|
| D01 日用换新 | 每天洗脸/洗手；想换掉不合适的日用品 | 不知道规格、材质和实际体验怎么选 | 犹豫→清楚，凑合→主动选择 | 展开、擦干、挂好 | S01；实物规格、标签、真实使用 | “不是把毛巾堆满，而是先选一条适合每天用的。” |
| D02 下班悦己 | 回家后想结束工作状态 | 内容中的放松很空泛，日常缺少小变化 | 紧绷→放松，敷衍自己→认真一点 | 放钥匙、洗手、擦干、整理 | S08/S01；真实图案与使用细节 | “把喜欢的小图案，放在每天会用到的位置。” |
| D03 来客与关系 | 朋友/家人来小住，需要准备用品 | 不知道用哪条、放哪儿，显得拘谨 | 生分→被欢迎，客气→有归属 | 取出干净用品、留独立挂位 | S08/S07；实际规格、真实包装条件 | “来住就好，不用像做客。” |
| D04 浴室微改造 | 觉得浴室杂乱或缺少审美统一 | 不想重装，也不想买很多装饰 | 将就→有秩序，普通→有一点趣味 | 只更换毛巾/挂放方式 | S05/S06/S08；同机位、真实颜色和尺寸 | “不换柜子，先换这一个小位置。” |
| D05 轻装与收纳 | 旅行、小浴室、有限收纳 | 不确定体积、重量、展开大小是否合适 | 麻烦→省心，拥挤→清爽 | 折叠、放入自己的包、展开 | S03/S04；实际重量体积，不能凭名称推断快干 | “这次出门，我先看它能不能放进这格。” |
| D06 运动后整理 | 运动后要擦汗、收拾和带走用品 | 吸水、携带、干燥是不同需求，常混着讲 | 狼狈→清爽，有负担→有秩序 | 擦汗、折叠、装袋/独立收纳 | S04一个确认规格；真实使用、体积、测试条件 | “练完后的最后一步，是把自己的东西收好。” |
| D07 共同生活 | 同住者希望区分各自用品与位置 | 易混淆、空间拥挤、互相提醒 | 混乱→边界清楚，重复沟通→默契 | 标注/区分实际颜色或位置 | S06/S01；有可购差异才讲配色区分 | “我们没换大浴室，先分清了这两个位置。” |
| D08 预算与品质选择 | 在20多元至50元款式间比较 | 价格不同，却不知道差别是否与自己有关 | 怕买错→有把握，不甘凑合→合理选择 | 对照实物差异与使用场景 | S01/S07/S08；按真实差异，不预设贵的更好 | “多花的钱，究竟买到了哪一种差别？” |
| D09 洗浴仪式 | 洗浴后希望有完整的生活体验 | 尺寸不确定、薄厚与收纳选择困难 | 匆忙→从容，使用→享受小仪式 | 实际展开、正常使用、晾挂 | S09；尺寸和真实使用，不生成虚假包裹效果 | “洗完澡的最后一步，也值得认真选。” |
| D10 证据与安心 | 看见银离子等术语，不知道能信什么 | 名称、报告、样品与实际功效容易脱节 | 被术语牵着走→理解依据 | 看标签、核对对应报告、展示条件 | S02；相符证据是前提，不制造健康焦虑 | “先不看名字有多厉害，先看证明对应哪一款。” |

### 3.1 需求单元的采集办法

每条真实需求记录保留：原始文本、来源渠道、采集时间、关联商品、具体场景、出现次数或覆盖人数口径、是否含购买意向、是否来自售后、脱敏状态。AI先聚类，人再判断。

只按相同意思聚合，不把一条热门评论视为普遍需求。对“需要礼盒”“想要成套”“颜色选择少”等信号标为**商品需求**，不能通过虚构包装或AI改色来假装解决。

### 3.2 选择本周需求的优先级

先过事实与商业准入，再用内部评分排序：需求具体性25、商品匹配25、可视化证据20、品牌适配15、低成本可测试性15。分值是工作流建议，不是平台算法；每两周按实际采用与结果修正。

第一轮优先D01、D02、D06；第二轮探索D03和D04。其余保留在候选池，不同时开十条战线。

## 4. 第二层：六种可复用内容结构

以下秒数仅作起始分镜参考，不是推荐算法阈值。可以先做18—35秒主体；需要解释条件的实测可延长，不能为了固定时长删去必要限定。

| 编号 | 结构 | 骨架 | 商品出现方式 | 适合需求 | 主要失败信号 |
|---|---|---|---|---|---|
| P1 真实验证 | 用观察和证据降低疑虑 | 具体问题→条件→观察过程→结果边界→选择建议 | 从被测试的对象开始 | D01/D05/D06/D08/D10 | 看起来专业，却没说清适合谁；演示被包装成检测 |
| P2 生活微仪式 | 让用户看到可以照着做的小选择 | 生活触发→一个动作→商品细节→小变化→自然承接 | 商品完成关键动作，不是片尾插入 | D01/D02/D06/D09 | 只剩音乐慢镜头；换成任意商品也完全成立 |

| P4 空间微改造 | 展示局部的可复制变化 | 同机位现状→一项改变→真实细节→同机位结果→规格选择 | 商品本身是变化来源 | D04/D07 | 同时换灯光、滤镜、空间和饰品，误归因给毛巾 |
| P5 轻喜剧反差 | 用生活小反差制造玩趣 | 熟悉的小麻烦→轻巧反转→真实使用→一条清晰理由 | 在反转中解决实际小问题 | D06/D07/D01 | 只记得梗，不记得商品；夸张到改变事实 |
| P6 场景选购 | 帮助做取舍 | “你主要用来做什么”→2—3个选择维度→证据→明确选项 | 商品就是被比较的方案 | D01/D05/D08/D10 | 多款信息堆叠；无依据地对材质做高低排序 |

TikTok官方的通用创意建议强调清晰开场、商品利益点、行动引导、探索期的实质创意差异以及素材资产库。本方案仅借鉴创意原则，不把TikTok建议等同于抖音机制或本账户成效。[S3]

### 4.1 感官治愈是表达组件，不是独立购买逻辑

织纹特写、水声、展开与折叠动作可以加入P1/P2/P3/P4，但必须基于实物。它们负责让内容可感知，不负责替代尺寸、使用场景和购买理由。

真实录音可以表现当时的声音，不把人为添加的音效当作材料性能证据。图案、纤维表面与水分行为不得通过生成或后期夸张成商品不具备的效果。

### 4.2 同一结构的固定与可变项

固定：商品事实、品牌边界、这一轮的主体证据、交易承诺、对照条件。可变：开场的提问方式、第一动作、镜头排列、证据呈现、旁白密度或CTA。探索期可比较整套表达；优化期一次只改变约定变量。

### 5.1 为什么首批是S01＋S08＋S04

S01与S08用于在各自商品内部比较购买动机；S04提供明确的运动任务作为场景对照。这个选择是本轮创意试验建议，不是历史销售排名，也不是永久替换原有主推款。

如果某款的事实、库存或贡献缺失，先补齐；仍不能通过准入时，用事实完备的相近商品替补，并登记选择变化。不得带着缺失数据“先把故事做出来再说”。

### 5.2 商品的五道准入门

| 门槛 | 必须具备 | 不通过的处理 |
|---|---|---|
| 实物 | 明确SKU、规格、实拍、实际可购选项 | 仅进入需求草稿，不生成可发布成片 |
| 声明 | 每个可检验卖点有来源与适用范围 | 删除无证据声明；严重依赖该声明的母题暂停 |
| 交易 | 链接、当前价格/优惠规则、库存、售后信息 | 不制作价格型承接；不放大不可交付商品 |
| 经济性 | 净收入、商品/履约/渠道/退款成本及投放上限口径 | 允许有限学习，不称合格利润款 |
| 权利 | 商标、图案、人物/声音、音乐、广告使用范围 | 未确认内容不发布、不投放 |

### 5.3 内容占比不等于媒体预算占比

“引流40%、腰部35%、利润25%”只可作为初始内容排期讨论，不直接分配投放预算。媒体预算优先给**已经具备贡献与复验证据的内容×SKU组合**。S08即使承担形象表达，仍可能未达到付费经济性；S01即使价格低，也可能由于多件购买或其他真实订单结构表现不同，必须分别核算。

多件装、浴巾组合和礼盒属于新的交易方案；没有真实可售组合，不在视频中制造“套装可买”的印象。商品角色以实际经营表现更新，不能按售价永久贴上利润标签。

## 7. 可直接转分镜的四条示范脚本

所有脚本都是待核实后制作的创意稿。“实测结果”位置不能由AI补写。场景可演绎，但不得把演员写成真实购买者、把虚构生活写成已验证用户故事。

### 7.1 S01｜实物选购版｜约28秒

| 时间 | 画面与动作 | 旁白/字幕 | 事实与制作要求 |
|---|---|---|---|
| 0—3秒 | 手里展开真实毛巾，镜头直接看到商品 | “选每天用的毛巾，我先看清楚这三件事。” | 开场不出现未经核实的比较结果 |
| 3—8秒 | 标签与尺子展示 | “实际多大，标签写了什么。” | 尺寸和成分必须对应当前SKU；不可读信息不补造 |
| 8—14秒 | 正常洗手后擦干，保持真实动作 | “再看它放进自己的使用习惯里是什么样。” | 生活演示不是标准性能检测 |
| 14—20秒 | 展开、边缘、挂位与收纳 | “挂在哪里、怎么洗，也一起想清楚。” | 按真实洗护标签说明 |
| 20—25秒 | 回到实际商品全貌 | “这一条，先把规格和实物看明白，再决定。” | 不总结未验证的优越性能 |
| 25—28秒 | 商品卡与清晰规格引导 | “当前规格和价格见商品卡。” | 价格变化风险由动态承接处理 |

开场A：“20多元选日用毛巾，我先看这三件事。”仅在当前价格已核实时使用。开场B：“每天会用的那条，先别只看名字。”其余主体保持不变。

### 7.2 S08｜下班微仪式版｜约28秒

| 时间 | 画面与动作 | 旁白/声音 | 事实与制作要求 |
|---|---|---|---|
| 0—3秒 | 钥匙放下，背景能看到真实毛巾 | “今天没做完的事，先放一放。” | 情绪情境，不承诺治疗或心理效果 |
| 3—8秒 | 洗手、关水，保留环境声 | 主要用现场声音 | 音效不冒充材料性能 |
| 8—15秒 | 用真实商品擦手，展示图案 | “把喜欢的小图案，留在每天都会用到的地方。” | 不生成新的兔子、配色或刺绣 |
| 15—21秒 | 展开并挂好，呈现实际尺寸关系 | “这次换的是这条萌兔款。” | 与链接实物一致 |
| 21—25秒 | 生活主理人整理台面，动作结束 | “今天，先到这里。” | 固定人格表达，不增加说教 |
| 25—28秒 | 规格与商品卡承接 | “同款图案、尺寸和洗护见详情。” | 详情页先展示同款，再讲参数 |

本轮变体只改开场或第一动作，不把颜色、优惠、人物和主体同时替换。图片“好看”不是吸水或耐洗证据。

### 7.3 S08｜关系微故事版｜约30秒

| 时间 | 画面与动作 | 旁白/字幕 | 事实与制作要求 |
|---|---|---|---|
| 0—3秒 | 一个空挂位 | “朋友第一次来住，我先给她留了这个位置。” | 情景演绎不包装成真实消费者评价 |
| 3—9秒 | 清理台面、准备干净用品 | “不是客套，是让她不用问：我用哪一条？” | 不以“新”暗示未真实确认的包装状态 |
| 9—17秒 | 展示毛巾图案、展开并挂好 | “这条给她，这个位置也给她。” | 用实际图案/尺寸，不添加不存在的礼盒 |
| 17—24秒 | 来客进门或自然的生活动作 | “来住就好，不用像做客。” | 关系表达保持轻松，有分寸 |
| 24—30秒 | 回到商品与空间 | “这次准备的是萌兔款，同款见商品卡。” | 商品必须是故事里的实物，而非换链 |

替换测试：朋友→家人不是只换一句称呼，而是新的关系场景，要登记新的需求条件；不能把这种变化当成纯开场实验。

### 7.4 S04｜运动整理版｜约26秒

| 时间 | 画面与动作 | 旁白/字幕 | 事实与制作要求 |
|---|---|---|---|
| 0—3秒 | 运动结束，整理个人物品 | “练完之后，我把最后一分钟留给整理。” | 不暗示运动成效或健康功效 |
| 3—9秒 | 正常擦汗动作 | “擦干，再把自己的东西收好。” | 不使用夸张吸水特效 |
| 9—16秒 | 实际折叠、放入个人包的指定位置 | “我选这条，也会看折起来放哪儿。” | 展示真实体积，不泛化适配所有包 |
| 16—22秒 | 实物规格、正常晾挂 | “尺寸和洗护，看自己怎么用。” | 规格确定后再出现数字 |
| 22—26秒 | 商品卡 | “这次用的具体规格见商品卡。” | 不能把27.9元档价格配给44.9元档实物 |

### 8.2 300条不等于300次机械公开发布

300个槽位指完成事实与合规审核、可进入相应分发测试的内容交付。自然公开内容优先选择有实质差异的完整作品；近似开场变体只在账户实际允许的广告/测试入口内使用，不机械刷屏。若没有可用实验入口，缩减近似变体，使用差异明确的分批内容，并将结论等级标为观察性。

本方案不预设抖音账号可挂几个链接、不预设后台具备何种AB测试或素材追投能力。沿用你此前描述的单计划多素材结构时，以实际权限操作；业务策划默认每条只推动一个主商品决策，对比内容再考虑第二个候选。

### 8.3 主页与置顶

建议置顶“账号能帮你解决什么”“如何按真实场景选毛巾”“一个已经核实的代表性使用/测试内容”。只展示真实可公开的授权或检测材料，不虚构工厂身份和品牌官方资质。

使用封面栏目标签帮助识别，不把页面分割成三个完全不同的视觉品牌。历史内容有价格、活动和证据过期时要登记复审，而不是继续当常青素材。

### 8.4 视频—商品页—直播三处同一个购买理由

| 内容入口 | 商品页首要承接 | 直播应回答 | 不能出现的断裂 |
|---|---|---|---|
| 图案悦己 | 同款真实图案、尺寸、使用画面 | 哪个规格、什么价格、怎么洗 | 视频是萌兔，落地先展示无关低价款 |
| 来客准备 | 单件/真实组合、数量、包装条件 | 几个人、买几条、如何区分 | 视频暗示礼盒，实际只有散装单条 |
| 运动任务 | 具体规格、实际携带与使用场景 | 擦汗、带走、晾晒分别有什么依据 | 一句“专业运动”替代实测 |
| 性能实测 | 同一SKU、条件、结果适用范围 | 哪个样品/批次，测试能说明什么 | 直播扩大成全部批次的绝对承诺 |
| 浴室改造 | 实际色差说明、尺寸、真实组合选项 | 哪一款对应视频场景 | 用AI效果图替代实物承诺 |

商品页和直播有任何主动变更，都写入实验记录；不能一边改承接，一边把订单变化全归因于新文案。

## 9. 四周300条实验：数量扩大，问题仍然收敛

### 9.1 每周75条，15个实验组分批推进

| 周次 | 问题 | 60条实验内容的组成 | 15条支持 | 输出 |
|---|---|---|---|---|
| W0 准备 | 商品和事实能否进入生产？ | 不计入300条；锁3款真实SKU、授权、成本、素材 | 账号/IP设定、测试入口核验 | 三款准入卡、拍摄清单、预算与数据读取规则 |
| W1 购买理由探索 | 事实入口与生活仪式，哪些组合值得继续？ | 15母版×4个实质开场＝60 | 信任9＋答疑3＋承接3 | 同SKU的候选或待测判断；不跨价格硬比 |
| W2 新表达探索 | 关系/空间/玩趣能否增加购买理由？ | 15组×（同期基准1＋新表达3）＝60 | 信任7＋答疑4＋承接4 | 可继续的表达组合；不是单因果证明 |
| W3 单变量优化 | 瓶颈在开场、证据还是结尾？ | 15组×（基准1＋同一变量的3个改版）＝60 | 信任7＋答疑4＋承接4 | 各组只改一类变量，不串行叠加 |
| W4 独立复验＋生产法 | 新情境还能成立吗？AI路径总成本如何？ | 15组×2个新情境×人工/AI两条路径＝60 | 信任7＋答疑4＋承接4 | 30个配对简报的质量/成本记录；经营结果单独核验 |
| 合计 | 四周60个排期实验组 | 240 | 60 | 300个去重成片交付名额 |

每周15组由S01的5组、S08的6组、S04的4组构成；每组4个成片。**15组是排期单位，不要求15组同时上量，也不是15个彼此独立的消费者样本。**每周仍只回答2—3个主要问题；组是同SKU、同类问题下的内容/复验实例。

### 9.2 W1：15母版，真实情境与开场变化

S01五个母版：3事实＋2仪式；S08六个：2事实＋4仪式；S04四个：2任务验证＋2整理仪式。每个母版制作问题、生活触发、第一动作、实物细节四种实质开场。主体商品、事实、价格、承接与IP在组内固定。共事实28条＋治愈32条。

跨母版可能改变需求与叙事，所以只能先筛“表达组合”；四个开场不是四次独立复验。日用品、萌兔、运动款先各自内部比较，不用绝对ROI推断哪种情绪表达在所有商品上更好。

### 9.3 W2：同期基准＋新表达，不把整套变化说成单因果

每组围绕同一SKU建立一个同构新情境的基准，再给三个关系/空间或轻玩趣表达。候选由前轮成熟数据选择；附件保留默认方向占位，必须经周复盘批准。W2计划：事实4、治愈11、关系20、空间玩趣25。

基准如果直接复用W1成片，只登记新增曝光与成本，不计新增视频。要完成本轮新增配额，可以补拍同构的新情境基准或生成有实质变化的独立复验片；不能重复导出旧片充数。

S04只保留自然成立的运动搭子、各自用品、收纳秩序等表达，不强塞浪漫或礼赠。前轮没有足够答案时，本周槽位转为补证/补样本；更新版本与数量账，不预先宣布赢家。

### 9.4 W3：一组只改一个维度

每组四个版本：基准＋三个改版。某组可以只测试开场，另一组只测试证据排列，另一组只测试结尾承接；**同一组不能同时测试开场、商品性能和价格**。所有改版都回到共同基准，不逐层叠加。

默认排期事实16、治愈16、关系20、空间8；这是待批准的供给目标，不是这些方向已经胜出。没有候选的组回到补证，不为完成60条自动降低入选标准。

### 9.5 W4：30个新情境简报，各比较两条制作路径

15个组各写两个不同、同类的生活小事件，共30个独立简报。每份使用同样的事实、素材、人物/IP和质量验收要求，分别由常规人工路径与AI辅助路径制作，形成60个候选作品。默认方向事实12、治愈16、关系20、空间12。

记录人工总人时、AI工具费、等待时间、返工次数、质量通过率和可复用素材占比，不只记API费用。人工版30条是一笔真实产能需求，W0先确认；不足时批准减少配对样本，剩余槽位做新的复验内容，不能仍宣称完成30对。

这验证“制作流程整体”，不是证明AI本身带来销售增量。生产评测与经营评测分开：没有预算或样本做经营验证的内容，标为“生产已评估，经营未验证”。人工/AI实质相同的文件不算两条新增内容。

### 9.6 启动、预算与滚动规则

先完成组内基准和一个代表性改版，再按前置判断和成本边界决定是否进入其余版本的媒体测试；不要因为成片已做完，就平均花钱。并行组数受实际可用入口、每个版本需要的样本和剩余学习预算约束，不能从75条产量直接倒推出媒体消耗。

供给配额可滚动：W2起，在同一SKU内淘汰不适配的方向并转移槽位；跨SKU改变100/120/80时需同时过事实、库存和贡献门，并在数量账和JSON中更新。目标300可以保留，但无法安全或有价值地补位时，公开记录取消/延期，不用低价值重复内容填满。

放量只选经复验、贡献和供货合格的组合。旧赢家再次追投不新增视频计数。没有赢家时保留预算；不把300条或4周期限视作必须放量的理由。

### 9.7 W5—W8条件性扩展

原有后续路径保留：W5再测固定栏目识别，W6选择一个新SKU迁移，W7做授权达人或出镜者复验，W8再判断预算/账号/浴巾的单项扩展。任何一步都依赖前置证据，不按日历自动晋级，也不额外算入本轮300条。

## 10. 商品事实体系：AI只能重组已批准的事实

### 10.1 一张商品事实卡的必要字段

| 字段组 | 必填内容 | 更新责任 |
|---|---|---|
| 身份与交易 | 内部商品族ID、平台商品ID、SKU ID、规格、链接、当前可售状态 | 商品/渠道运营 |
| 实物属性 | 标签原文、成分比例、尺寸、克重、颜色图案、实际工艺、包装、洗护信息 | 商品负责人 |
| 证据 | 原片/报告/标签照片、对应SKU与批次、测试方法和条件、日期、有效范围 | 商品＋质量负责人 |
| 声明 | 可发布文本、适用范围、禁用表达、审核人、审核时间、所依赖证据ID | 内容＋合规负责人 |
| 经营属性 | 净成交收入、商品成本、履约/渠道/售后成本、库存、退货回收处理、投放上限 | 商品＋财务/数据 |
| 权利 | 商标/图案、人物声音、音乐素材、改编、广告使用渠道、区域与到期日 | 授权/合规负责人 |
| 版本与时效 | 事实版本、价格核验时间、报告版本、失效标记、受影响内容清单 | 系统记录，负责人批准 |

### 10.2 事实、观察、偏好、主张四分法

| 类型 | 例子 | 如何处理 |
|---|---|---|
| 可核验属性 | 成分比例、实际尺寸、包装件数 | 没有来源就不填；商品标题不自动晋级为已核实属性 |
| 条件性观察 | 某次样品在记录条件下的干燥时间/洗后变化 | 只说本次样品与条件；保留原片，不泛化批次 |
| 主观偏好 | “我喜欢这个图案”“我觉得这样挂很好看” | 要基于真实图案；演员/虚拟人物不伪装真实购买评价 |
| 性能/功效主张 | 吸水更快、抗菌、速干倍数、适用特殊皮肤 | 审核相符证据与表达合法性；不足则删除，不加一句免责声明后继续说 |

**特别修正：**“采用银离子相关工艺，性能以报告为准”本身仍包含工艺或性能暗示。缺少相符来源时，不能用这种兜底句替代核验。安全做法是删除未经支持的工艺/功效表述，或仅讨论消费者如何核对标签与报告，不为当前商品背书。

### 10.3 证据状态

`待采集 → 已采集待核验 → 已核验可限定使用 → 已失效/撤回`。

声明只有在证据可用、适用范围相符、人工批准后才能进入生成提示词。证据更新或撤回时，反向定位关联脚本、成片、商品页话术与直播提词，决定重新审核、改版或暂停使用。

### 10.4 实测方法的最低记录要求

吸水、干燥、缩水、掉毛属于不同问题，不能一个镜头证明全部。先写清比较对象与任务：同尺寸产品的实际使用表现，和单位质量材料性能，不是同一个问题。

记录样品SKU/批次、洗前洗后状态、实际尺寸与质量、温湿度/通风、用水量、脱水与挂放方式、计时规则、重复次数、异常与原片。生活演示只形成有限观察，不冒充实验室报告或符合某标准的检测结果。

尚未做完的测试，脚本中使用明确占位符并阻止发布，例如`[待填：实际测量结果与条件]`，绝不能由模型根据材质常识补全。

## 11. 资产库沉淀：参考、素材、证据、配方和经验分开管理

### 11.1 最小五张表

| 表 | 核心对象 | 关键关联 |
|---|---|---|
| 商品事实表 | 商品、属性、可用声明、证据、经营条件 | SKU→声明→证据→可发布范围 |
| 需求与配方表 | 需求原话、情绪任务、内容结构、IP设定版本、母题 | D→P→I→允许的SKU范围 |
| 素材资产表 | 自有原片、切片、授权片段、参考视频元数据 | 素材→SKU/动作/权利/适用配方 |
| 实验与成片表 | 实验卡、脚本、版本、时间线、成片、发布/投放ID | 实验→父版本→只改了什么→用了哪些事实和素材 |
| 数据与复盘表 | 曝光/点击/订单/成本、成熟度、结论、规则 | 成片→条件→结果→下一步与经验状态 |

第一版IP设定可存在一个版本化文件中，不必拆出一套独立系统。数据量和协作复杂度上来后再拆声明、证据、授权等独立实体。

### 11.2 六类资产不能混在一个“素材文件夹”

| 资产类别 | 作用 | 可否直接进入商业成片 |
|---|---|---|
| 外部参考知识 | 学习结构、开场、商品角色与表达 | 默认不可；另行取得相应权利才可用 |
| 自有实拍原片 | 保留真实商品和动作证据 | 通过人物/音乐/场地等权利与质量审核后可用 |
| 可复用切片 | 提高组装效率 | 仅在SKU、场景、声明与许可适配时可用 |
| 证据资产 | 支持具体声明和审核 | 能展示的范围由证据/授权审核决定 |
| 内容配方 | 复用叙事和测试策略 | 可生成新脚本，不等于允许复制别人的画面/文案 |
| 经营经验 | 记录何时有效、何时失效 | 用于建议和先验，不直接当成事实或永久规律 |

**研究参考库不等于可商用素材库；高播放外部视频也不等于已验证的成交黄金样本。**参考视频记录可见数据的观测时间与口径；看不到投流和成交时，明确写“未知”。

### 11.3 第一批素材采集清单

W0每个首测SKU先整理15—20段可复用片段；为支撑300条，每周再按新情境缺口补拍，不能仅循环播放同一组片段。初始采集优先覆盖全貌、图案/标签、真实展开、使用、挂放、折叠、空间关系及实际完成的测试。数量是采集计划，不是质量保证；一个复杂动作可保留多个原始取景，不能为了凑数把同一镜头切成许多无信息片段。

另外共享采集：钥匙放下、清理台面、准备来客用品、留空挂位、运动后整理、同机位浴室前后环境。共享镜头不含特定SKU证据；凡包含商品实物的镜头标明商品身份。

### 11.4 切片必须标“能表达什么”

除画面对象外，每段至少记录：动作、叙事功能、情绪表达、SKU可见性、证据属性、是否可替换、前后镜头连续性条件、人物/灯光/衣着、使用权利和过期时间。

“把毛巾挂到空位置”可以表达回家仪式或来客准备；“干燥实验的结果镜头”不能随意移入另一个SKU、另一种测试条件或另一个批次。

### 11.5 三种验证等级相互独立

| 维度 | 状态示例 | 不得混淆 |
|---|---|---|
| 权利与事实 | 不可用/待核验/可限定使用/失效 | 成交好不代表素材有权使用 |
| 创作质量 | 草稿/可制作/审核通过/需返工 | 人工觉得好看不代表经营有效 |
| 经营证据 | E0假设/E1首次可判定/E2独立复验/E3有条件迁移 | 第一次高ROI不代表黄金配方；E2也非普遍因果定律 |

E2最低工作门槛是，在登记条件下获得不止一批相对独立的复验资料，且商品贡献和审核未失守；它是内部使用等级，不是统计显著性的替代。

### 11.6 每周必须沉淀什么

每周形成一份需求优先级变化、一套事实/声明更新、若干已标权利和商品身份的切片、每个主要实验一张结论卡，以及继续/改动/暂停清单。

必须保留失败和不足样本。结论要写“在什么SKU、价格、场景、渠道与时间条件下观察到了什么”，不写“治愈永远比实测好”“萌兔天然适合卖高价”。

## 12. AI快速生成机制：先复用，再补拍，最后才生成缺口

### 12.1 一周的产能漏斗

建议先按“约90张候选经营卡 → 15个实验母版＋15个支持脚本 → 约90条粗剪候选（含返工/备选）→ 75条审核去重成片”估算每周负荷。实验母版各生成4个有实质变化的版本，得到60条；支持脚本各形成1条，得到15条。W4另拆30个新情境配对简报＋15个支持脚本，人工/AI各30条实验片，需单独校验人时。

这些是排产假设，不是已经实现的效率。按五个工作日估算，周均需审核15条/日，但**审核节拍不是公开发布频次**。首周记录单位脚本、素材补拍、粗剪与审核人时，再调整并行任务和支持岗位；不承诺300条会带来5倍增长或相同预算下的5倍可判定样本。

先限制缺口镜头和返工次数，再追求候选数量。没有真实证据的漂亮脚本不进入粗剪队列。

### 12.2 八个生产步骤

| 步骤 | 输入 | AI负责 | 人负责 | 输出与闸门 |
|---|---|---|---|---|
| 1 选问题 | 真实需求、成熟数据、库存与成本 | 聚类、候选排序、发现缺口 | 选2—3个主要问题和学习预算 | 本周问题清单 |
| 2 配组合 | 已批准事实、IP设定、配方库 | 生成受约束的D×P×I×S候选 | 删除不真实、不适配、不值得测的组合 | 内容经营卡 |
| 3 写变体 | 经营卡与控制变量 | 输出脚本、镜头、开场版本、差异表 | 确认购买理由和实验可解释性 | 可制作脚本 |
| 4 找素材 | 镜头需求与素材库 | 优先召回自有可用片段，检查SKU/权利 | 复核主体一致与证据使用 | 时间线草案＋缺口表 |
| 5 补缺口 | 缺口表 | 生成非商品事实性辅助内容的方案 | 实拍商品、真实动作与证据 | 已审核补充素材 |
| 6 组装初剪 | 脚本、素材、字幕规则 | 初剪、配音/字幕、时长适配与版本生成 | 审美、节奏、商品可信度把关 | 粗剪和成本记录 |
| 7 发布审核 | 成片、事实与授权版本 | 自动检查价格/声明/标识/一致性风险 | 批准发布或投放；预算操作保留人工确认 | 可发布成片＋追溯记录 |
| 8 回写学习 | 成熟指标、评论与售后 | 汇总、定位瓶颈、提下一轮候选 | 判断条件、结论等级与下一步 | 复盘卡与配方更新 |

### 12.3 允许AI生成什么

允许在审核下使用AI做非事实性背景设计、明确标识的虚拟角色、图文说明和必要过渡。商品实物、测试行为与结果、颜色/图案/包装、用户证言不能自由补造。AI辅助不意味着所有镜头都要生成。

发布包含AI生成合成内容时，应按适用规则主动声明并使用平台提供的标识功能；不得恶意删除、篡改、伪造或隐匿相关标识。《人工智能生成合成内容标识办法》第十条对此有明确要求。[S5]

### 12.4 返工按问题分类，而不是反复重生成

| 返工原因 | 正确处理 | 错误处理 |
|---|---|---|
| 商品事实不清 | 补证据/删声明/补实拍 | 让模型写得更“像真的” |
| 开场无吸引力 | 只重写开场与首个动作 | 全片推倒重来，失去对照 |
| 故事与商品脱节 | 重写商品参与动作与购买理由 | 片尾再加一次Logo |
| 镜头不连续 | 换匹配素材或补拍 | 用夸张转场掩盖商品变化 |
| 点击后不成交 | 核对页面、价格、规格和用户疑问 | 继续堆更多治愈音乐 |
| 内容疲劳疑似出现 | 先检查分发、供货、价格等，再换对应模块 | 每周固定淘汰所有旧片 |

每条任务设定人工批准的成本上限与生成重试上限；超过上限进入人工选择，不无限调用模型。优先优化“获得一个可判定答案的总成本”，不是单条API调用价格。

## 13. 实验、预算与统计边界

### 13.1 一个实验卡至少写清楚十件事

实验ID、经营问题、SKU/事实版本、需求/结构/IP版本、基准、改变项、不变项、主要判断指标、预算/停止条件、可读取的观察窗口与成熟度。补充记录发布与投放ID、价格/库存/直播/页面变更、其他干扰和结论等级。

只写“今天发了三条”不算实验。一个问题有多个视频版本，一条视频可以是其中一个实验臂；视频数量不能当作独立实验数量。

### 13.2 三类实验分开

| 类型 | 适合何时 | 允许变化 | 结论边界 |
|---|---|---|---|
| 表达组合探索 | W1/W2 | 购买动机与叙事可以整体变化 | 经营筛选，不能归因到单一因素 |
| 局部优化 | W3 | 一项明确变量 | 有控制条件才能把差异更多归到该改动 |
| 迁移/生产路径复验 | W4及以后 | 新故事/素材/制作路径或新SKU | 验证条件性复用，不宣称普遍规律 |

### 13.3 单计划多素材的限制

单计划内素材获得的曝光与人群由平台分配，可能与此前表现相关，不是随机等量。单条追投也会改变样本条件。自然发布存在时段、人群、流量来源与竞争差异，因此不能把任意两个视频的ROI相减后声称因果提升。

若账户有合适的受控测试能力，尽量保持其他条件一致、分开受众暴露。TikTok官方分组测试明确采用等分且互斥的受众组；这是实验设计参考，不代表本抖音账户一定提供相同功能。[S4]

若只能观察性赛马，明确标记，按同SKU、同报价/优惠、相近时间窗、同转化去向分层，记录干扰；优先做跨批复验，不夸大结论。

### 13.4 不用“花了100元”或“发满一天”定义有效测试

先定义问题和最低可接受表现，再估算信息量与预算。开场留存可以用曝光/播放数据判断，订单贡献需要足够点击、订单及退款成熟；一种样本不能回答所有问题。

仅为解释样本问题：假设点击近似独立、转化概率稳定、固定一次检验，最低可接受点击转化率为2%，则149次点击仍零订单的概率约为4.93%。但30次点击零订单的概率约为54.55%，并不罕见。因此“几十次点击没有成交”不能机械等同失败。这里2%是数学示例，不是对毛巾账户的预测，也不是应统一执行的暂停阈值。

正式实验需预先约定比较方式、最小有意义变化、允许误判风险、预算上限和读取规则。反复偷看并在最好时结束会夸大胜率；预算不足以区分时，输出“证据不足”，不是编造一个赢家。

### 13.5 预算分三本账，但总账不能遗漏

| 预算 | 用途 | 是否必须每条即时盈利 |
|---|---|---|
| 学习预算 | 判断需求、商品事实承接和表达组合 | 可以有限亏损，必须有问题、上限和结论 |
| 复验预算 | 验证候选稳定性、再生产与迁移 | 需更严格控制贡献与条件，不能无限补样本 |
| 放大预算 | 扩大已达到经营条件的组合 | 必须守贡献、费比、库存和售后边界 |

一个起始设计：媒体预算上限中学习50%、复验30%、条件性放大20%。这只是资金分桶建议，不要求把钱用完；无合格候选时放大部分保留。内容制作、工具费用与人工成本单列后仍进入总账，不因为叫“学习”就从利润中删掉。

不得把探索中的亏损素材与已成熟放量素材混算后，掩盖任何一边的真实表现。

### 13.6 放量与创意实验分开操作

放量使用已确认的成片版本；一次只改变预算或成本出价中的一个，观察新增消耗区间的净收入与贡献，不同时改视频主体、优惠和商品页。预算是可花上限，成本出价是竞价控制量，出价提高20%不等于消耗或订单必然提高20%。

放量步长不预设为平台规律，由账户实际响应决定，并保留人工审批。库存不足、证据失效、出现误导性承诺或单位贡献失守时，优先暂停；不能为了月度GMV把合规或质量问题当普通波动。

## 14. 指标、单位经济与周度决策

### 14.1 北极星：退款调整后的内容贡献利润

**内容贡献利润 = 归因净成交收入 − 实际承担的商品/渠道/履约/售后成本 − 广告费用 − 按统一规则分摊的内容制作与工具成本。**

净成交收入扣除已知退款；未成熟订单保留预计退款成本或单独列示。退回库存的可回收价值按财务口径处理，避免商品成本和退货损失重复扣减。跨短视频、直播和商品卡建立统一归因去重口径；无法去重时分开报表，不相加冒充总收入。

这是内部贡献利润，不自动等于公司净利润，也不等于因果增量利润；公司固定开支还需统一处理，增量需要额外对照。

### 14.2 三个核心过程指标

| 指标 | 定义 | 作用 |
|---|---|---|
| 有效实验单位成本 | 本期全部实验相关制作、人工、工具与媒体费用 ÷ 本期达到预注册判断要求的实验问题数 | 不能删除不足样本的花费；分母不是视频条数 |
| 独立复验通过率 | 独立复验达到预定事实、质量与经营门槛的母题数 ÷ 本期进入独立复验的母题数 | 防止把一条偶然高ROI当作方法 |
| 合格消耗容量 | 在贡献、费比、库存与售后边界内实际验证过的日消耗范围 | 只报已观测范围，不从100元测试外推到万元/日 |

### 14.3 诊断指标，不全部升为考核指标

开场保留/平均观看、商品点击率、CPC、点击后成交率、实际客单、净ROI、退款与退款原因、制作成本、人工修改量、商品/品牌相关评论、数据成熟度。

字段按平台实际可获得口径记录。没有某指标时填缺失，不填0；不同平台或入口的分母不得混用。IP记忆可以增加用户主动提及栏目/角色、非诱导的记忆访谈和回访内容，但不把评论量直接当品牌增量。

### 14.4 付费CPA上限的可计算口径

对同一SKU/交易方案的成熟付费订单群组，设：

- R：每笔付费成交订单对应的预计退款后净收入；不是页面单件售价。
- C：同口径每笔订单的非广告、非内容变动成本，包含实际履约/渠道/售后并处理退货回收。
- K：每笔订单分摊的内容成本。
- m：希望保留的贡献利润率；若要表示公司利润目标，还应扣对应固定成本分摊。
- θ：批准用于该付费群组的广告费比上限；采用20%只是保守统一约束示例，整体与单素材口径需先确认。

则可采用：**CPA上限 = min(θ×R, R−C−K−m×R)**。

上限≤0表示当前交易方案不适合付费放量；不是换一个治愈文案就能解决。若θ=20%，同口径广告净ROI门槛为5，这是1/0.2的算术结果，不是对账户实际可实现ROI的预测。

20.9元、49.9元和89.9元是用户提供的单件参考价，不能直接代入R；多件装、套装与退款结构必须分别建账。

### 14.5 一张经营诊断表

| 观察 | 优先排查 | 默认动作 |
|---|---|---|
| 开场保留弱 | 情境是否具体、首个动作是否清楚 | 改开场，不立即否定SKU |
| 观看好、点击弱 | 商品出现与购买理由是否成立；人群是否匹配 | 强化商品动作和适用性，不只加Logo |
| 点击好、成交弱 | 规格、价格、信任、页面/直播承接、运费与库存 | 核对承接与用户疑问 |
| 成交好、贡献弱 | 订单结构、退款、投放/履约成本 | 调整交易方案或停止放量 |
| 互动好、商品意图长期弱 | 是不是只有故事受欢迎 | 放入有限品牌内容预算，不进入成交赢家池 |
| 曝光不足、订单太少 | 是否获得判断机会 | 标记待测，补信息或因机会成本暂停，不能称范式失败 |
| 旧素材持续下降 | 流量价格、库存优惠、竞争、投放条件与创意疲劳 | 先定位原因，再更新对应模块 |

### 14.6 7日/30日数据的使用

7日看最近状态，30日提供背景与不确定性信息。近7日已经包含在近30日中，不当成两份独立样本简单相加；可拆成最近7日与此前23日，并按投放条件、内容年龄和样本量比较。连续滚动窗口高度重叠，不能把几次连续上涨视为几次独立验证。

每周滚动不等于每条视频一周内强制结案。早期T+3观察与较晚T+7/更长窗口分别记录；退款成熟周期由实际订单分布和业务规则决定，不能默认7天或14天所有退款已结束。

## 15. 周度AI实验节奏与组织协作

### 15.1 一周运行节奏

| 时间 | 业务动作 | AI动作 | 必须交付 |
|---|---|---|---|
| 周一 | 只读取已达到窗口要求的实验；核对库存、价格、证据变化；选主要问题 | 汇总7/30日背景、评论与干扰，生成候选与不足样本清单 | 本周实验卡、预算上限、延续问题 |
| 周二 | 审核需求、脚本与商品动作，批准实际要拍什么 | 生成变体、素材召回、缺口与时间线 | 可制作脚本、拍摄清单、对照关系 |
| 周三 | 集中拍商品与生活动作，审核粗剪 | 组装、字幕、版本管理、自动检查 | 12实验＋3支持槽位的生产状态 |
| 周四至周五 | 按账户允许的方式分批上线；记录条件 | 汇总早期数据、异常与评论，保留发布ID | 发布记录和风险提醒，不抢跑宣布赢家 |
| 持续检查 | 处理违规、缺货、价格错误与明确亏损越界 | 规则检查与需人批准的动作建议 | 暂停/改版审计记录 |
| 下一周及以后 | 读取成熟结果，复验/扩大/暂停 | 生成差异分析与资产回写草稿 | 一页周复盘与条件性经验 |

### 15.2 角色与责任，不先建多个中台

| 角色 | 唯一主要责任 | 验收物 |
|---|---|---|
| 品类负责人 | 经营目标、SKU选择、预算与晋级决策 | 本周问题、损失上限、继续/暂停决策 |
| 商品/质量负责人 | 实物、声明、证据、库存与单位经济基础 | 已批准商品事实卡与证据 |
| 内容主理人/导演 | 人格、购买理由、脚本与成片可信度 | 可拍脚本、成片审核、IP一致性 |
| 增长投放/渠道 | 测试条件、实际投放与商品/直播承接 | 发布投放映射、变更日志、预算动作 |
| AI/数据负责人 | 生产效率、数据对齐、实验记录与资产回写 | 可追溯时间线、成本数据、复盘与模板 |

这些是职责，可以由现有人员兼任；不等于必须新增五个岗位。授权/法务、摄影、演员、客服与财务按事项加入，但审批责任不能空缺。

### 15.3 一页周复盘必须回答

本周买到了什么答案；哪些问题仍证据不足；哪款商品的哪种购买理由值得继续；最大亏损/返工来自哪里；下周只改变什么；哪些事实、素材与配方更新或撤回。

不按“发布数量、AI使用次数、生成分钟数”单独奖励。数量必须以事实和质量为前提，效率必须落到可判定答案与经营结果。

## 16. 最小落地系统：先表格与文件夹，再工具化

### 16.1 五个业务页面足够开始

商品事实与准入、需求/配方候选、制作任务与素材、实验与发布、复盘与资产。页面对应前面的五张表；第一周可用现有协作工具实现，不要求先开发完整平台。

### 16.2 六个可逐步沉淀的技能

`需求聚类`、`受约束内容配方生成`、`素材召回与缺口分析`、`镜头组装与一致性检查`、`实验对比与诊断`、`经验回写与过期检查`。

它们是可复用任务能力，不要求各配一个独立Agent。由一个有审核闸门的任务编排流程调用即可；确定性的ID、权限、预算与状态变化交给程序，人保留发布与广告预算审批。

### 16.3 每条成片保存的最小追溯链

实验ID → 内容版本 → 父版本与改变项 → 需求/结构/IP版本 → SKU/商品事实版本 → 声明与证据ID → 素材ID/时间码 → 制作路径/模型与工具版本 → 人工审核 → 发布/投放ID → 数据窗口与成熟度 → 复盘结论。

缺ID的成片不进入正式复盘；缺证据的声明不进入发布；缺经营数据不填造数。系统初版可以人工导入投放导出表，先做准映射，不先追求自动抓一切。

## 17. 风险、失败与调整规则

| 风险 | 早期表现 | 处理 |
|---|---|---|
| 泛治愈化 | 评论只谈心情，没人理解商品选择 | 恢复商品关键动作与适用性；限制纯品牌预算 |
| 品牌失焦 | 和任何温柔日用品账号都一样 | 回到玩趣、实际图案与角色态度；不只加Logo |
| 高价但无差异 | 需要很长话术解释，却没有实物理由 | 让实物说差异，必要时改变交易方案，不吹品质 |
| 快速生成失真 | 图案/包装/材质变化、假水效 | 商品镜头回到实拍；提升事实闸门，不加重生成 |
| 过度并行 | 每个版本只有很少数据，周周无结论 | 缩减在测SKU与变量，先补一组可判定对照 |
| 把运气当规律 | 单条高ROI就大量复制、扩号 | 独立素材复验、同条件对照，再测容量 |
| 只存赢家 | 错误反复出现，规则越来越乐观 | 失败与不足样本全部保留并标条件 |
| 权利混用 | 外部参考被直接剪入、角色延展无许可 | 研究库与生产库隔离，发布前核权利 |
| 虚假情景证言 | 演员扮消费者、AI声线假冒真实评价 | 明确演绎，不伪造交易或独立评价身份 |

## 附录B. 给AI的四条工作指令

### B.1 周一：受约束选题

```text
你是毛巾品类内容策划助手。读取已批准商品事实、IP设定、现有素材、
成熟实验结果和经过脱敏的真实用户问题。

先指出事实、库存、成本、授权与样本缺口，再推荐本周最多3个主要问题。
每个问题提出：需求与情绪、内容结构、同一IP的表达侧面、具体SKU、
商品关键动作、证据、交易承接、基准、只改变什么、预算/读取规则。

用户原话与模型编写的洞察例句必须分开。
没有证据不编造测试结果；没有可售组合不创作礼盒/套装承诺。
不能因为一条视频数据最高就称为赢家。
输出：候选表、被拒绝组合及原因、待人批准的实验卡。
```

### B.2 周二：脚本与分镜

```text
为指定的内容经营卡生成脚本，而不是重新定义整个策略。
沿用冻结的SKU、事实版本、IP设定、主体证据与承接条件。
需要开场变体时，只改约定开场，不同时改价格、人物、场景和证据。

每个镜头输出：时间范围、画面动作、旁白/字幕、素材ID或缺口、
对应声明/证据ID、连续性条件、AI是否允许生成、人工审核项。
找不到实物或证据时标记“必须补拍/补证”，不得根据商品名补全。
末尾输出购买理由与“拿掉商品故事是否仍完全成立”的检查结果。
```

### B.3 周三：素材召回与组装

```text
先检索有商业使用许可的自有素材，再检索已获许可的外部素材。
研究参考库默认不允许进入成片。
必须匹配SKU、图案/颜色、场景连续性、证据条件与许可有效期。

输出时间线、素材来源、缺口与最低成本补拍方案。
商品外观、测试行为与结果、价格、包装、消费者证言不得自由生成。
达到成本或重试上限就请求人工选择，不无限生成。
成片记录所有事实/素材版本、制作成本、人工修改与发布审核状态。
```

### B.4 周复盘：判断而非找理由

```text
按实验卡的预注册问题读取数据，先判断数据是否足以回答问题。
区分付费/自然、短视频商品/直播去向、SKU、价格、时段与退款成熟度。
最近7日包含在30日内，不能当两份独立证据简单相加。

输出每个实验：已知事实、观察结果、可成立解释、未排除干扰、
证据等级、损失/贡献、下一步只改变什么。
没有随机或可比对照时，不输出确定的因果提升。
没有赢家就明确写“本轮没有合格赢家”，不把最高值自动晋级。
最后给出待审核的需求、事实、素材、配方和失败规则更新。
```
