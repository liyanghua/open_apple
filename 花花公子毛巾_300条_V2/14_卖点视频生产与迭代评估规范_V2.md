# 卖点视频生产与迭代评估规范 V2

版本：v2.0｜日期：2026-10-08｜用途：**后续制作、系统升级和评估的文档依据**。规范写入不代表代码已经实现、评估器已校准或样片已通过。

本版继承 [11 号制作规范](11_卖点短视频制作规范_待审核.md) 的已批准品牌和制作边界，增加可信记录、分工与迭代评估规则。旧版留存为历史；已生成成片继续绑定生成时的文档、素材和审批快照。采用本版的新运行需显式登记本版文件及哈希，不能给旧片自动换规范。

适用于当前展示类路线：Seedance 2.5＋Doubao TTS＋Remotion ProductionBrand＋已批准 SUNO 素材。P2 必须使用自己的商品事实与参考图；故事、实测等使用各自的内容 recipe，不继承本版展示类固定节奏。

配套：[实施方案](13_生产复盘与持续迭代评估实施方案.md)、[迭代评估卡](templates/迭代评估卡.md)。

## 1. 规则层级与执行责任

| 层级 | 规则 | 责任与生效 |
|---|---|---|
| 制作约束 | 事实、商品、品牌、声音完整性及输出规格 | Agent 必须遵守；已有校验按真实能力执行，缺项显式记录 |
| 工作流约束 | 先记录、后生成；先审素材、后合成；改版后重核；批准绑定版本 | 通过现有 pipeline 与持久化推进，不补造历史状态 |
| 迭代评估 | 冻结基线、预登记变量、盲评、五类结论和证据强度 | 本版新增合同；代码未实现前可使用模板人工登记，不声称自动执行 |
| 创作空间 | 钩子措辞、环境、动作、运镜、镜头顺序、停顿和音乐入点 | Agent 写理由及预期；重大生产路线变更继续按既有授权机制处理 |

**GOV-01** 可试看、必要检查完成、最终人工批准、允许交付、可计数、经营有效分别记录。禁止用其中一项替代其他项。

**GOV-02** 商品事实和关键机器检查不能通过人工点击批准补足。允许人工核验的内容项必须具名、带时间、检查范围和当前媒体/报告哈希；机器原始结果不改写。

**GOV-03** 新规范、文档更新、评估计划不是付费、发布或扩大批量授权。已有本轮 6 段＋最多 2 次追加的上限是历史运行合同，不自动转成今后每批预算。

## 2. 事实、镜头与生成

**SP-01** 每个主张绑定 SKU、claim ID、准确措辞、来源和哈希、证据类别、措辞审批。银离子、10A、抗菌、防臭、吸水分别管理，不能互相推导。

**SP-02** `merchant_claim`、真实实测、`generated_visual_expression` 分开。展示挂放/擦拭可以承接生活用途，不能证明防臭时长、吸水速度或抗菌等级。不凭生成画面补报告、证书、数值或“永不发臭”等新承诺。

**SH-01** 本类完整片规划环境中景、完整商品、手部使用近景、织纹超近景；相邻镜头至少在景别、机位、主体动作之一形成有用变化。记录实际镜头是否实现，不以计划标签当检测结果。

**SH-02** 一镜头承担清晰信息任务；每个主卖点有相符画面。不得靠同一微距、换字幕或裁切连续假扮不同卖点。镜头多、切得快不等于信息更清晰。

**SH-03** 本类动作开头前 1 秒出现可见主体动作，前 3 秒识别商品和一个重点。每段记录起始状态、主体动作、可见结束状态；镜头运动不能代替主体动作。

**SH-04** 生成默认 4 秒；主体剪入通常 1.8–2.6 秒；开头 3 秒；收尾由实测语音长度及至少 0.4 秒余量决定。不能为了满足时长切掉动作结果或必要实测条件。

**REF-01** 商品外观、动作构图、品牌叠加三种参考角色明确分开。参考片抽帧只在明确授权的用途内使用，不能当作自有商品身份或直接成片素材；原始与处理文件分别留存。

**GEN-01** 当前锁定 `seedance_ark / Ark / doubao-seedance-2-5-260628`，variant `2.5`，`reference_to_video`，720p、9:16、`generate_audio=false`；执行前 dry-run。环境变量不能静默替换已锁定模型。

**GEN-02** 提示词包含主体、主体运动、场景、空间构图、摄影机，以及参考角色、外观保持项、禁止变化。一段一个主要动作；LOGO、广告字和等级文字由后期叠加。

**GEN-03** 记录真实 task ID、模型、输入/输出哈希、usage、原生尺寸、帧率、时长和截取区间。最终 1080p 输出不代表原生 1080p 生成。API 配置只记变量名，不把 key 值写入文档、日志、回执或样本。

**GEN-04** 远端状态不明先查询，不能重新 POST；无 task ID 也需使用请求/幂等/账务等证据消除不确定性。服务失败与创意淘汰分开，任何已收费失败或淘汰都计成本，重试受运行预算与次数限制。

**GEN-05** 不把选片后的动作描述反写成原计划。实际只发生轻提、未完成展开或松手时，记录执行差异，选择重做或修订表达；涉及承诺变化时重新审核相应创意。

## 3. 品牌、口播、音乐与输出

以已批准品牌 profile 及字体文件为数值单一来源。本表为 `playboy-production-noto-fullscreen-v3` 在 1080×1920 下的说明；后续变更需新版本绑定。

| 元素 | 当前约束 |
|---|---|
| LOGO | 官方资产，右 72px、顶 96px、宽 120px，净空 16px |
| 字体 | Noto Sans CJK SC，400/700，绑定实际文件哈希；禁止静默回退 |
| 左上标题 | x=72、y=220，64px、700 字重，行高 1.15，2–4 字符；只放核心关键词 |
| 下划线 | 实际标题等宽，8px 高、间距 22px，`#4874CB` |
| 下方字幕 | top=1550，左右 72px，38px、400 字重，行高 1.25；显示实际口播 |
| 背景 | 全屏，无上下宽蒙版、中央事实栏或整画面灰罩 |
| 结尾 | “PLAYBOY，让日常更有质感。”读完整，最后词后至少 0.4 秒 |
| 转场 | 现有 5 帧实现；品牌层连续，源素材有足够余量 |
| 输出 | 1080×1920、30fps、H.264、AAC、yuv420p、可在线播放 MP4 |

**BR-01** 左上可写“10A”；“10A抗菌”有 5 字符，完整词组进入口播和字幕。不能为个别标题放宽全局字号或字符规则。

**BR-02** 实际 DOM 测量与成片画面复核并行使用；几何无重叠不等于复杂背景可读。转场检查覆盖两个相邻镜头的接触区域、字幕、亮度突变和手部跳位。

**AU-01** 实际配音测量后再排时间轴。开头与正文同声线、相近语气；不截字、辅音、尾音，不靠长静音或整条强制加速塞进时长。

**AU-02** 分别保留脚本、实际 TTS、词时间、混音、人声/BGM stem、独立 ASR、人工试听。TTS 输入与返回时间戳不能充当独立听审。

**AU-03** 标点、空格及经过版本化规则确认的数字表示可以用于辅助比对；不得把同音词直接改成期望产品词来消除原始失败。“银离子”“10A”、颜色名和品牌句有差异时定位试听，必要时对比干声与最终混音以区分发音、识别和掩蔽问题。

**AU-04** 当前混音目标约 -14 LUFS、真峰值≤-1.5dBTP，两版整体差≤0.5 LU；这些是制作目标，达标仍需试听。volume 数字不是响度证据。

## 4. 开头比较与工作流

**AB-01** 先声明比较单位是一个变量、完整开头方案还是整条方案。本轮 P1-SELL-A/B 是开头方案对比，不能归因于“防臭”或“吸水”某个词本身。

**AB-02** 正式开头变体先建立获批 B0，再冻结共同正文、事实、品牌、参考边界、口播、音乐及混音。还没有 B0 时可以制作并试看候选，但不得宣称已经完成正式冻结实验或批准批量。

**AB-03** 共用正文只生成一份 TTS。30fps 时第 90 帧为正文起点，85–89 帧完成开头转场；从第 3 秒开始不能残留旧开头。实际媒体比较与时间轴比较都要记录；有损编码误差不等于创意差异，SSIM 高也不等于两版逐字节一致。

**WF-01** 阶段顺序：核对任务/事实/授权→锁定脚本和比较条件→分镜与素材缺口→生成并审素材→实测口播→合成→检查→试看反馈/局部返工→必要证据齐备→最终批准→交付/计数。

**WF-02** 生产记录在生成前建立。任务回执、测量和审批使用追加版本；原始输出不改。修改文案、素材、字体或混音后，依据影响范围重跑检查并重新绑定审批；工具不支持局部出口时仍走正式完整渲染。

**WF-03** 既有历史缺口显式保留。不能把新文件存在当成旧阶段已完成；现有工具与产物可用，不代表整个生命周期已通过。checkpoint 保留合法状态和明确 next_action。

**WF-04** skills 描述方法，workflow 约束阶段，代码执行工具与持久化。禁止为了便利新建包办创意、判断与审批的总控脚本；新增能力在独立开发流程验证后接入。

## 5. 质量状态与证据

**QA-01** 机器结果保留 `pass / fail / not_run / error`。适用性单独记录 `applies / required / reason / evidence`，不是第五个机器状态。无价格文案可有证据地不适用；缺价格资料或未运行检查不能据此排除。相关主张后来出现时，原“不适用”随依赖变更失效。

**QA-02** 门禁只在全部适用必要项有有效结果时成立。coverage 按适用项计算并显示排除理由；未执行的必要项仍计缺失，失败不能从分母删除。此处是目标规则，不表示当前技术工具已改造。

**QA-03** 每份测量绑定 render 哈希、canonical props、范围、工具/模型/规则版本、实际输入模态和原始结果。前置预检不等于渲染后测量；帧级判断不等于连续动作审查。

**QA-04** 缺音频时声音维度显示未评估，保留工具原始值但不把原始 0 分当实际差评或纳入均分。Judge JSON 最多一次格式修复重试；仍失败记 error，不补造分数。

**QA-05** 人工替代仅限系统允许的内容项，保存核验人、时间点、问题、媒体及报告版本。不能替代商品事实来源或机器硬性检查。采纳一条创意建议不等于最终验收。

## 6. 迭代评估合同

**EV-01 预登记。** 执行前填写比较类型、主目标、基线/候选、允许变化/冻结项、指标定义与方向、改善/退化/等效边界、评估集、运行顺序、预算、审核方法。不能看完结果后修改阈值选赢家。

**EV-02 可比性。** 同 brief/SKU/类型及预登记约束；评估器相同版本、提示词、输入模态、采样与量表。条件不同则具体标明；评估器换版时用新旧评估器重评同一组固定媒体，不把跨版本原始分数直接相减。

**EV-03 六维创意量表。** 人工/已校准评估器使用 1–5 级，缺失留空。2、4 为相邻锚点之间；以下是待校准的文档锚点，不是已证明预测留存的模型。

| 维度 | 1：明显不成立 | 3：合格 | 5：突出 |
|---|---|---|---|
| 开头 | 看不出商品/问题，或误导承诺 | 3 秒内理解商品和一个重点 | 动作与诉求立即成立，有清楚的继续观看理由 |
| 卖点 | 无重点、听不懂或只有动作说明 | 能识别主要卖点 | 优先级明确，观看后能准确复述重点与适用语境 |
| 画面对应 | 画面无关或暗示虚假证明 | 当前画面与卖点相符，证据口径清楚 | 画面帮助理解价值且不越过事实边界 |
| 镜头层次 | 相同近景重复或变化无意义 | 景别/场景/动作有有效变化 | 远近和动作转换持续推进信息，空间清楚 |
| 节奏 | 拖沓、赶字、跳切或结果被截断 | 信息可消化，切换自然 | 信息密度高且重点、停顿、动作完成协调 |
| 声音 | 关键字不清、音乐盖人声、截尾 | 发音清楚、音量合适、句子完整 | 语气/重音/停顿与画面配合自然，音乐强化表达 |

关键缺陷另走门禁，不靠六维平均分决定放行。1–5 级不得与既有 0–10 Judge 或百分制混算；单人意见标为单人偏好。

**EV-04 默认边界。** 若迭代卡没有更具体且事前批准的设置，创意主维度改善/退化边界为 ±1 级；其他重要维度降低 1 级要显式记录取舍。效率类主指标相对改善/退化边界为 ±10%，等效区间为开区间（-10%，+10%），恰达边界归改善/退化方向。相对变化先按“越高/越低越好”统一方向；基线为零或量纲不同需事前指定绝对边界，否则不计算相对提升。以上为初始产品规则，后续只能前瞻修订版本，不能倒改本次结论；观测变化达到边界仍须按证据强度限定结论。

**EV-05 盲评。** 隐藏旧/新、模型、文件名及既有分数，平衡顺序；先看前三秒，再看全片，最后听声音。记录偏好、六维等级、时间点和理由；缺少独立评价时保留制作 Agent 自评身份，不能称为独立盲评。正式 Judge 校准采用双人独立标注及争议仲裁。

**EV-06 结论与优先级。** 各成绩单分别给结论，整体不靠简单平均。已证实的新关键缺陷优先阻止采用；可比性或必要证据不足时不宣布总体改善。

| 结论 | 使用条件 |
|---|---|
| 改善 | 主指标达到改善边界，适用质量底线满足，重要维度没有退化；注明是单次偏好、固定集回放、重复生成方向性还是统计支持 |
| 退化 | 新关键缺陷已被证实，或可比主指标达到退化边界；其余未知维度仍保留未知 |
| 持平 | 证据足以支持事前定义的等效区间；固定确定性回放仅能证明测试集覆盖范围内行为一致 |
| 有取舍 | 某指标变好、另一个重要指标变差；列明交换条件，不自动晋升 |
| 证据不足 | 缺基线、样本、必要测量、可比条件或一致标注；没有显著差异不等于持平 |

**EV-07 随机性。** 关键生成升级默认 3 任务×每版 3 次，全部结果入账并按任务分组报告；少量结果只作方向性诊断。统计支持需事前分析计划、按独立任务/用户单元处理相关性及样本量依据，不能把同一 brief 的重试凑成独立样本。不在看见有利结果时提前停止。

**EV-08 日常成本。** 日常回放不调用付费生成。关键升级的任务粒度、每任务调用数和总预算明确登记，预算不足则缩减评估范围并降低证据强度，不静默追加。

## 7. 效率与经营指标口径

| 指标 | 定义与限制 |
|---|---|
| 首次合格率 | 第一次完整生成/制作尝试即通过适用检查的任务数÷已完成评判的任务数；待评审另列，不提前算成功 |
| 创意淘汰率 | 已成功产出但被判创意不合格的素材数÷已完成创意评判的成功素材数 |
| 重复付费 | 无新增授权创意请求却因恢复错误重复提交的付费次数；目标为零 |
| 每条候选成本 | 本轮全部尝试与明确分摊成本÷候选数；仅用于样片阶段，不冒充合格作品成本 |
| 每条合格成本 | 全部相关生产与返工成本÷最终验收的独立 work 数；分母为零时未定义 |
| 直接与完整成本 | 增量现金费用和包含人工/摊销的完整成本分别列示；估算、预占、实付、未知分开 |
| 生产耗时 | 排队、模型、Agent 主动、人工主动、等待、渲染、返工分别记录；并发累计工时与实际墙钟时间不混用 |
| 复用与回放 | 缓存/素材复用命中率单列；冷启动、缓存回放、全新生成不混合比较耗时 |
| 三秒留存等经营指标 | 使用平台原始口径、分子分母与窗口；平台定义不同不统一强算 |

**MET-01** 未知实付、工时、分母不能填零。共享素材按预先说明的方式分摊，项目总账只计一次；不把整池费用重复算到每条影片。

**MET-02** 线上比较保留平台、账号、SKU/受众、分配方式、观察窗口、原始导出和发布时间。受众及曝光不可控时只能描述观察差异，不推断因果。没有数据不预测“爆款概率”作为已验证结论。

**MET-03** 版本比较不等于独立作品计数；旧基准引用、重复导出和三秒节选不增加 300 条名额。受控单变量实验允许变化少；跨母题探索仍需要实质差异。

## 8. 证据集、晋升与变更验收

**SET-01** 首版 12 例用于展示类回归，Gold/Silver/Bad/Hard Negative 各 3 例。标签必须有来源；不足时写不足。当前 P1-SELL-A/B 未最终验收，不能自动标 Gold。测试衍生物不混入生产素材池。
